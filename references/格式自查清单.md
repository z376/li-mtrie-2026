# 论文格式自查清单 (Paper Format Self-Check)

> **借鉴源**: BZD 数模社 `bzd-paper-format-checker` v1.0 (2026-08-18) 的 **报告结构** (12 章节 + 100+ 原子检查点 + 15 分逐项扣分制).
> 本文档搬运**报告骨架**和**关键检查点**供 li-mtrie 自用, 实际自查可程序化部分走 `references/scripts/verify_pdf_metrics.py`.

**LLM 工具版本** (本方法论 + 结构化 prompt): `references/llm-prompts/04-百分制评审.md §M2 格式自查` — 12 章节 + 100+ 原子检查点 全部进 JSON OUTPUT_FORMAT, 学生 copy-paste 自用.

## 1. 何时用

终审前(Step 4 编译后, 提交前 1-2 小时), 对**完整 PDF** 做一次格式总检.

**不替代**:
- 模型正确性检查 (走 §5 求解后再用 `references/脚本工具/score_estimator.py` 或人工)
- AIGC 痕迹检查 (走 `references/scripts/aigc_scan.py`)
- 内容逻辑检查 (走 `references/llm-prompts/03-自动审稿.md`)

## 2. 评分规则

**满分 15 分**, **逐项扣分**, 最低 -9999.

| 状态 | 扣分 |
|---|---|
| **不满足** | 核心信息缺失/系统性错误/严重影响阅读/可能违反明确规则 → **扣 2 分**; 一般完整性/统一性/清晰度/局部规范 → **扣 1 分** |
| **部分满足** | 实质缺口 → 扣 1 分; 仅轻微优化 → 不扣分但要说明 |
| **满足 / 无法核验 / 不适用** | 0 分 |

**铁律**:
- 同一现象可触发多条独立未满足, **但不机械重复扣同一模板错** (e.g., 页码错在 30 页, 不扣 30 次)
- 官方资格性问题另标 `资格风险`, **不被分数抵消**
- 不得用"代码过长""42 页长文档应有目录"等**主观阈值**直接扣分

## 3. 报告模板 (12 章节, Markdown)

### 一、总体结论

```markdown
## 一、总体结论
- 当前状态: 通过 / 修改后通过 / 材料不足 / 高风险
- 规范质量得分: X/15 (唯一结果, 允许负分, 最低 -9999)
- 最高风险: 资格风险 / 严重问题 / 重要问题 / 一般问题 / 未能判断
- 检查依据: 当届官方规范 / 用户提供规范 / 通用建议
- 检查边界: 仅 PDF / PDF+Word / 含附件数据
```

### 二、页面结构与页码

检查项:
- [ ] 总页数 (含附录)
- [ ] 摘要页 / 正文起始页 / 正文结束页 / 附录起始页
- [ ] 页码连续 (摘要用罗马, 正文用阿拉伯, **不能混**)
- [ ] 页眉页脚 (是否有"全国大学生数学建模竞赛"标识?)
- [ ] 目录存在性 (**国赛严禁目录** — 出现即资格风险)

### 三、摘要逐项检查 (5 个独立检查点)

| # | 检查点 | 状态 | 证据 | 扣分 |
|---|---|---|---|---|
| 3.1 | 摘要能否脱离赛题独立阅读 (含问题/方法/结果/结论) | | | |
| 3.2 | 摘要开头是否直接点题 (不写"针对...本文..."套话) | | | |
| 3.3 | 摘要是否列出每道问题的方法 + 关键结果 (数值) | | | |
| 3.4 | 摘要是否在 1 页内 (400-800 字) | | | |
| 3.5 | 摘要是否避免引用图表/公式/参考文献 (国赛规则) | | | |

| 部分/问题 | 实际页数 | 判断 | 修改建议 |
|---|---|---|---|
| 引言 | | | |

| 模型假设 + 符号说明 | | | |
| 问题 1: 建立/求解/结果 | | | |
| 问题 2: 建立/求解/结果 | | | |
| 问题 3: 建立/求解/结果 | | | |
| 模型检验 | | | |

**诊断参照** (不机械执行): 模型建立 ~50%, 求解过程 20-30%, 结果与解释 20-30%. 失衡且影响说明完整性时提醒.

### 五、标题 / 正文 / 页眉页脚

- [ ] 一级标题 (章) 字号一致 / 居中 / 不编号或用罗马 I, II, III
- [ ] 二级标题 (节) 1-1.5 页出现 1 次 (超频扣分)
- [ ] 三级标题 (小节) 每页 ≤ 2 个 (3+ 扣分)
- [ ] 标题下必有实质内容 (不空挂)
- [ ] 标题编号连续无跳号
- [ ] 正文字体 / 字号 / 行距符合模板
- [ ] 段落首行缩进 2 字符
- [ ] 页眉页脚无身份信息

### 六、图 / 表 / 公式

- [ ] 图题 + 表题 + 公式编号齐全连续
- [ ] 三线表 (顶/底/表头下, 无竖线)
- [ ] 公式居中, 编号右对齐
- [ ] 公式后标点正确
- [ ] 图/表分辨率 ≥ 200 DPI
- [ ] 图/表**必须由正文引出** ("如图 X 所示...")
- [ ] 图/表**必须由正文解释** (不只贴图)

### 七、图文平衡与重复表达

| 检查 | 描述 | 状态 | 扣分 |
|---|---|---|---|
| 图与表是否表达同一数据 | | | |
| 图/表/段落是否重复同一结论 | | | |
| 是否出现图片/表格/大段文字堆积 | | | |
| 图内标题是否与正文图题重复 | | | |

**铁律**: 图和表表达相同数据或结论即判重复, **不**以"图看趋势, 表看数值"为由放行.

### 八、匿名信息与文件元数据

- [ ] 正文无学校/队名/姓名/指导教师
- [ ] 页眉页脚无身份信息
- [ ] PDF 元数据 (作者/标题/主题/关键字) 全部匿名
- [ ] 截图无个人信息
- [ ] 文件名不含个人姓名
- [ ] 无隐藏批注/修订记录 (Word 提交时)

### 十一、计分汇总

```markdown
- 基础分: 15
- 原子检查点扣分合计: X
- 最终规范分: Y/15, 其中 `Y = max(-9999, 15 - X)`
```

**报告中只能出现一个最终分数.**

## 5. 国赛 (CUMCM) 特殊规则

| 项 | 规则 | 判定 |
|---|---|---|
| **目录** | **严禁** | 出现即**资格风险** |
| **正文页数** | 约 30 页为**建议**, 非硬性 | 不足或略超不自动扣分, 视**信息密度**判定 |
| **附录代码** | 约 10 页核心代码 | 仅当代码混入正文且造成阅读/分页问题时扣分 |
| **支撑材料** | 独立提交, 不计入正文页数 | 缺少时标记"待核对官方规则", **不自动扣分** |
| **代码比例** | 无硬性 | 不得以"代码过长""占比高"主观扣分 |

## 6. 输入与核验边界

| 输入 | 可核验 | 不可靠核验 |
|---|---|---|
| **仅 PDF** | 页面结构 / 排版 / 页码 / 图表 / 公式 / 可见匿名 / 部分 PDF 元数据 | Word 隐藏批注 / 修订记录 / 源样式名 |
| **仅 Word** | 样式 / 字体 / 段落 / 批注 / 文档属性 | 导出后的最终 PDF 是否完全一致 |
| **PDF + Word** | 完整内容+版式交叉核对 / 元数据 / 隐藏内容 | 未提供的外部支撑文件 |

**铁律**:
- "文本抽取未发现" ≠ "视觉上确定不存在". 图表/字体/跨页/留白必须**逐页渲染**判断.
- 只 PDF 时, 不得声称已检查 Word 隐藏批注/修订记录.

## 7. 自动化建议

- **程序化可查**: 页码 / 页数 / PDF 元数据 / 图分辨率 / 字体 → `references/scripts/verify_pdf_metrics.py` (6 项体检)
- **半自动**: 摘要字数 / 图表数量 / 标题层级 / 公式编号 → LLM 半自检 (走 `llm-prompts/03-自动审稿.md` 第 2 节)
- **必须人工**: 建模可读性 / 符号定义闭环 / 优化模型集中陈述 / 图文重复 → 评委视角读

## 8. 自查表 (赛前 1 周打印贴墙)

```
□ 摘要 1 页内, 独立可读
□ 正文 25-32 页 (国赛建议 30)
□ 国赛无目录
□ 附录按功能分板块, 核心代码 ≤ 10 页
□ 标题层级 1-1.5 页/次, 三级 ≤ 2 个/页
□ 公式编号连续, 居中
□ 三线表, 顶/底/表头下三线
□ 图分辨率 ≥ 200 DPI, 图题齐全
□ 所有图/表由正文引出并解释
□ 所有非通用符号在符号表/首次出现处定义
□ 优化模型有"综上所述, 模型为"总结句
□ 参考文献格式统一, DOI/页码齐全
□ 正文字体/字号/行距符合模板
□ 段落首行缩进 2 字符
□ 页眉页脚无身份信息
□ PDF 元数据全部匿名
□ 文件名不含姓名/学校
□ Word 无隐藏批注/修订记录
□ 图与表无重复表达
□ 图文无单点堆积
```
