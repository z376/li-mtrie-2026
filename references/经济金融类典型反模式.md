# 经济金融类典型反模式 (v1.5.7.15 新增, 经济金融题类适配)

> **⚠️ 适用题类**: CUMCM/MCM/ICM **C 题 (经济金融/资产定价/风险管理/博弈论) + 货币/利率/汇率/资产组合**. 核心特征: **市场机制 + 风险/不确定性 + 概率/统计 + 优化决策**, 通常**有历史数据可用 + 决策时间窗口**, 也有**滚动决策**特征 (e.g. 每日资产配置).

> **5 道防线使用**: 防线 1 + 3 + 4 **完全适用**; 防线 2 (数据隔离, 0:00 决策) **部分适用** (滚动决策题适用, 单时点决策题不适用); 防线 5 (三口径) **部分适用** (用"风险/收益/约束"三口径替代).

---

## 1. 经济金融类典型反模式

| # | 反模式 | 防线 | 修正做法 |
|---|--------|------|---------|
| 1 | 数据来源不标 (e.g. 用某财经数据库没说授权/截止日期) | 1 | §3 报告**完整来源**: 数据库名 + 日期范围 + 字段定义 + 缺失率 |
| 2 | 单位基点错误 (e.g. 利率% vs ‰ vs bp 混用, 100bp = 1%) | 1 | **统一基点**: 利率全部 bp 或 %, 资产全部 元/万元/亿美元, 论文 §2 公式前后声明 |
| 3 | 时间序列用未来信息 (e.g. 训练用未来宏观数据做特征) | 2 (变体) | **时序严格**: 训练用 t < train_end, 测试用未来 (评阅对应章节 "数据使用" 条款) |
| 4 | 风险度量选错 (e.g. VaR 单边, 没考虑 ES/CVaR) | 1/5 | **风险/收益/约束** 三口径: VaR 或 ES + 收益均值 + 流动性/杠杆约束 |
| 5 | 假设"市场有效"过头 (e.g. 直接套 CAPM 没考虑摩擦) | 3 | 假设简化**说明理由** + 摩擦成本 (交易费/滑点) 加入模型 |
| 6 | 没考虑极端情况 (e.g. 2008/2020 黑天鹅没测) | 3 | **压力测试**: 极端场景 (e.g. 2008 危机 + 流动性枯竭) 报告模型表现 |
| 7 | 黑盒模型没可解释性 (e.g. 深度学习预测汇率, 评阅不接受) | 1 | **可解释性**: SHAP/特征 importance + 经济意义注解 (e.g. "利率敏感性") |
| 8 | 历史回测不报告 (e.g. Sharpe ratio/Max Drawdown 缺失) | 3 | §5 报告**回测指标**: 年化收益 / Sharpe / MaxDD / 胜率 + benchmark 对比 |
| 9 | 监管/合规忽略 (e.g. 巴塞尔协议/限购/熔断没说) | 1 | §1.3 报告**合规约束**: 杠杆上限/单一持仓限制/止损规则 |
| 10 | 滚动决策用未来信息 (e.g. 0:00 用当天实际收盘价做 0:00 决策) | 2 | **滚动决策题**: 用**前一天收盘价/历史均值**做 0:00 预测, 执行用当天实际 (跟调度类同) |

**典型例题**: 资产组合优化 / 风险度量 (VaR/ES) / 期权定价 / 利率期限结构 / 汇率预测 / 信用评分 / 博弈论 (拍卖/纳什均衡).

## 2. 跑题前自检 checklist (经济金融类)

- [ ] **数据来源完整**: §3.1 数据库 + 日期范围 + 字段定义 + 缺失率 + 来源授权
- [ ] **单位基点统一**: §2 利率 bp/%, 资产 元/万元/亿美元, 论文公式前后声明
- [ ] **时序严格性**: §3.2 训练集 t < train_end, 测试集 t > train_end, 不能用未来信息
- [ ] **风险度量**: §3.3 VaR / ES / Sharpe / MaxDD 至少 2 个指标
- [ ] **摩擦成本**: §2 报告交易费/滑点/流动性影响
- [ ] **压力测试计划**: §5 写 1-2 个极端场景 (e.g. 2008 危机 + 流动性枯竭)
- [ ] **可解释性**: §4 末尾 SHAP/importance + 经济意义注解
- [ ] **回测计划**: §5 报告年化收益/Sharpe/MaxDD + benchmark 对比
- [ ] **合规约束**: §1.3 报告杠杆/持仓/止损约束

## 3. 跑完后期望对照 checklist (经济金融类)

| 检查项 | 期望方向 | 量化判据 | 实际值 | 命中? |
|--------|---------|---------|--------|-------|
| 时序严格性 | 训练集仅历史, 测试集仅未来 | 0 数据泄露 | ___ | ☐ |
| 回测超额收益 | 模型 > benchmark | Sharpe ratio 提升 ≥ 20% | ___ | ☐ |
| 风险度量 | VaR/ES 准确 | Kupiec 检验通过 / 回测覆盖率 > 95% | ___ | ☐ |
| 极端场景 | 极端场景下不破产 | MaxDD < 30% / 流动性枯竭下能平仓 | ___ | ☐ |
| 可解释性 | top-5 特征有经济意义 | 特征与利率/汇率/波动率等挂钩 | ___ | ☐ |
| 合规约束 | 全部约束满足 | check 0 违规 | ___ | ☐ |

**不命中**: ✗ → 检查 (1) 时序是否严格 (2) 摩擦是否考虑 (3) 极端场景是否测 (4) 可解释性是否给 (5) 合规是否满足.

## 4. 滚动决策 vs 单时点决策

| 子类 | 0:00 信息边界 | 用法 |
|------|---------------|------|
| **滚动决策** (e.g. 每日资产配置/盘中交易) | **适用**: 用前一天收盘价/历史均值做 0:00 预测, 执行用当天实际 | 见 references/信息边界原则.md |
| **单时点决策** (e.g. 期权定价/IPO 估值) | **不适用**: 用题面给定的所有数据 | 见 references/优化类典型反模式.md |

## 5. 与 5 道防线的引用关系

- **防线 1 (流程修剪)**: 完整适用, 红线在 references/红线与失败模式.md
