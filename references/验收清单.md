## 自动化建议(可选)

验收手可以用脚本辅助检查,例如:

```python
# A1-A3: 编译错误计数
import subprocess
r = subprocess.run(['xelatex', '-interaction=nonstopmode', '论文.tex'],
                   cwd='论文', capture_output=True, text=True)
errors = r.stderr.count('Error') + r.stdout.count('Error')

# C1.1: 分点符号扫描
import re, glob
violations = []
for f in glob.glob('论文/[0-9]*.tex'):
    with open(f, encoding='utf-8') as fh:
        content = fh.read()
    if re.search(r'[①②③④⑤●○]', content):
        violations.append(f)

# 等等
```

自动化只做**机械检查**,数值一致性、模型合理性还是需要人工/模型判断。

## 2026 规范升级清单(避免漏项)

每次写完论文,验收手必须额外检查以下 6 项(任何一项漏掉都会被取消评奖资格):

1. ☐  .AI声明.tex 存在且在参考文献之前
2. ☐ AI工具使用详情.pdf 存在(放支撑材料)
3. ☐ 10.附录.tex 含「程序使用说明」+「支撑材料说明」
4. ☐ 编译两份:论文.tex → 论文.pdf(纸质版) + 电子版.tex → 电子版.pdf(电子版)
