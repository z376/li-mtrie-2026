# 03 问题重述自查 (Problem Restatement)

> 借鉴 BZD 数模社 `bzd-problem-restatement` v1.0 (2026-08-18).
> 生成/审核问题重述章节 (1.引言.tex 后半).

## 何时用

- 写完 1.引言.tex 的"问题重述"段
- 终审前, 检查是否**贴题**但**不抄题**
- 想要 AI 帮你重写但不知道 prompt 怎么写

## 3 段结构 (BZD 范本)

```
段 1 研究背景 (1-2 段): 应用场景 + 现实意义 + 行业现状 (200-300 字)
段 2 问题回顾 (N 段, 一问一段): 题目要求 + 已知条件 + 输出 (200-300 字/段)
段 3 研究综述 (1 段): 前人方法 + 不足 + 本文思路 (100-200 字)
```

**总字数**: 600-800 字 (不超 1 页, 国赛规范)

## 7 维诊断表

| # | 维度 | 关键检查 | 扣分点 |
|---|------|----------|--------|
| 1 | **贴题** | 题目 N 个问题全覆盖, 关键词出现 | 漏题 -2 |
| 2 | **不抄题** | 改写 + 重新组织, 不直接复制题目原文 | 大段抄题 -2 |
| 3 | **不引入新假设** | 只复述题面, 不加自己条件 | 擅自加条件 -1 |
| 4 | **不引文献** | 综述段才引, 重述段无 [N] | 重述段引文献 -1 |
| 5 | **不写答案** | 不在重述中给方法/结论 | 重述写方法 -1 |
| 6 | **保留数学符号** | 题面 $\Omega$ / $M_1$ 等保留 | 自创符号 -1 |
| 7 | **研究综述引 3-5 篇** | 前人方法覆盖近 3 年 | 综述 ≤ 2 篇 -1 |

**总分 10**, ≥ 8 绿, 6-7 黄, < 6 红.

## 改写 3 法 (BZD)

```
1. 同义替换: 题目 "建立模型" → 本文 "构建预测框架"
2. 重新组织: 题目 1+2+3 顺序 → 本文 3+1+2 (按依赖关系)
3. 抽象提升: 题目 "销量" → 本文 "时序需求响应"
```

**反例 (BZD 警告)**: "改写后还像题目原文" = 抄题, 必扣.
