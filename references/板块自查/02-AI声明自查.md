# 02 AI 工具使用声明自查 (AI Usage Disclosure)

> 借鉴 BZD 数模社 `bzd-ai-usage-disclosure` v1.0 (2026-08-18).
> 生成/审核 1 句 AI 工具使用声明 + AI工具使用详情.pdf.

## 何时用

- 写完 9.0.AI工具使用声明.tex (二者择一)
- 写完 AI工具使用详情.tex (用了 AI 必填)
- 终审前 30 分钟, 检查合规性 (国赛 2026 规范第 3 条)

## 5 项 AI 参与边界 (BZD 5 问)

| # | 问题 | 必填 | example 答案 |
|---|------|------|--------------|
| 1 | **是否参与核心模型设计** | 是/否 + 说明 | 否, AI 仅辅助代码实现 |
| 2 | **是否生成或修改程序代码** | 是/否 + 说明 | 是, 详见 §3.1-3.7 |
| 3 | **输出是否经人工审查** | 是 + 方式 | 是, 单元测试 + 解析解对照 + 5 轮 smoke test |
| 4 | **是否独立完成核心建模** | 否 (不能独立) | 公式推导 + 参数选择 + 最终结论 100% 人工 |
| 5 | **AI 使用占比** | 估算 | 资料 30% + 代码 40% + 文档 20% + 其他 10% |

## 4 类 AI 用途 (BZD 分类)

```
资料与思路: 文献检索 / 赛题条件梳理 / 候选建模思路讨论
数据与程序: 数据预处理方法比较 / 程序代码调试 / 模型检验方案讨论
检验与写作: 摘要提炼 / 图表优化 / 语言润色 / 格式与一致性检查
核心建模: (禁用, 必填"否" + 说明)
```

**位置**: 参考文献之前, 紧邻 9.0.AI工具使用声明.tex (单段 100-180 字)

## 声明 4 铁律 (BZD 警告)

1. **绝不声称 AI 独立完成核心建模** (扣分)
2. **必须说明人工审查方式** (逐行检查/重推公式/手算交叉/误差分析)
3. **不写提示词/交互记录/技术细节** (放 AI工具使用详情.pdf)
4. **不夸大不模糊** ("极大提高""全面保证" 必扣分)

## 详情 PDF 5 段结构

```latex
\section{工具信息}        % 工具名/版本/接入/使用时间
\section{使用目的与环节}  % 3 阶段 (资料/数据/写作), 真实用途
\section{主要 prompt 与过程}  % 节选 3-7 个关键 prompt + AI 响应 + 采纳/修改
\section{对 AI 输出的核验情况}  % 单元测试/解析解/手工交叉/误差分析
\section{占比与人工工作}  % 估算 5 类用途占比 + 最终决策 100% 人工
```
