## 5 段结构诊断 (每问)

| # | 段 | 关键检查 | 必填 |
|---|----|----------|------|
| 1 | **建模思路与模型选择** | 问题类型判断 + 模型选择理由 (≥ 1 句, 不能"流行") | ✓ |
| 2 | **数据处理** | 来源 + 处理方法 + 理由 + 样本量 | 仅问题 1 |
| 3 | **模型建立** | 变量 + 参数 + 目标函数 + 约束 (优化模型集中陈述) | ✓ |
| 4 | **模型求解** | 算法 + 步骤 + 参数 + 初值 + 迭代 + 终止 | ✓ |
| 5 | **结果分析** | 核心结果 + 图/表 + 关键变量 + 趋势 + 答案 | ✓ |
| 6 | **模型检验与灵敏度分析** | 检验方法 + 指标 + 灵敏度 + 稳定区间 | ✓ |

**每段 1-2 段, 总 5-8 页/问 (国赛规范: 全文 ≤ 30 页)**

## 5 大常见错误 (BZD 反例)

1. ❌ **只写经典模型原理, 不针对本题** (BZD 必扣: 评委说"套模板")
2. ❌ **优化模型不集中陈述** (BZD: 必"综上所述, 模型为: max ... s.t. ...")
3. ❌ **算法只写"用 X", 不写参数/初值/迭代/终止条件**
4. ❌ **结果图/表不解释** ("如图 3 所示" 后不写"曲线先升后降, 峰值在 X 处")
5. ❌ **检验只"模型合理"** (必须量化: MAE < 5%, 灵敏度变化 < 10%)

## 关键质量指标 (BZD 评委视角)

| 指标 | 优秀 (国一) | 合格 (省一) | 勉强 (省二) |
|------|------------|------------|------------|
| 模型针对性 | 改 ≥ 2 处经典模型适配本题 | 改 1 处 | 套原模型 |
| 数据利用 | 用 ≥ 80% 题面数据 | 用 50-80% | 用 < 50% |
| 检验完整 | 交叉验证 + 灵敏度 + 鲁棒 + 误差 | 交叉 + 灵敏度 | 仅交叉 |
| 灵敏度分析 | 3+ 参数, 量化稳定区间 | 1-2 参数 | 仅说"不敏感" |
| 创新点 | 真实改进 (机理/算法/数据) | 1 处小改 | 0 创新 |
