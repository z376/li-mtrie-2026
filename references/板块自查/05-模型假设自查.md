# 05 模型假设自查 (Model Assumption)

> 借鉴 BZD 数模社 `bzd-model-assumption-checker` v1.0 (2026-08-18).
> 模型假设章节 (3.模型假设.tex) 自查.

## 何时用

- 写完 3.模型假设.tex (国赛规范: 4-6 条 itemize 格式)
- 终审前, 检查假设是否**必要/有据/任务兼容/简化/可被后续用**
- 想确认假设不会"自打脸" (与 §6 检验矛盾)

## 5 维诊断表 (每条假设)

| # | 维度 | 关键问题 | 必填 |
|---|------|----------|------|
| 1 | **必要** | 去掉这条假设, 模型还成立吗? 不成立 = 必要 |
| 2 | **有据** | 有 §1 题目条件 / §2 数据 / §4 符号 / 现实机理论据? 不能凭空 |
| 3 | **任务兼容** | 与题目要求不矛盾? (BZD: 不能假设"忽略某约束"后题目不要求) |
| 4 | **简化** | 是简化处理而非本质假设? 本质假设放 §4 符号 (单位/坐标系) |
| 5 | **可被后续用** | §5 模型建立能用, §6 检验能验, §7 评价能评? 不能自打脸 |

**每条假设 5 维全过 = 绿, 1 维不过 = 黄 (改), ≥ 2 维不过 = 红 (删/重写)**

## 常见假设类型 (4 大类)

```
A. 数据假设: 数据无噪声 / 缺失率 < 5% / 分布近似正态
B. 模型假设: 线性 / 平稳 / 独立同分布 / 二阶矩存在
C. 环境假设: 重力 9.8 m/s² / 海平面气压 / 光速不变
D. 任务假设: 题面未明说但默认的约束 (如"球赛主场优势")
```

**BZD 警告**: D 类假设 (任务假设) 风险最高, 容易自打脸. 必须**显式说明 + 边界验证**.

## 4 大常见错误 (BZD 反例)

1. ❌ **"假设 1: 地球是平的"** — 显然假, 必删
2. ❌ **"假设 2: 数据服从正态分布"** — 无 §2 数据诊断, 必黄
3. ❌ **"假设 3: 忽略空气阻力"** — 题面未说且违反物理, 必红
4. ❌ **"假设 4: 选手发挥稳定"** — 模糊, 必黄 (改"选手发挥标准差 ≤ X")

## 数量与质量平衡

- 国赛规范: 4-6 条 (太少 = 简化不充分, 太多 = 抓不住重点)
- BZD 建议: 5 条为佳, 3 类数据 + 1 类模型 + 1 类环境
- 关键假设 ≥ 2 条标 "**关键假设**" 加粗, 其他标 "**辅助假设**"
