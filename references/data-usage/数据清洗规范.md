## 1. 总纲: 趋势数据禁用全局 IQR/箱线判据

**核心**: **单调趋势段 (升温曲线/收缩曲线/衰减曲线) 禁用全局 IQR/箱线判据**. 二阶差分"速率阶段变化"是物理现象, 不是测量错误. IQR 适用于"平稳分布 + 异常点检测", 不适用于"过程段 + 趋势识别".

**反例 (P0-2, 2026A 复盘)**:

| 场景 | 错做法 | 后果 |
|------|--------|------|
| 附件 1 (升温曲线 27 行) | `df = df[(df['T'] > Q1 - 3*IQR) & (df['T'] < Q3 + 3*IQR)]` | 升温段 (T 上升过程) 全部被判异常, 删空, 边界条件失效 |
| 附件 2 (收缩曲线 23 行) | 同上 | 快速收缩段被误删, 动力学参数估错 |

**正解**: 趋势数据**默认保留全量**, 只允许 §2 四类物理驱动的检测方法.

## 2. 四类允许检测方法 (单调趋势段内)

只有以下 4 类检测可用于单调趋势段, 其它一律禁用:

### 2.1 物理越界 (Physical Range)

- 温度 `T ∈ [T_min, T_max]` (题面给出或物理意义给出)
- 浓度 `C > 0` (非负)
- 半径 `R ∈ (0, R_0]` (内含端点)
- 水分 `X ∈ [0, 1]` (含水率无量纲)

```python
# 物理越界
mask = (df['T'] >= T_min) & (df['T'] <= T_max)
mask &= (df['C'] > 0)
mask &= (df['R'] > 0) & (df['R'] <= R_0)
df_clean = df[mask]
```

### 2.2 一阶差分突变 (Rate Z-Score)

- 计算 `dT/dt = ΔT / Δt` 一阶差分
- z-score = `(dT/dt - μ_rate) / σ_rate`, **|z| > 5** 才判异常 (远比 IQR 的 1.5 严格)
- 适用于平稳段, **不适用于过程段 (升温/收缩) 内的预期变化**

```python
# 一阶差分 z-score
dT = df['T'].diff()
mu, sigma = dT.mean(), dT.std()
z = (dT - mu) / sigma
mask = z.abs() < 5  # |z| < 5 保留
df_clean = df[mask]
```

### 2.3 物理单调性 (Monotonicity, 带容差)

- 收缩曲线: `R(t)` 不增, 给容差 `ε` (e.g. 1e-6), `R(t+1) > R(t) + ε` 才判异常
- 升温曲线: `T(t)` 不降, 给容差 `ε`
- 衰减曲线: `C(t)` 不增, 给容差 `ε`
- 强制物理约束, **不是"剔除异常", 是"剔除违反物理的错误"**

```python
# 物理单调性 (含容差)
EPS = 1e-6
mask = pd.Series(True, index=df.index)
for i in range(1, len(df)):
    if df['R'].iloc[i] > df['R'].iloc[i-1] + EPS:
        mask.iloc[i] = False  # 收缩曲线 R 上升 = 异常
df_clean = df[mask]
```

### 2.4 时间间隔一致性 + 重复值

- `Δt` 应**等间隔** (e.g. 5 min), 偏差 > 5% 提示时间戳错乱
- 完全重复行 (R, T, C 三列都同) → 删保留第 1 行 (测量重复, 不是物理)

```python
# 时间间隔 + 重复值
dt = df['t'].diff()
dt_expected = 5  # min
mask = (dt - dt_expected).abs() / dt_expected < 0.05  # ±5%
mask.iloc[0] = True  # 第一行无前驱
df_clean = df[mask].drop_duplicates(subset=['R', 'T', 'C'], keep='first')
```

## 3. 边界/驱动类数据默认保留全量

附件 M 的 `R(t)` (动边界) / 附件 2 的预报曲线 / 附件 3 的滚动预测 — 这些是**驱动类**数据, 不是"测量数据", **默认保留全量**, 不允许任何剔除:

```python
# ❌ 错: 驱动数据用 IQR
df_drive = df_drive[(df_drive['R'] > Q1 - 3*IQR) & (df_drive['R'] < Q3 + 3*IQR)]

# ✅ 对: 驱动数据保留全量, 只做 §2.1 物理越界
mask = (df_drive['R'] > 0) & (df_drive['R'] <= R_0)
df_drive = df_drive[mask]
```

**为什么**: 驱动数据是输入到模型/PDE 的边界条件, 删 1 行 = 改 1 个边界时刻 = 模型对不上. 评阅判"题意理解不深" (P0 等级).

## 4. 二阶差分"速率阶段变化"是物理现象

升温曲线常分阶段:
- 阶段 1: 表面水蒸发 (T 缓升)
- 阶段 2: 自由水蒸发 (T 平稳)
- 阶段 3: 结合水扩散 (T 缓升, 二阶导数变小)

**d²T/dt² 突变** = 阶段切换, **不是测量错误**, **不允许剔除**. IQR 对"二阶差分"天然判异常 (因为阶段 1→2 切换时 d²T/dt² 跳变大).

```python
# ❌ 错: 二阶差分也 IQR
d2T = df['T'].diff().diff()
mask = (d2T - d2T.mean()).abs() < 3 * d2T.std()  # 这会把阶段切换段全删

# ✅ 对: 二阶差分只检查物理一致性, 不剔除
d2T = df['T'].diff().diff()
# 阶段切换: d2T 突变, 但 T 仍单调 → 保留
```

## 5. 与 v1.5.8 §红线 5 (物理机理类) 协同

P0-2 数据清洗规范 + v1.5.8 §红线 5 Robin 边界离散式 = 物理机理题"输入/输出"双防:

- §红线 5 防御**输出侧**: 边界离散式错 → 表面钉死/水分负值
- P0-2 防御**输入侧**: 清洗错 → 升温段被删/收缩段被删 → 边界条件失效

两者共同构成"机理题数据-模型"全链路安全. 任何一边失守都 P0 翻车.
