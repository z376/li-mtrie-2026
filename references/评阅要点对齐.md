## 3. 评阅要点映射矩阵模板 (Step 3 必填)

每张题面 4 列映射矩阵 (写到 `求解/读题清单.md` §评阅要点对齐 子节):

| 题面要求 (题面 quote) | 评阅关注点编号 | 落位章节 | 是否显式落位? |
|---------------------|----------------|---------|--------------|
| "试分析温度场分布" | 1 物理机理 + 4 步长/量程 | §5.1.2 温度场求解 | ✓ / ✗ |
| "讨论 h 灵敏度" | 5 参数灵敏度 ±10% | §7 模型评价 §7.X | ✓ / ✗ |
| "数值计算过程" | 3 高效 (耗时+复杂度+步长依据) | §5.X.2 三件套 | ✓ / ✗ |
| "结果保留 X 位小数" | 4 结果完整性 精度 | §6 核对表 | ✓ / ✗ |

**判定规则**:
- ✗ 项 = 必须在 Step 3 起手前补写对应章节
- 跑题后 audit 阶段必跑 映射矩阵所有 ✓ → 验证 (跑题过程中不要走样)

## 5. 跑题前/跑题后 4 道防线

### 5.1 跑题前 (Step 0 必做)
- 读 `references/评阅要点对齐.md` §1-§2 (4 大通用 + 5 大专属)
- 扫 `题面 PDF` 标动词 (分析/讨论/计算/比较...), 每个动词匹配 1 个关注点

### 5.2 跑题中 (Step 1-2 必做)
- 求解阶段同时维护**关注点 3 三件套** (耗时/复杂度/步长依据)
- meta.json 落盘, 不是 print 一下就忘

### 5.3 Step 3 起手 (写论文前必做)
- 填映射矩阵 4 列 (跑题后必填表 §3)
- 任何 ✗ 项先补章节, 再写正文

### 5.4 跑题后 (Step 4 必做)
- 验证所有 ✓ 项 (论文中实际体现)
- 跑 `py -3 references/scripts/check_meta.py` 验证 meta.json 含 3 件套 (P1-7 联动)
