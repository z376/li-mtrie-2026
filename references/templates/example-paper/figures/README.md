## 命名约定

```
figures/
├── q1_<图意>.png          # 问题 1 的图, 图意用中文或拼音均可
├── q2_<图意>.png          # 问题 2
├── q3_<图意>.png
├── q4_<图意>.png
└── <图意>.png             # 跨问题共用图 (如灵敏度图)
```

- `q<N>_` 前缀 = **第 N 问**，与章节号 `5.N.2` 一一对应
- 同名字体/配色在全文保持一致（见 `references/plot/绘图规范与避坑.md`）
- DPI ≥ 200（`check_figure.py` 会查）
- 图内**不要**写 `set_title`（标题只由 `\caption` 承担，见绘图规范 §〇 第 0 条）

## 怎么用

1. 跑完求解 → 用 matplotlib / seaborn / plotly 出图
2. 导出 PNG（DPI ≥ 200）到本目录，文件名按上面的约定
3. 章节 `.tex` 里的 `\IfFileExists{...}` 会自动切换成真图（不用改 `.tex`）
4. 跑 `py -3 references/scripts/dryrun.py --mode self` → check 17（图存在）/ check 59（内容自检）/ check 67（图名对问题号）全绿
5. 在 PDF 里核对：图是否清楚、图题是否唯一、坐标轴 / 单位 / 图例是否齐全

## 删图

不用的图**从 `.tex` 里删掉 `\IfFileExists{...}` 整块**（不是只删 PNG 文件），
否则会留下空 figure 环境。删完再跑一次 dryrun，check 47（冗余图）会告诉你有没有漏删。
