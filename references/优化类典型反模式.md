# 优化类典型反模式 (v1.5.7.14 新增, 优化类题类适配)

> **⚠️ 适用题类**: CUMCM **B 题 (本科优化类)** + 路径规划/资源分配/排班/选址/调度优化类题. 核心特征: **目标函数 + 约束条件 + 决策变量** 三要素, **算法求解** (LP/IP/MIP/启发式/元启发式).

> **5 道防线使用**: 防线 1 + 3 + 4 **完全适用**; 防线 2 (数据隔离) **部分适用** (静态优化无 0:00 决策, 但**数据使用纪律**仍要遵守 — 不能用未来信息); 防线 5 (三口径) **轻度适用** (用"目标函数 + 约束合理性" 替代).

---

## 1. 优化类典型反模式

| # | 反模式 | 防线 | 修正做法 |
|---|--------|------|---------|
| 1 | 决策变量定义不清 (e.g. "路径"是节点序列还是边集合没说) | 1 | **决策变量定义表**: §2.1 完整列出每个变量 + 类型 (连续/整数/二元) + 物理意义 |
| 2 | 目标函数"简化"过头 (e.g. 改 min 5 个目标为 min 1 个) | 3 | **目标函数来源**: §2.2 写明每个目标的物理/业务含义 + 加权理由 |
| 3 | 约束条件漏写 (e.g. 漏写"容量约束"/"时序约束") | 1 | **约束条件表**: §2.3 完整列出 + 物理意义 + 数学表达式 |
| 4 | 算法选错 (e.g. NP-hard 用 LP 解) | 1/3 | **算法适用性**: LP → 凸连续; IP → 整数; 启发式 → 大规模 NP-hard; 元启发式 (GA/PSO/SA) → 难解 |
| 5 | "求解器黑盒" — 跑出结果没验证最优性 | 3 | **最优性验证**: gap < 1% (MIP) / 多随机种子 (启发式) / 下界对比 |
| 6 | 灵敏度分析缺失 (e.g. 关键参数 ±10% 没测) | 3 | **灵敏度分析**: §5 报告关键参数 (e.g. 需求量/容量) ±10% / ±20% / ±50% 输出影响 |
| 7 | 多目标加权和随意 (e.g. "经济 5 权, 时间 3 权" 没理由) | 3 | **权重来源**: 文献 / 业务规则 / AHP / Pareto 前沿 |
| 8 | 不可行解处理缺失 (e.g. 约束冲突时直接报错) | 1 | **不可行解处理**: 报告不可行实例 + 放宽约束 + 报告次优解 |
| 9 | 数据使用违规 (e.g. 用未来信息做静态优化) | 2 (变体) | **静态数据严格**: 用题面给定的"已知数据集", 不用未来信息 |
| 10 | 解的"实际可执行性"忽略 (e.g. 整数解 7.5 车辆) | 1 | **整数化**: 决策变量是整数要**显式声明** + 解释"整数化" 是否影响最优性 |

**典型例题**: 路径规划 (TSP/VRP) / 资源分配 / 排班 / 选址 / 网络流 / 库存优化 / 调度优化.

## 2. 跑题前自检 checklist (优化类)

- [ ] **决策变量定义**: §2.1 变量表完整 (名称 + 类型 + 物理意义 + 单位)
- [ ] **目标函数**: §2.2 写明每个目标的物理/业务含义 + 权重来源
- [ ] **约束条件**: §2.3 约束表完整 (数学表达式 + 物理意义)
- [ ] **算法选择**: §3 写明算法 + 适用性分析 (LP/启发式/元启发式)
- [ ] **最优性验证计划**: §3 末尾写 gap / 随机种子 / 下界对比
- [ ] **灵敏度分析计划**: §5 写关键参数 ±10% / ±20% / ±50%
- [ ] **不可行解处理**: §3 末尾写不可行实例如何处理
- [ ] **数据使用纪律**: 静态数据严格, 不用未来信息
- [ ] **期望结果方向**: §4 写"目标值 vs 已知下界" 或"gap < 1%" 等量化

## 3. 跑完后期望对照 checklist (优化类)

| 检查项 | 期望方向 | 量化判据 | 实际值 | 命中? |
|--------|---------|---------|--------|-------|
| 算法适用性 | 算法匹配问题规模 | LP/启发式/元启发式 | ___ | ☐ |
| 最优性 gap | gap < 1% (MIP) / 多 seed 一致 | 报告 gap | ___ | ☐ |
| 约束满足 | 所有约束严格满足 | check 0 违规 | ___ | ☐ |
| 灵敏度 | ±10% 输出影响在量级内 | 报告参数影响 | ___ | ☐ |
| Pareto 多目标 | Pareto 前沿合理 | 多目标不矛盾 | ___ | ☐ |
| 整数化合理 | 整数决策变量显式声明 | 整数 ≠ 连续近似 | ___ | ☐ |

**不命中**: ✗ → 检查 (1) 决策变量定义 (2) 约束是否漏 (3) 算法是否适用 (4) gap 是否合理 (5) 整数化是否合理.
