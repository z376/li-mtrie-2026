# 提交前自检清单

> 每次跑完题，准备提交前逐条对照检查。对应规范：**全国大学生数学建模竞赛论文格式规范（2026年修订稿）**。

---

## 一、论文版（论文.pdf / 电子版.pdf）共检

### 第一条 · 页面与版心

- [ ] A4 纸，单/双面均可
- [ ] 上下左右页边距 ≥ 2.5 cm
- [ ] 字号、字体、行距、颜色不做统一要求（2026 第八条：赛区可自定）

### 第二条 · 承诺书 + 编号页位置

- [ ] 论文版第 1 页 = 承诺书（含题目 / 学校 / 队员 / 指导老师 / 日期）
- [ ] 论文版第 2 页 = 编号专用页（赛区评阅编号 + 送全国评阅统一编号 + 评阅记录表）
- [ ] **电子版不包含这两页**（2026 第十条）

### 第三条 · 摘要专用页

- [ ] 论文版第 3 页 = **标题 + 摘要正文 + 关键词**（同一页）
  - 注：标题属于"摘要内容"的一部分（2026 第三条："含标题和关键词"），跟摘要同页合法
- [ ] 摘要**一律中文**，**无英文摘要/英文标题/英文关键词**
- [ ] 摘要 ≤ 900 字，原则上 ≤ 1 页
- [ ] 摘要格式：开头 ≤ 30 字 + 逐问题（针对问题X：...） + 结尾 ≤ 20 字
- [ ] 关键词 5-6 个，用分号分隔
- [ ] 页码从摘要页起算 = 1（页脚居中，阿拉伯数字）

### 第四条 · 正文

- [ ] 第 4 页起是正文
- [ ] **无目录**
- [ ] 正文 ≤ 30 页
- [ ] 正文之后是附录（页数不限）

### 第五条 / 第十一条 · 附录 + 支撑材料

- [ ] 附录含「**程序使用说明**」段（用了程序就列文件，没用就写"本论文没有用到程序"）
- [ ] 附录含「**支撑材料说明**」段（用了就列文件，没用就写"本论文没有支撑材料"）
- [ ] 支撑材料文件清单与实际压缩包内文件一致

### 第六条 · 匿名

- [ ] 摘要、正文、附录中**没有**参赛队/学校/赛区/姓名信息
- [ ] 承诺书只在论文版第 1 页；电子版不含

### 第七条 · 参考文献

- [ ] 参考文献 8-15 条
- [ ] **每条都被正文 `\cite{}` 引用**（重点检查：搜索 `\bibitem{xxx}` 中的 `xxx` 都在正文出现 `\cite{xxx}`）
- [ ] GB/T 7714-2015 格式
- [ ] **禁止** `\emph{}` / `\textbf{}` / `\textit{}` / DOI 号

### AI 工具使用规定（2026 新增）

- [ ] 「**AI 工具使用声明**」放在**参考文献之前**（不是附录）
- [ ] 二选一：
  - 没用 AI：`本参赛队在竞赛过程中未使用任何 AI 工具。`
  - 用了 AI：`本参赛队在竞赛过程中使用了 AI 工具，主要用于【语言润色、代码调试等】，详细使用情况见支撑材料。`
- [ ] 用了 AI：`支撑材料/AI工具使用详情.pdf` 必填（按 `AI工具使用详情-template.md` 模板）
- [ ] 正文中由 AI 生成的段落/公式/图有内联标注（如"本节公式由 AI 辅助生成，已人工校验"）

---

## 二、电子版（电子版.pdf）专属检查

- [ ] **第 1 页** = 标题 + 摘要 + 关键词
- [ ] **不包含**承诺书、编号专用页
- [ ] 内容与论文版**完全一致**（包括附录）
- [ ] **PDF 格式**（推荐）或 Word 格式之一
- [ ] 大小 **≤ 20MB**
- [ ] **未压缩**（PDF 本身就是压缩格式）

---

## 三、支撑材料（支撑材料.rar）专属检查

- [ ] 后缀 **`.rar`** 或 **`.zip`**
- [ ] 大小 **≤ 20MB**
- [ ] 用 **WinRAR** 或 `Compress-Archive` 压缩
- [ ] 内容包含：
  - 建模所用到的所有**可运行源程序**（.py / .m / .c / EXCEL/SPSS 命令等）
  - 自主查阅使用的数据资料（**赛题原始数据除外**）
  - 较大篇幅中间结果图表
  - `AI工具使用详情.pdf`（仅用了 AI 时需要）
- [ ] **不包含**承诺书、编号专用页
- [ ] 文件中**没有**显示参赛者/学校/赛区信息

---

## 四、LaTeX 编译检查

- [ ] 论文.tex 编译 2 次，`论文.log` 中无 `^!` Error
- [ ] 电子版.tex 编译 2 次，`电子版.log` 中无 `^!` Error
- [ ] 无致命警告：Overfull/Underfull 可接受，Error/Fatal 不能有
- [ ] 字体警告（如 `TU/SimHei(0)/b/n' undefined`）会自动 fallback，不影响输出

---

## 五、其他建议

- [ ] 文件命名：避免中文/特殊字符（commit hash 文件名要 ASCII）
- [ ] 论文总页数（含承诺+编号+摘要+正文+附录+参考文献）：通常 25-40 页
- [ ] 提交前在 PDF 阅读器里**实际翻一下**看排版效果
- [ ] 把比赛当天日期填到承诺书底部

---

## 六、复检命令

```powershell
# 检查 Error 数量
@(Get-Content 论文.log; Get-Content 电子版.log) | Select-String -Pattern '^!' | Measure-Object | Select-Object -ExpandProperty Count

# 检查支撑材料大小
(Get-Item 支撑材料.rar).Length / 1MB

# 检查 PDF 页数
$paperPages = (Get-Content 论文.log | Select-String 'Output written').Line -replace '.*\((\d+) pages\).*','$1'
$elecPages = (Get-Content 电子版.log | Select-String 'Output written').Line -replace '.*\((\d+) pages\).*','$1'
Write-Host "论文版: $paperPages 页, 电子版: $elecPages 页"
Write-Host "差 $($paperPages - $elecPages) 页（应 = 2：承诺书 + 编号页）"
```

---

**自检通过后**，你就有 3 个文件可以提交：

| 文件 | 规范依据 |
|------|----------|
| `论文/论文.pdf` | 纸质版提交 |
| `论文/电子版.pdf` | 电子版提交 |
| `支撑材料.rar` | 支撑材料 |
