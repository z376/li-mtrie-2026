# 交通运筹类典型反模式 (v1.5.7.15 新增, 交通运筹题类适配)

> **⚠️ 适用题类**: CUMCM/MCM/ICM **B 题 (本科优化类常考) + D 题 (交通/网络) + 路径规划/车流/航班/排班/物流**. 核心特征: **网络结构 + 流/路径 + 时空约束 + 多目标优化**, 通常**有大规模数据 (道路网络/航班时刻/订单) + 决策输出 (路径/调度)**.

> **5 道防线使用**: 防线 1 + 3 + 4 **完全适用**; 防线 2 (数据隔离) **部分适用** (动态调度题适用, 静态规划题不适用); 防线 5 (三口径) **轻度适用** (用"时效/成本/容量" 三口径替代).

---

## 1. 交通运筹类典型反模式

| # | 反模式 | 防线 | 修正做法 |
|---|--------|------|---------|
| 1 | **网络结构漏标** (e.g. 节点数/边数/连通性没说) | 1 | §1.3 报告**完整网络结构**: 节点数/边数/连通性/平均度/有无向 |
| 2 | **流量单位混淆** (e.g. 车辆数 vs 流量 vs 密度 混用) | 1 | **统一单位**: 论文 §2 公式前后声明 (e.g. 流量 veh/h, 密度 veh/km) |
| 3 | **动态 vs 静态混淆** (e.g. 静态规划没考虑时变需求) | 3 | §1.1 明确**动态/静态**: 动态 = 时变需求/供给; 静态 = 单时点规划 |
| 4 | **路径假设"最短"过头** (e.g. 只考虑距离, 忽略时间窗/容量) | 3 | 假设简化**说明理由** + 多目标 (距离/时间/碳排放) |
| 5 | **算法不适用** (e.g. TSP 用 LP 解, 大规模用精确解超时) | 1/3 | **算法适用性**: 节点 ≤ 20 用精确解; 20-50 用启发式; ≥ 50 用元启发式 (GA/PSO/SA) |
| 6 | **容量约束漏写** (e.g. VRP 漏车辆容量约束) | 1 | §2.3 完整**约束表**: 容量/时间窗/优先级/同时取送货 |
| 7 | **时空约束漏写** (e.g. 时间窗/班次约束/换乘约束没说) | 1 | §2.3 报告**时空约束**: 时间窗 + 班次 + 换乘/中转 |
| 8 | **多目标加权和随意** (e.g. "时效 5 权, 成本 3 权" 没理由) | 3 | **权重来源**: 文献 / 业务规则 / AHP / Pareto 前沿 |
| 9 | **没报告计算时间** (e.g. 大规模 VRP 跑 10 小时没说) | 3 | §3 报告**计算时间** + 收敛曲线 + gap 演化 |
| 10 | **可执行性忽略** (e.g. 整数解 7.5 车辆 / 时序冲突) | 1 | §3 报告**整数化** + 时序冲突检测 + 实际可执行性 |
| 11 | **滚动决策用未来信息** (e.g. 周期起点用当天实际路况做 0:00 调度) | 2 | **动态调度题**: 用**前一天历史路况**做 周期起点预测, 执行用当天实际 (跟调度类同) |

**典型例题**: TSP/VRP / 最短路径 / 最大流 / 交通分配 / 航班排班 / 公交调度 / 应急疏散 / 仓储拣货.

## 2. 跑题前自检 checklist (交通运筹类)

- [ ] **网络结构完整**: §1.3 节点数/边数/连通性/平均度/有无向 报告
- [ ] **流量单位统一**: §2 流量 veh/h, 密度 veh/km, 速度 km/h, 论文公式前后声明
- [ ] **动态/静态明确**: §1.1 区分动态 (时变需求/供给) vs 静态 (单时点)
- [ ] **路径假设**: §1.2 多目标 (距离/时间/碳排放) + 简化理由
- [ ] **算法选择**: §3 写明算法 + 适用性 (精确/启发式/元启发式) + 收敛曲线
- [ ] **容量约束表**: §2.3 车辆容量/时间窗/优先级/同时取送货 完整
- [ ] **时空约束表**: §2.3 时间窗/班次/换乘/中转 完整
- [ ] **多目标权重来源**: §2 文献/业务规则/AHP/Pareto
- [ ] **计算时间**: §3 报告计算时间 + 收敛曲线 + gap 演化
- [ ] **整数化合理性**: §3 整数决策变量显式声明
- [ ] **动态调度时序严格**: 用前一天路况做预测, 执行用当天实际

## 3. 跑完后期望对照 checklist (交通运筹类)

| 检查项 | 期望方向 | 量化判据 | 实际值 | 命中? |
|--------|---------|---------|--------|-------|
| 算法适用性 | 算法匹配问题规模 | 精确/启发式/元启发式 | ___ | ☐ |
| gap | 多种子 gap < 1% | 报告 gap 演化 | ___ | ☐ |
| 约束满足 | 所有约束严格满足 | check 0 违规 | ___ | ☐ |
| 计算时间 | 在题目限定时间内 | ≤ 60 min / ≤ 24 小时 | ___ | ☐ |
| Pareto | 多目标 Pareto 前沿合理 | 时效 vs 成本不矛盾 | ___ | ☐ |
| 整数化 | 整数决策变量显式 | 整数 ≠ 连续近似 | ___ | ☐ |
| 时空一致 | 时序/空间约束 0 冲突 | check 0 冲突 | ___ | ☐ |
| 滚动预测 | 动态调度 0 数据泄露 | 用前一天历史 (无未来) | ___ | ☐ |

**不命中**: ✗ → 检查 (1) 网络结构是否完整 (2) 算法是否适用 (3) 约束是否漏 (4) 多目标权重是否合理 (5) 时空冲突.

## 4. 动态调度 vs 静态规划

| 子类 | 周期起点信息边界 | 典型例 |
|------|---------------|--------|
| **动态调度** (e.g. 实时派单/动态路径) | **适用**: 用前一天历史路况做 周期起点预测, 执行用当天实际 | 见 references/信息边界原则.md |
| **静态规划** (e.g. 战略网络规划/年度排班) | **不适用**: 用题面给定的所有数据 | 见 references/优化类典型反模式.md |

---

## 5. 与优化类 / 调度类 的关系

| 维度 | 优化类 | 交通运筹类 | 调度类 |
|------|--------|----------|--------|
| **网络** | 通常无 | **核心特征** | 通常无 |
| **时空约束** | 弱 | **强** (时间窗/班次) | 弱 |
| **数据规模** | 小-中 | **大** (万级节点) | 中-大 |
| **算法** | LP/MIP | **元启发式 (GA/PSO)** | LP/MPC |
| **滚动决策** | 通常无 | **动态子类适用** | **核心特征** |
