## 3. 跑题前自检 checklist (5 分钟)

跑题前**必做**, 任何一项 ✗ 都要补:

- [ ] **防线 1 (流程)**: 装包 checkable 已跑, 输出 `core ok`
- [ ] **防线 2 (数据)**: 0:00 信息边界列表已填 (历史/预报/当天实际 三类)
- [ ] **防线 2 (数据)**: 各问题用哪个附件已明确 (Q2 = 1+2, Q3 = 1+2+3, Q4 = 1+2+3+4)
- [ ] **防线 3 (设计)**: N 个问题的**递进关系图**已画 (基线 → 机制 → 优化 → 加维度?)
- [ ] **防线 3 (设计)**: 每个问题**测什么** 1-2 句话已写
- [ ] **防线 3 (设计)**: 每个问题**期望方向 + 量化值** 已列 (e.g. "Q3 紧急购电 < Q2 30%+")
- [ ] **防线 4 (指针)**: 已读 SKILL.md frontmatter description + §Step 0 必读 3 文件
- [ ] **防线 5 (口径)**: 总费 = 计划 + 紧急 + 调整 三口径已分开记账
- [ ] **防线 5 (物理)**: 数据物理不真实标注位置已确定 (论文 §5.2.2)
- [ ] **跑题目录**: `求解/读题清单.md` 5 列已填 (含 "题面禁项" + "题目设计意图")

## 4. 跑完后期望对照 checklist (10 分钟)

跑完每个问题**必做**, 不达预期 = **回头改方法**:

| 问题 | 期望方向 | 量化判据 | 实际值 | 命中? |
|------|---------|---------|--------|-------|
| Q1 | 总费最优 | 跟官方参考值 ± 5% | ___ | ☐ |
| Q2 | 紧急购电 > 0 (物理真实) | 紧急购电天数 > 50% | ___ | ☐ |
| Q3 | 紧急购电 < Q2 (滚动压缩) | 下降 ≥ 30% | ___ | ☐ |
| Q3 | 调整偏差费 ≤ 紧急购电费 (净收益) | 调整偏差 ≤ 紧急购电 | ___ | ☐ |
| Q4-3 | 紧急购电转移到低价时段 | 时段分布变化 ≠ Q3 | ___ | ☐ |

**不命中**: ✗ → 回头看 references/题目设计意图分析.md §4.3 修正方案 (换数据源 / 减滚动次数 / 改初始 SOC / 加套利层), **不能**接受"现实如此".
