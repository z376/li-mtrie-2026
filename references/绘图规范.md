# 论文绘图规范

> 论文里所有图都是 **`\includegraphics{0.8\textwidth}`** ≈ 12cm × 9cm。matplotlib
> 默认 10pt 字号在这个尺寸下**打印模糊**，必须按本规范调大。

**`code-template.py` 顶部已经预设好**所有推荐值（`plt.rcParams.update(...)`），
复制模板时直接带上即可。下面是规范的"为什么"和"怎么验证"。

---

## 一、字号规范

### 基础字号表

| 元素 | rcParams key | 最小（pt） | **推荐（pt）** | 说明 |
|------|--------------|-----------|----------------|------|
| 基础字号 | `font.size` | 12 | **14** | 全局默认 |
| 坐标轴标签 | `axes.labelsize` | 13 | **16** | xlabel / ylabel |
| x 轴刻度 | `xtick.labelsize` | 12 | **14** | |
| y 轴刻度 | `ytick.labelsize` | 12 | **14** | |
| 图例 | `legend.fontsize` | 12 | **13** | 多图例再大 |
| 子图标题 | `axes.titlesize` | 13 | 16 | 一般不用，论文 caption 承担 |
| 总标题 | `figure.titlesize` | 14 | 16 | 同上 |

### 为什么是这些数字

- 论文图实际打印大小 ≈ 12cm × 9cm
- 14pt 文字在 12cm 宽图上 ≈ 3-4mm 高，**正常视力 30cm 阅读距离清晰可读**
- 10pt 文字 ≈ 2-2.5mm 高，**接近视力极限**，打印模糊

### 如果用 seaborn

seaborn 主题（`whitegrid` / `darkgrid` / `white` / `dark`）会覆盖 matplotlib 的部分 rcParams。
设置方式：

```python
import seaborn as sns
sns.set_theme(style='whitegrid', font='SimHei', font_scale=1.2)
# font_scale=1.2 会在默认基础上放大 1.2 倍
# 然后再用 plt.rcParams 覆盖 seaborn 没设的字段
plt.rcParams['axes.unicode_minus'] = False
```

### 如果用 plotly

plotly 的字号是 pixel 单位，跟 matplotlib 不一样。设置方式：

```python
import plotly.graph_objects as go
fig.update_layout(
    font=dict(family='SimHei', size=16),  # 整体 16px
    xaxis=dict(title_font_size=18, tickfont_size=14),
    yaxis=dict(title_font_size=18, tickfont_size=14),
    legend=dict(font_size=14),
)
```

## 二、线条 / 标记 / 边框

| 元素 | rcParams key | 最小 | **推荐** |
|------|--------------|------|----------|
| 折线粗细 | `lines.linewidth` | 1.5 | **2.0** |
| 标记点大小 | `lines.markersize` | 6 | **8** |
| 坐标轴边框 | `axes.linewidth` | 1.0 | 1.2 |
| 主刻度线宽 | `xtick.major.width` | 0.8 | 1.0 |
| 网格线宽 | `grid.linewidth` | 0.4 | 0.6 |

**折线必须带标记点**（`marker='o'` / `'s'` / `'^'`），纯线条在黑白打印里看不出区分。

## 三、保存 DPI

| 用途 | rcParams key | 最小 | **推荐** |
|------|--------------|------|----------|
| 屏幕显示 | `figure.dpi` | 100 | 120 |
| **文件保存** | `savefig.dpi` | 150 | **200** |
| 黑白打印冗余 | `savefig.dpi` | 300 | 300（彩色不需要） |

**200 DPI 是论文图的"甜点"**：
- 72 DPI（屏幕默认）：肉眼可见像素
- 150 DPI：A4 打印基本清晰，但 12pt 文字边缘略糊
- 200 DPI：12pt 文字锐利，**论文够用**，文件不大（每张图 100-300 KB）
- 300 DPI：印刷级，文件大（每张 300-800 KB），没必要

**检查方法**：
1. 保存后用图片查看器打开 PNG
2. 放大到 100%（即论文实际打印大小）看数字
3. 如果标签/数字边缘糊，立刻调高 `savefig.dpi` + 重画

## 四、保存方式

**强制要求**：
- `bbox='tight'`：自动裁掉多余白边
- `facecolor='white'`：背景纯白（避免透明背景在 PDF 里渲染异常）
- `pad_inches=0.1`：保留少量留白（防止裁到标签边缘）

**示例**：

```python
import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(8, 5))
# ... 画图 ...
fig.savefig('out.png', dpi=200, bbox_inches='tight',
            facecolor='white', pad_inches=0.1)
plt.close(fig)
```

或者用 `code-template.py` 里提供的 `save_fig` 工具函数：

```python
save_fig(fig, '问题X_销售额预测.png')  # dpi=200 + bbox='tight' 都内置
```

## 五、中文字体

### matplotlib 设置

```python
plt.rcParams['font.sans-serif'] = ['SimHei', 'Microsoft YaHei',
                                     'Arial Unicode MS', 'DejaVu Sans']
plt.rcParams['font.family'] = 'sans-serif'
plt.rcParams['axes.unicode_minus'] = False  # 负号正常显示
```

**字体选择优先级**：
1. `SimHei`（Windows 默认中易黑体，**最常用**）
2. `Microsoft YaHei`（Windows 微软雅黑）
3. `Arial Unicode MS`（macOS 兜底）
4. `DejaVu Sans`（Linux 兜底，**不支持中文**，仅作 fallback）

**Linux/Mac 跨平台**：
- 装 `wqy-microhei` 或 `noto-cjk` 包
- 或下载思源宋体/思源黑体 .ttf / .otf，用 `matplotlib.font_manager.fontManager.addfont()` 注册

**注意**：西文字体（Times New Roman、Latin Modern）不包含中文字符，会显示成方块。

### seaborn


## 六、配色

### 推荐配色（按色盲友好度排序）

| 配色 | 适合场景 | 引用方式 |
|------|----------|----------|
| `tab10` | **默认首选**，10 种区分明显的色 | `plt.cm.tab10` / `sns.color_palette("tab10")` |
| `viridis` | 渐变色，适合热力图 / 连续值 | `plt.cm.viridis` |
| `RdBu_r` | 双向色，适合有正负/高低对比 | `plt.cm.RdBu_r` |
| `Set3` | 柔和色，适合分类多 | `plt.cm.Set3` |
| `husl` | 均匀色相 + 亮度 | `sns.color_palette("husl")` |

### 单色填充 + 渐变

热力图 / 等高线用 `viridis` / `plasma` / `inferno` 渐变。
柱状图/饼图用 `tab10` / `Set3` 离散色。

### 避免的配色

- 纯红 + 纯绿（色盲不友好）
- 高饱和荧光色（打印容易糊）
- 浅黄底 + 白字（对比度不够）

## 七、常见图类型

### 折线图（时间序列 / 趋势）

```python
fig, ax = plt.subplots(figsize=(8, 5))
ax.plot(x, y1, marker='o', label='真实值', color='#1f77b4', linewidth=2)
ax.plot(x, y2, marker='s', label='预测值', color='#ff7f0e',
        linewidth=2, linestyle='--')
ax.fill_between(x, y1, y2, alpha=0.2, color='gray', label='误差区间')
ax.set_xlabel('日期')
ax.set_ylabel('销售额 / 万元')
ax.legend(loc='best')
ax.grid(True, alpha=0.3)
save_fig(fig, '预测对比.png')
```

### 柱状图（分类对比）

```python
fig, ax = plt.subplots(figsize=(8, 5))
bars = ax.bar(categories, values, color='#1f77b4', edgecolor='white', linewidth=1.2)
ax.set_xlabel('分类')
ax.set_ylabel('数值')
# 柱顶加数字
for bar, val in zip(bars, values):
    ax.text(bar.get_x() + bar.get_width()/2, bar.get_height(),
            f'{val:.1f}', ha='center', va='bottom', fontsize=14)
ax.grid(True, alpha=0.3, axis='y')  # 只 y 轴网格
save_fig(fig, '分类对比.png')
```

### 散点图（相关性）

```python
fig, ax = plt.subplots(figsize=(8, 5))
ax.scatter(x, y, s=40, alpha=0.6, c=colors, edgecolors='white', linewidths=0.5)
# 加回归线
import numpy as np
coef = np.polyfit(x, y, 1)
ax.plot(x, np.poly1d(coef)(x), 'r--', linewidth=2, label=f'y={coef[0]:.2f}x+{coef[1]:.2f}')
ax.set_xlabel('自变量')
ax.set_ylabel('因变量')
ax.legend()
save_fig(fig, '散点图.png')
```

### 热力图（相关性矩阵）

```python
import seaborn as sns
fig, ax = plt.subplots(figsize=(8, 6))
sns.heatmap(corr_matrix, annot=True, fmt='.2f', cmap='RdBu_r',
            center=0, square=True, cbar_kws={'shrink': 0.8},
            annot_kws={'size': 12}, ax=ax)
save_fig(fig, '相关性热力图.png')
```

## 八、自检清单

每张图保存后，**强制检查**：

- [ ] **缩放到 100%**（即论文实际大小）数字/标签**清晰可读**
- [ ] **坐标轴标签**完整、有单位（如"销售额 / 万元"）
- [ ] **图例**有，不混淆
- [ ] **中文字符**不显示成方块 □
- [ ] **负号** `-` 不显示成奇怪的方块
- [ ] **图片宽高比** ≈ 4:3 或 16:9（避免细长条）
- [ ] **文件大小** < 500 KB（避免 PDF 太大）
- [ ] **保存到 `求解/问题X/图片/`**（论文通过相对路径引用）

## 九、完整画图模板

```python
import pandas as pd
import numpy as np
import os
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt

# === 1) 论文图片专用配置 ===
plt.rcParams.update({
    'font.sans-serif': ['SimHei', 'Microsoft YaHei', 'DejaVu Sans'],
    'font.family': 'sans-serif',
    'axes.unicode_minus': False,
    'font.size': 14,
    'axes.labelsize': 16,
    'xtick.labelsize': 14,
    'ytick.labelsize': 14,
    'legend.fontsize': 13,
    'lines.linewidth': 2.0,
    'lines.markersize': 8,
    'axes.linewidth': 1.2,
    'grid.linewidth': 0.6,
    'figure.dpi': 120,
    'savefig.dpi': 200,
    'savefig.bbox': 'tight',
    'savefig.pad_inches': 0.1,
    'savefig.facecolor': 'white',
    'figure.constrained_layout.use': True,
})

# === 2) 目录 ===
BASE = os.path.dirname(os.path.abspath(__file__))
FIG_DIR = os.path.join(BASE, '图片')
os.makedirs(FIG_DIR, exist_ok=True)

# === 3) 画图 ===
df = pd.read_csv('data.csv')
fig, ax = plt.subplots(figsize=(8, 5))
ax.plot(df['x'], df['y'], marker='o', label='真实', color='#1f77b4')
ax.plot(df['x'], df['y_pred'], '--', marker='s', label='预测', color='#ff7f0e')
ax.set_xlabel('时间')
ax.set_ylabel('数值 / 单位')
ax.legend(loc='best')
ax.grid(True, alpha=0.3)

# === 4) 保存 ===
fig.savefig(os.path.join(FIG_DIR, '对比图.png'),
            dpi=200, bbox_inches='tight', facecolor='white', pad_inches=0.1)
plt.close(fig)
```

或者用 `code-template.py` 里的 `save_fig` 函数（更简洁）。
