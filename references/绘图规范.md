## 〇、画图前的决策三轴 + 18 条陷阱（速查）

**画图前先看这节**——不看你画完会发现图跟想说的论点对不上。

### 决策三轴（每次画图前问自己 3 个问题）

#### 轴 1：变量数与类型 → 推荐图型

| 组合 | 变量结构 | 论证目标 | 推荐图型 |
|------|----------|----------|----------|
| 1×连续 | 1 个连续变量 | 看分布 | **KDE / 直方图 / 箱线图** |
| 1×分类 | 1 个分类变量 | 看占比 | **横向柱状图**（按值排序） |
| 1×分类 + 1×连续 | 组间比较 | 1 分类 vs 1 连续 | **箱线图 + stripplot 叠加原始点** |
| 2×连续 | 2 个连续变量 | 看关系 | **散点图 + 回归线** |
| 1×时间 + 1×连续 | 时序趋势 | 看趋势 | **折线图 + 误差带** |
| 多个连续（3-20） | 多变量关系 | 相关性 | **相关性热力图** |
| 二维矩阵 | n×m 数据 | 模式 | **热力图**（perceptually uniform colormap） |
| 构成 | 总和分解 | 部分占比 | **堆叠柱状图 / treemap** |
| 二分类预测性能 | 分类器评估 | 性能 | **ROC / PR 曲线** |

#### 轴 2：样本量 → 图型选择（**最重要的轴**）

| 每组样本量 n | 推荐 | 不要做 |
|--------------|------|--------|
| **n ≥ 30** | 箱线图 / 小提琴图 / 误差棒柱 | 都可以 |
| **10 ≤ n < 30** | 箱线图 / 小提琴图 + **必须叠加 stripplot** | 不要只画均值柱（掩盖分布） |
| **3 ≤ n < 10** | **stripplot / dot plot** | 箱线图统计意义不足，慎用 |
| **n < 3** | **直接散点展示每个点** | 不要画统计图 |
| 总数据 > 10 万 | 散点 alpha=0.1-0.3 防 overplot | 改 hexbin / 2D KDE |

**强制规则**：n < 30 时**任何均值柱都强制叠加原始点**——
否则 3 个点和 300 个点画出来一样高，掩盖真实分布。

#### 轴 3：论证目标 → 图型约束

| 论证目标 | 推荐图型 | 不要做 |
|----------|----------|--------|
| "这组数据长啥样" | 直方图 / KDE | 折线图（x 不是时间/有序） |
| "A 比 B 高/低" | 箱线 + 显著性 | 简单均值柱 |
| "X 越大 Y 越大" | 散点 + 回归 | 折线图（x 是连续变量且无序） |
| "随时间变化" | 折线 + 误差带 | 箱线图 |
| "总和被分成几份" | 堆叠柱 | **饼图**（角度感知比长度差 3 倍） |
| "哪些变量相关" | 热力图 / pairplot | 平行坐标（除非有交互） |
| "组间差异是否显著" | 箱线 + 显著性标注 | 箱线不带 p 值 |
| "估计有多不确定" | 误差棒 / 置信带 | 点估计（裸数） |

### 18 条画图陷阱清单（**主动拦截**——画完对照自检）

| # | 陷阱 | 严重度 | 正确做法 |
|---|------|--------|----------|
| P1 | **均值柱掩盖分布**（每组一根柱 + 误差棒，无原始点） | **FAIL** | n<30 必须叠加 stripplot；2020 起 PLoS/Nature 已禁 |
| P2 | **双 Y 轴**（左右两轴标尺不同） | **FAIL** | 拆子图 / 共享 x 轴 / 标准化到 [0,1]；Tufte 1983 就批评 |
| P3 | **饼图 / 3D 饼图**（角度判断误差 3 倍于长度） | **FAIL** | 横向柱状图（按值排序） |
| P4 | **Y 轴不当截断**（从非 0 起始放大差异） | **WARN** | 比例/概率/准确率从 0 起；跨数量级用 log |
| P5 | **颜色映射无 colorbar** | **WARN** | 任何 hue=col 时必须配 colorbar + label |
| P6 | **离散点连成折线**（x 是分类却用 `plt.plot`） | **FAIL** | 分类 x → 散点 / 箱线 / dot plot |
| P7 | **过度用色**（>7 种颜色无法稳定记忆） | **WARN** | 类别 ≤5 用色+双重编码（线型+marker）；6-12 用直接标注；>12 拆图 |
| P8 | **图例缺失或不规范** | **WARN** | 每个图必须有图例，多系列用 `bbox_to_anchor` 放外侧 |
| P9 | **误差棒类型不交代**（SD vs SEM vs CI） | **WARN** | 图注必须写清是 SD / SEM / 95% CI |
| P10 | **chartjunk**（3D 边框、网格、阴影、装饰） | **WARN** | 删！只留必要元素 |
| P11 | **分辨率不达标**（PNG DPI < 200） | **WARN** | 数模国赛用 DPI ≥ 200，论文图 ≥ 300 |
| P12 | **一图多论点**（一图承载太多信息） | **WARN** | 一图一论点；维度太多拆子图 |
| P13 | **红绿对比不做色盲检查** | **WARN** | 配色用 `palette="colorblind"`（seaborn） |
| P14 | **rainbow / jet 色图**（感知非线性） | **WARN** | 改用 viridis / plasma（perceptually uniform） |
| P15 | **显著性符号错用**（ns / \* / \*\* / \*\*\* 含义不清） | **WARN** | 必须在图注说明对应 p 值阈值 |
| P16 | **缺字/方框**（中文字体未配） | **FAIL** | `plt.rcParams['font.sans-serif'] = ['SimHei']` + `axes.unicode_minus = False` |
| P17 | **文字裁切/图例遮盖** | **WARN** | 用 `constrained_layout=True` 或 `tight_layout` |
| P18 | **多面板子图编号不对齐** | **WARN** | 用 `gridspec` 或 `subplots_adjust` 严格对齐 |

## 一、字号规范

### 基础字号表

| 元素 | rcParams key | 最小（pt） | **推荐（pt）** | 说明 |
|------|--------------|-----------|----------------|------|
| 基础字号 | `font.size` | 12 | **14** | 全局默认 |
| 坐标轴标签 | `axes.labelsize` | 13 | **16** | xlabel / ylabel |
| x 轴刻度 | `xtick.labelsize` | 12 | **14** | |
| y 轴刻度 | `ytick.labelsize` | 12 | **14** | |
| 图例 | `legend.fontsize` | 12 | **13** | 多图例再大 |
| 子图标题 | `axes.titlesize` | 13 | 16 | 一般不用，论文 caption 承担 |
| 总标题 | `figure.titlesize` | 14 | 16 | 同上 |

### 为什么是这些数字

- 论文图实际打印大小 ≈ 12cm × 9cm
- 14pt 文字在 12cm 宽图上 ≈ 3-4mm 高，**正常视力 30cm 阅读距离清晰可读**
- 10pt 文字 ≈ 2-2.5mm 高，**接近视力极限**，打印模糊

### 如果用 seaborn

seaborn 主题（`whitegrid` / `darkgrid` / `white` / `dark`）会覆盖 matplotlib 的部分 rcParams。
设置方式：

```python
import seaborn as sns
sns.set_theme(style='whitegrid', font='SimHei', font_scale=1.2)
# font_scale=1.2 会在默认基础上放大 1.2 倍
# 然后再用 plt.rcParams 覆盖 seaborn 没设的字段
plt.rcParams['axes.unicode_minus'] = False
```

### 如果用 plotly

plotly 的字号是 pixel 单位，跟 matplotlib 不一样。设置方式：

```python
import plotly.graph_objects as go
fig.update_layout(
    font=dict(family='SimHei', size=16),  # 整体 16px
    xaxis=dict(title_font_size=18, tickfont_size=14),
    yaxis=dict(title_font_size=18, tickfont_size=14),
    legend=dict(font_size=14),
)
```

## 二、线条 / 标记 / 边框

| 元素 | rcParams key | 最小 | **推荐** |
|------|--------------|------|----------|
| 折线粗细 | `lines.linewidth` | 1.5 | **2.0** |
| 标记点大小 | `lines.markersize` | 6 | **8** |
| 坐标轴边框 | `axes.linewidth` | 1.0 | 1.2 |
| 主刻度线宽 | `xtick.major.width` | 0.8 | 1.0 |
| 网格线宽 | `grid.linewidth` | 0.4 | 0.6 |

**折线必须带标记点**（`marker='o'` / `'s'` / `'^'`），纯线条在黑白打印里看不出区分。

## 三、保存 DPI

| 用途 | rcParams key | 最小 | **推荐** |
|------|--------------|------|----------|
| 屏幕显示 | `figure.dpi` | 100 | 120 |
| **文件保存** | `savefig.dpi` | 150 | **200** |
| 黑白打印冗余 | `savefig.dpi` | 300 | 300（彩色不需要） |

**200 DPI 是论文图的"甜点"**：
- 72 DPI（屏幕默认）：肉眼可见像素
- 150 DPI：A4 打印基本清晰，但 12pt 文字边缘略糊
- 200 DPI：12pt 文字锐利，**论文够用**，文件不大（每张图 100-300 KB）
- 300 DPI：印刷级，文件大（每张 300-800 KB），没必要

**检查方法**：
1. 保存后用图片查看器打开 PNG
2. 放大到 100%（即论文实际打印大小）看数字
3. 如果标签/数字边缘糊，立刻调高 `savefig.dpi` + 重画

## 四、保存方式

**强制要求**：
- `bbox='tight'`：自动裁掉多余白边
- `facecolor='white'`：背景纯白（避免透明背景在 PDF 里渲染异常）
- `pad_inches=0.1`：保留少量留白（防止裁到标签边缘）

**示例**：

```python
import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(8, 5))
# ... 画图 ...
fig.savefig('out.png', dpi=200, bbox_inches='tight',
            facecolor='white', pad_inches=0.1)
plt.close(fig)
```

或者用 `code-template.py` 里提供的 `save_fig` 工具函数：

```python
save_fig(fig, '问题X_销售额预测.png')  # dpi=200 + bbox='tight' 都内置
```

## 十二、机理题专用图型

> 适用：A 题（机理建模）、B 题（工程系统）、美赛连续/离散型机制
> 与数据驱动题（评价/预测/分类）不同，机理题**没有"原始数据散点"**，
> 通常画的是"物理量随时间/空间的演化"或"几何轨迹"。

### 1. 几何轨迹图（机理题最常用）

```python
fig, ax = plt.subplots(figsize=(10, 8))
# 画螺线 / 曲线 / 折线
for ti, t in enumerate(times):
    if int(t) not in [0, 60, 120, 180, 240, 300]:
        continue
    xs = positions[ti, :, 0]
    ys = positions[ti, :, 1]
    ax.plot(xs, ys, '-o', markersize=4, linewidth=1.5, alpha=0.7,
            label=f't={int(t)}s')
ax.set_xlabel('x (m)')
ax.set_ylabel('y (m)')
ax.set_aspect('equal')   # 几何图必须等比！否则弧形会失真
ax.grid(True, alpha=0.3)
ax.legend()
```

**关键点**：
- **`ax.set_aspect('equal')` 几乎必须**——不等比会让圆/椭圆/螺线失真
- 多时刻叠加用不同颜色 + 标签
- 几何图常用大尺寸 figsize=(10, 8) 展示完整轨迹

### 2. 时间序列（速度/位置/角度 vs 时间）

```python
fig, ax = plt.subplots(figsize=(10, 5))
ax.plot(times, speeds[:, 0], label='龙头', linewidth=2)
ax.plot(times, speeds[:, -1], label='龙尾', linewidth=2, linestyle='--')
ax.fill_between(times, speeds.min(axis=1), speeds.max(axis=1),
                alpha=0.2, color='gray', label='所有把手范围')
ax.set_xlabel('时间 (s)')
ax.set_ylabel('速度 (m/s)')
ax.grid(True, alpha=0.3)
ax.legend()
```

**关键点**：
- 多个把手**用 fill_between 显示范围**（评委会一眼看全）
- 关键点（如 t=终止）用 axvline 标

### 3. 相位图 / 参数空间图

```python
fig, ax = plt.subplots(figsize=(8, 8))
# 参数空间探索: 如 (p_min, v_max) 平面
p_values = np.linspace(0.1, 2.0, 50)
v_values = np.linspace(0.5, 2.0, 50)
P, V = np.meshgrid(p_values, v_values)
Z = some_metric(P, V)  # 如可行性 0/1 或最大速度
im = ax.contourf(P, V, Z, levels=20, cmap='viridis')
ax.set_xlabel('螺距 p (m)')
ax.set_ylabel('龙头速度 v (m/s)')
plt.colorbar(im, ax=ax, label='可行性')
```

**关键点**：
- 用 `contourf` 画参数空间可行性
- 找最优点（标记 + axvline/axhline）

### 4. 场图 / 等高线（温度场 / 速度场 / 浓度场）

```python
fig, ax = plt.subplots(figsize=(10, 8))
im = ax.contourf(X, Y, Z, levels=20, cmap='viridis')  # 感知均匀
# 必须配 colorbar！
plt.colorbar(im, ax=ax, label='数值 (单位)')
# 叠加等高线
cs = ax.contour(X, Y, Z, levels=10, colors='white', linewidths=0.5)
ax.clabel(cs, inline=True, fontsize=8)
ax.set_xlabel('x')
ax.set_ylabel('y')
ax.set_aspect('equal')
```

**关键点**：
- **`colorbar 必须有 label + 单位**（P5 陷阱）
- 等高线数值用 `ax.clabel` 标注
- viridis 不是 rainbow（perceptually uniform）

### 5. 杆/桁架/网络的连接关系图

```python
import networkx as nx
G = nx.Graph()
# 加节点
for i in range(n_nodes):
    G.add_node(i, pos=(xs[i], ys[i]))
# 加边
for i, j in connections:
    G.add_edge(i, j, weight=w_ij)
# 画
pos = nx.get_node_attributes(G, 'pos')
nx.draw_networkx(G, pos,
                 node_color='lightblue',
                 edge_color='gray',
                 width=[2 * G[i][j]['weight'] for i, j in G.edges()],
                 with_labels=True)
ax.set_aspect('equal')
```

**关键点**：
- 用 networkx 画图论问题
- 边权可视化为宽度
- 节点大小/颜色可映射到节点属性

### 6. 动画（机理过程演示，可选）

```python
from matplotlib.animation import FuncAnimation
fig, ax = plt.subplots(figsize=(8, 8))
ax.set_aspect('equal')
ax.set_xlim(-15, 15)
ax.set_ylim(-15, 15)
line, = ax.plot([], [], 'o-', markersize=4)

def update(frame):
    line.set_data(positions[frame, :, 0], positions[frame, :, 1])
    return line,

ani = FuncAnimation(fig, update, frames=len(times),
                    interval=100, blit=True)
ani.save('问题X_动画.gif', writer='pillow', fps=10)
```

**关键点**：
- 96h 比赛时**不建议**做动画（耗时间）
- **如果做**：用 GIF 而非 MP4（兼容性）
- 论文里**用静态图**（关键时刻快照）

### 7. 机理题常见错误（**主动拦截**）

| 错误 | 后果 | 正确做法 |
|------|------|----------|
| 几何图忘了 `set_aspect('equal')` | 螺线变椭圆，圆变椭圆 | 一律等比 |
| 多条轨迹无颜色区分 | 黑色一片 | 用 `tab10` 调色板 + 标签 |
| 时间序列用 1000 颜色映射 1000 点 | 噪声大 | 用主题色 + 透明度 |
| 速度图用线性 y 轴 | 看不到 0.01 vs 100 的差异 | 用 `symlog` 或拆子图 |
| 等高线无数值 | 不知道 Z=多少 | `ax.clabel` |
| 网络图画成歪的 | 节点位置乱 | 用 `nx.spring_layout` 或真实坐标 |

## 五、中文字体

### matplotlib 设置

```python
plt.rcParams['font.sans-serif'] = ['SimHei', 'Microsoft YaHei',
                                     'Arial Unicode MS', 'DejaVu Sans']
```

**字体选择优先级**：
1. `SimHei`（Windows 默认中易黑体，**最常用**）
2. `Microsoft YaHei`（Windows 微软雅黑）
3. `Arial Unicode MS`（macOS 兜底）
4. `DejaVu Sans`（Linux 兜底，**不支持中文**，仅作 fallback）

**Linux/Mac 跨平台**：
- 装 `wqy-microhei` 或 `noto-cjk` 包
- 或下载思源宋体/思源黑体 .ttf / .otf，用 `matplotlib.font_manager.fontManager.addfont()` 注册

**注意**：西文字体（Times New Roman、Latin Modern）不包含中文字符，会显示成方块。

## 六、配色

### 推荐配色（按色盲友好度排序）

| 配色 | 适合场景 | 引用方式 |
|------|----------|----------|
| `tab10` | **默认首选**，10 种区分明显的色 | `plt.cm.tab10` / `sns.color_palette("tab10")` |
| `viridis` | 渐变色，适合热力图 / 连续值 | `plt.cm.viridis` |
| `RdBu_r` | 双向色，适合有正负/高低对比 | `plt.cm.RdBu_r` |
| `Set3` | 柔和色，适合分类多 | `plt.cm.Set3` |
| `husl` | 均匀色相 + 亮度 | `sns.color_palette("husl")` |

### 单色填充 + 渐变

热力图 / 等高线用 `viridis` / `plasma` / `inferno` 渐变。
柱状图/饼图用 `tab10` / `Set3` 离散色。

### 避免的配色

- 纯红 + 纯绿（色盲不友好）
- 高饱和荧光色（打印容易糊）
- 浅黄底 + 白字（对比度不够）

## 七、常见图类型

### 折线图（时间序列 / 趋势）

```python
fig, ax = plt.subplots(figsize=(8, 5))
ax.plot(x, y1, marker='o', label='真实值', color='#1f77b4', linewidth=2)
ax.plot(x, y2, marker='s', label='预测值', color='#ff7f0e',
        linewidth=2, linestyle='--')
ax.fill_between(x, y1, y2, alpha=0.2, color='gray', label='误差区间')
ax.set_xlabel('日期')
ax.set_ylabel('销售额 / 万元')
ax.legend(loc='best')
ax.grid(True, alpha=0.3)
save_fig(fig, '预测对比.png')
```
