# 题意红线（4 条通用准则，96 小时必读）

> 借鉴自 cumcm-live-workflow-skill v5.0 §1"题意理解优先（最高优先级教训，任何题目通用）"，按 li-mtrie 学生视角重新组织。
>
> **作用**: 读完赛题后**第一件事**就是逐条对照。漏一条 → 终止时刻、临界参数、关键结果整体失真。

---

## 红线 1: 题面明写的物理事实必须建模进去

**表现**: 题面给出物体有宽度/厚度/形状 → 碰撞/干涉/间隙类判定必须用其**真实几何**（矩形/多边形/角点-中心线距离判据），**严禁**简化为"中心线/质点间距"判据——后者会漏检真实干涉，导致终止时刻、临界参数等关键结果整体失真。

**反例**: 螺线轨迹题（2024 A 题）简化为"两质点距离"判据，结果碰撞检测漏掉 30%+ 的真实擦碰，得分砍 30%。

**对策**:
- 读题时把所有几何/物理事实逐条列清单（题面数字 + 形状 + 约束）
- 写进代码注释/文档，建模时**逐条对照**是否全部体现
- 写"判据代码"前先画示意图，标注每个物体的真实几何边界

---

## 红线 2: 几何初始条件必须用解析公式独立验证

**表现**: 凡能用公式从题干数字推出的参数（半径=螺距×圈数、长度=孔距+2×孔心距、角度=弧长/半径），**一律推导核对一遍**，不能只信视觉读图。

**反例**: 从赛题图上"量"出某段曲线长度 → 跟解析公式差 5%，中间结果全错位。

**对策**:
- 列出所有可解析推导的参数
- 在代码注释里写明公式来源：`# 圈数 N = L / (π*d) = 1.0 / (3.14*0.1) = 3.18` (示例)
- 跟读图/看附件数字核对，发现差异立即回到红线 1 检查几何

---

## 红线 3: 后问对前问误差高度敏感

**表现**: 初始条件错 → 中间判据错 → 后续结果连锁全错。问题间耦合必须**每步验证**。

**对策**:
- 每完成一问先做"前问接力"检查：当前问的输入参数跟前问的输出参数是否完全对齐
- 5 个问题解完后做"端到端"演练：从问题 1 输入到问题 5 输出走一遍，看链路是否断裂

**自检命令**:
```powershell
# 验证问题 1 的 result1.xlsx 是否被问题 2 读取
Select-String -Path 求解/问题2/*.py -Pattern 'result1|q1|问题1' -CaseSensitive:$false
# 应该有至少 1 处读取，否则就是断链
```

## 红线 4: 无官方答案时的题目自查（5 步）

**真实比赛核心**——96 小时大部分赛题没有官方答案，必须自己建立基准。

1. **题干数值→解析公式独立推导**
   - 把题面每个数字代入公式算一遍，凡是能算出来的参数不许依赖读图/猜
2. **单位与几何自洽检查**
   - 所有长度/时间/速度换算成同一单位系
   - 画示意图核对几何关系（物体大小、相对位置、坐标系方向）
3. **边界情形推演**
   - 取极端参数（最大/最小）走一遍模型
   - 看结论是否符合物理直觉（能抓出大部分"模型没建对"）
4. **多方法交叉验证**
   - 同一结论至少 2 种独立途径（解析式 vs 数值扫描 vs 特例验证）
   - 一致才算数
5. **把"题面明写的物理事实"列清单**
   - 写进代码注释/文档
   - 建模时逐条对照是否全部体现

## 5 步自查的实战示例（机理题）

**赛题片段（示意）**: "螺线 r = θ / (2π)，共 N 圈，d0 = 0.1 m ..."

| 步 | 操作 | 示例 |
|----|------|------|
| 1 解析推导 | 圈数 = 弧长 / 螺距 | N = L / (π × d) = 1.0 / (3.14 × 0.1) = 3.18 |
| 2 单位自洽 | 弧长 L = 1.0 m, 螺距 π × d = 0.314 m | N = 3.18 (无量纲) ✓ |
| 3 边界推演 | 极值 0 / N_max 走一遍 | 0 圈时 r=0 (中心) ✓; N_max 时 r 极大 ✓ |
| 4 多方法验证 | 解析 vs 数值扫描 | 数值积分弧长 = 1.0 m ✓ |
| 5 物理事实清单 | 圈数 / 螺距 / 直径 / 起点 全部建模 | 代码注释里逐条标 ✓ |

## 红线 5 (v1.5.8 新增, 物理机理类必读): 边界离散式两道校验 + 半控制体 FVM Robin 模板

**表现**: 物理机理题 (本科 A/生物/传染病/扩散/传热) 用有限体积法 (FVM) 或有限差分 (FDM) 离散后, **表面上最容易错**的一道防线. 错模式不会被 dryrun 49 项扫到, 必须靠下面 2 道校验 + 正确模板兜底. 2026A v15 复盘 P0-1 (温度场): `build_surface_row()` 返回 `(1.0, 1+β, β)`, β = h·Δr/α ≈ 29611 且**式中无 Δt**, 表面钉死在烘房温度 (h→∞ 极限, 不是题面 h=25). 决定性证据: 正确格式 `dE/dt ÷ [h(T∞−Ts)A] ≈ 0.995`, 错误格式 = 223 (不可能).

**反例**:
- 温度场 v15 P0-1: `(1.0, 1+β, β)` β = h·Δr/α 形式, 缺 Δt → 表面被错钉死 (h→∞ 极限, T_s ≡ T_∞)
- 水分场 v15: 同上错离散 + 错算 Bi_m = 32 (实 3.24) + 改用 Dirichlet 三层错误叠加
- Q3 干燥后期动边界: `Δr(t) = R(t)·Δξ` 没随时间步缩放, 数值质量不守恒

**两道校验 (跑完每问必做, 物理机理题专属)**:

1. **能量/质量守恒校验**: 跑完求解, 取最后 1 个时间步, 计算 `dE/dt ÷ [h·(T∞ − T_s)·A]` (温度场) 或 `dm/dt ÷ [h_m·(X∞ − X_s)·A]` (水分场). **|比值 − 1| < 0.05 为绿**, ≥ 0.05 红 (P0-1 反例: 错格式下比值 = 223, 正确格式 ≈ 0.995).
2. **独立换实现重算**: 把同一方程改成另一套方法 (e.g. FVM → 解析极限 / FDM / 商用 PDE 库 FEniCS), 同一参数同一网格同一时间步, 两套实现的特征量 (峰值温度 / 平衡水分 / 半干燥时间) 对比. **相对误差 < 1% 为绿**, 1-5% 黄, > 5% 红.

**正确半控制体 FVM Robin 模板** (圆柱/球坐标通用, 中心节点因子 4, 边界节点因子 2):

```python
def build_surface_row(N, mu, gamma):
    """半控制体 FVM Robin 边界 — 第 N-1 节点 (表面内一格).

    适用: 温度场 T(r,t) / 水分场 X(r,t) / 动边界 Δr(t) = R(t)·Δξ 重映.
    PDE: ∂U/∂t = (1/r^m)·∂/∂r[r^m · D_eff · ∂U/∂r], m=0(平板)/1(柱)/2(球)
    离散: 显式时间 + 中心差分空间, 半控制体 (边界节点体积 1/2)
    Robin: -D_eff ∂U/∂r|_s = h_eff (U_amb - U_s)
    """
    # (1 + 2μ + γ) · U^{n+1}_{N-1} − 2μ · U^{n+1}_{N-2} = U^n_{N-1} + γ · U_amb
    a_self = 1 + 2*mu + gamma       # 中心节点权重 4 → 实际 1+2μ+γ
    a_prev = -2*mu                  # 内节点耦合
    rhs_amb = gamma                 # U_amb 系数 = γ = 2·h_eff·Δt/Δr
    return a_self, a_prev, rhs_amb
```

**关键参数**:
- μ = `D_eff · Δt / Δr²` (Fourier 数 / 2, 全控制体; 中心节点因子 = 1+2μ)
- γ = `2 · h_eff · Δt / Δr` (**Biot 含 Δt**, 不同于经典 Bi = h·Δr/D, P0-1 反例就是 β = h·Δr/D 形式无 Δt)
- μ, γ 自检: μ ≈ 0.1–0.5 (显式稳定上限 0.5), γ ≈ 1–10 (匹配 h 大小)
- 边界节点因子 2 (半控制体体积 = Δr/2, 内部节点因子 = Δr); 第 N-1 节点用半控制体, 第 0 节点同理

**3 类典型错模式 vs 正确模式对照表**:

| 模式 | 公式 (第 N-1 节点) | 物理意义 | 判定 |
|------|---------------------|----------|------|
| **错 1** (P0-1 反例) | `(1, 1+β, β)` β = h·Δr/D | h→∞ 极限, 表面钉死 T_amb | **red** |
| 错 2 | `(1, 1+2μ, μ+γ)` | 项错位, 传热方向反 | red |
| 错 3 | `(1+β+μ, -μ, β)` | β = h·Δr/D 无 Δt; μ 项又含 Δt, 维数不一致 | red |
| 对 1 | `(1+2μ+γ, -2μ, γ)` γ = 2·h·Δt/Δr | 标准半控制体 Robin | **green** |
| 对 2 (隐式 Crank-Nicolson) | `(1+μ+γ/2, -μ, γ/2)` 左 1+μ+γ/2, 右 γ/2 · U_amb | 时间中心格式 | green |
