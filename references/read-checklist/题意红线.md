# 题意红线（4 条通用准则，96 小时必读）

> 借鉴自 cumcm-live-workflow-skill v5.0 §1"题意理解优先（最高优先级教训，任何题目通用）"，按 li-mtrie 学生视角重新组织。
>
> **作用**: 读完赛题后**第一件事**就是逐条对照。漏一条 → 终止时刻、临界参数、关键结果整体失真。

## 红线 1: 题面明写的物理事实必须建模进去

**表现**: 题面给出物体有宽度/厚度/形状 → 碰撞/干涉/间隙类判定必须用其**真实几何**（矩形/多边形/角点-中心线距离判据），**严禁**简化为"中心线/质点间距"判据——后者会漏检真实干涉，导致终止时刻、临界参数等关键结果整体失真。

**反例**: 螺线轨迹题（2024 A 题）简化为"两质点距离"判据，结果碰撞检测漏掉 30%+ 的真实擦碰，得分砍 30%。

**对策**:
- 读题时把所有几何/物理事实逐条列清单（题面数字 + 形状 + 约束）
- 写进代码注释/文档，建模时**逐条对照**是否全部体现
- 写"判据代码"前先画示意图，标注每个物体的真实几何边界

---

## 红线 2: 几何初始条件必须用解析公式独立验证

**表现**: 凡能用公式从题干数字推出的参数（半径=螺距×圈数、长度=孔距+2×孔心距、角度=弧长/半径），**一律推导核对一遍**，不能只信视觉读图。

**反例**: 从赛题图上"量"出某段曲线长度 → 跟解析公式差 5%，中间结果全错位。

**对策**:
- 列出所有可解析推导的参数
- 在代码注释里写明公式来源：`# 圈数 N = L / (π*d) = 1.0 / (3.14*0.1) = 3.18` (示例)
- 跟读图/看附件数字核对，发现差异立即回到红线 1 检查几何

---

## 红线 3: 后问对前问误差高度敏感

**表现**: 初始条件错 → 中间判据错 → 后续结果连锁全错。问题间耦合必须**每步验证**。

**对策**:
- 每完成一问先做"前问接力"检查：当前问的输入参数跟前问的输出参数是否完全对齐
- 5 个问题解完后做"端到端"演练：从问题 1 输入到问题 5 输出走一遍，看链路是否断裂

**自检命令**:
```powershell
# 验证问题 1 的 result1.xlsx 是否被问题 2 读取
Select-String -Path 求解/问题2/*.py -Pattern 'result1|q1|问题1' -CaseSensitive:$false
# 应该有至少 1 处读取，否则就是断链
```

## 红线 4: 无官方答案时的题目自查（5 步）

**真实比赛核心**——96 小时大部分赛题没有官方答案，必须自己建立基准。

1. **题干数值→解析公式独立推导**
   - 把题面每个数字代入公式算一遍，凡是能算出来的参数不许依赖读图/猜
2. **单位与几何自洽检查**
   - 所有长度/时间/速度换算成同一单位系
   - 画示意图核对几何关系（物体大小、相对位置、坐标系方向）
3. **边界情形推演**
   - 取极端参数（最大/最小）走一遍模型
   - 看结论是否符合物理直觉（能抓出大部分"模型没建对"）
4. **多方法交叉验证**
   - 同一结论至少 2 种独立途径（解析式 vs 数值扫描 vs 特例验证）
   - 一致才算数
5. **把"题面明写的物理事实"列清单**
   - 写进代码注释/文档
   - 建模时逐条对照是否全部体现

## 5 步自查的实战示例（机理题）

**赛题片段（示意）**: "螺线 r = θ / (2π)，共 N 圈，d0 = 0.1 m ..."

| 步 | 操作 | 示例 |
|----|------|------|
| 1 解析推导 | 圈数 = 弧长 / 螺距 | N = L / (π × d) = 1.0 / (3.14 × 0.1) = 3.18 |
| 2 单位自洽 | 弧长 L = 1.0 m, 螺距 π × d = 0.314 m | N = 3.18 (无量纲) ✓ |
| 3 边界推演 | 极值 0 / N_max 走一遍 | 0 圈时 r=0 (中心) ✓; N_max 时 r 极大 ✓ |
| 4 多方法验证 | 解析 vs 数值扫描 | 数值积分弧长 = 1.0 m ✓ |
| 5 物理事实清单 | 圈数 / 螺距 / 直径 / 起点 全部建模 | 代码注释里逐条标 ✓ |

## 红线 5 (v1.5.8 新增, 物理机理类必读): 边界离散式两道校验 + 半控制体 FVM Robin 模板

**表现**: 物理机理题 (本科 A/生物/传染病/扩散/传热) 用有限体积法 (FVM) 或有限差分 (FDM) 离散后, **表面上最容易错**的一道防线. 错模式不会被 dryrun 49 项扫到, 必须靠下面 2 道校验 + 正确模板兜底. 2026A v15 复盘 P0-1 (温度场): `build_surface_row()` 返回 `(1.0, 1+β, β)`, β = h·Δr/α ≈ 29611 且**式中无 Δt**, 表面钉死在烘房温度 (h→∞ 极限, 不是题面 h=25). 决定性证据: 正确格式 `dE/dt ÷ [h(T∞−Ts)A] ≈ 0.995`, 错误格式 = 223 (不可能).

**反例**:
- 温度场 v15 P0-1: `(1.0, 1+β, β)` β = h·Δr/α 形式, 缺 Δt → 表面被错钉死 (h→∞ 极限, T_s ≡ T_∞)
- 水分场 v15: 同上错离散 + 错算 Bi_m = 32 (实 3.24) + 改用 Dirichlet 三层错误叠加
- Q3 干燥后期动边界: `Δr(t) = R(t)·Δξ` 没随时间步缩放, 数值质量不守恒

**两道校验 (跑完每问必做, 物理机理题专属)**:

1. **能量/质量守恒校验**: 跑完求解, 取最后 1 个时间步, 计算 `dE/dt ÷ [h·(T∞ − T_s)·A]` (温度场) 或 `dm/dt ÷ [h_m·(X∞ − X_s)·A]` (水分场). **|比值 − 1| < 0.05 为绿**, ≥ 0.05 红 (P0-1 反例: 错格式下比值 = 223, 正确格式 ≈ 0.995).
2. **独立换实现重算**: 把同一方程改成另一套方法 (e.g. FVM → 解析极限 / FDM / 商用 PDE 库 FEniCS), 同一参数同一网格同一时间步, 两套实现的特征量 (峰值温度 / 平衡水分 / 半干燥时间) 对比. **相对误差 < 1% 为绿**, 1-5% 黄, > 5% 红.

**正确半控制体 FVM Robin 模板** (圆柱/球坐标通用, 中心节点因子 4, 边界节点因子 2):

```python
def build_surface_row(N, mu, gamma):
    """半控制体 FVM Robin 边界 — 第 N-1 节点 (表面内一格).

    适用: 温度场 T(r,t) / 水分场 X(r,t) / 动边界 Δr(t) = R(t)·Δξ 重映.
    PDE: ∂U/∂t = (1/r^m)·∂/∂r[r^m · D_eff · ∂U/∂r], m=0(平板)/1(柱)/2(球)
    离散: 显式时间 + 中心差分空间, 半控制体 (边界节点体积 1/2)
    Robin: -D_eff ∂U/∂r|_s = h_eff (U_amb - U_s)
    """
    # (1 + 2μ + γ) · U^{n+1}_{N-1} − 2μ · U^{n+1}_{N-2} = U^n_{N-1} + γ · U_amb
    a_self = 1 + 2*mu + gamma       # 中心节点权重 4 → 实际 1+2μ+γ
    a_prev = -2*mu                  # 内节点耦合
    rhs_amb = gamma                 # U_amb 系数 = γ = 2·h_eff·Δt/Δr
    return a_self, a_prev, rhs_amb
```

**关键参数**:
- μ = `D_eff · Δt / Δr²` (Fourier 数 / 2, 全控制体; 中心节点因子 = 1+2μ)
- γ = `2 · h_eff · Δt / Δr` (**Biot 含 Δt**, 不同于经典 Bi = h·Δr/D, P0-1 反例就是 β = h·Δr/D 形式无 Δt)
- μ, γ 自检: μ ≈ 0.1–0.5 (显式稳定上限 0.5), γ ≈ 1–10 (匹配 h 大小)
- 边界节点因子 2 (半控制体体积 = Δr/2, 内部节点因子 = Δr); 第 N-1 节点用半控制体, 第 0 节点同理

**3 类典型错模式 vs 正确模式对照表**:

| 模式 | 公式 (第 N-1 节点) | 物理意义 | 判定 |
|------|---------------------|----------|------|
| **错 1** (P0-1 反例) | `(1, 1+β, β)` β = h·Δr/D | h→∞ 极限, 表面钉死 T_amb | **red** |
| 错 2 | `(1, 1+2μ, μ+γ)` | 项错位, 传热方向反 | red |
| 错 3 | `(1+β+μ, -μ, β)` | β = h·Δr/D 无 Δt; μ 项又含 Δt, 维数不一致 | red |
| 对 1 | `(1+2μ+γ, -2μ, γ)` γ = 2·h·Δt/Δr | 标准半控制体 Robin | **green** |
| 对 2 (隐式 Crank-Nicolson) | `(1+μ+γ/2, -μ, γ/2)` 左 1+μ+γ/2, 右 γ/2 · U_amb | 时间中心格式 | green |

**与 Li-mtrie 现有文档协同**:
- `references/by-category/物理机理类典型反模式.md §1` 加 #9 (Robin 错离散) + #10 (不换实现独立验算)
- dryrun check 53 (L20, v1.5.8 新增) 自动扫 `求解/问题N/solve_*.py` 找 bc_row 类函数, 检测错模式 → red, 真 Robin → green, 非 FVM → yellow 跳过
- `references/scripts/dryrun.py` `check_bc_robin_template` 函数: 启发式扫 `build_surface_row / bc_row / surface_row` 等 6 个常见命名, 提 (1, 1+x, x) 错模式 vs 含 γ 项真模式

**一句话总结 (v1.5.8 加)**:
> 物理机理题 **第 4 道防线**: 边界离散式 (1) 能量/质量守恒校验 | (2) 独立换实现重算 | (3) (1+2μ+γ)·U[N-1] − 2μ·U[N-2] = U_old + γ·U_amb, γ = 2·h·Δt/Δr (不是 β = h·Δr/D).

## 红线 6 (v1.5.8.1 新增, 数据清洗维度通用): 趋势数据禁用全局 IQR/箱线判据

**表现**: 数据清洗的 4 类常见反模式之一 (P0-2, 2026A 复盘). 趋势数据 (升温/收缩/衰减曲线) 的四分位距天然覆盖不了分布尾部的"过程段", IQR(k=1.5 或 3) 会把升温段/收缩段全部判异常, 删空后边界条件失效. **不是 4 类题专属, 是通用数据清洗规则** — 机理题 (升温曲线/收缩曲线) / 优化题 (需求曲线) / 数据题 (时间序列) / 经济题 (价格序列) 全部适用.

**反例** (2026A 复盘, P0-2):
- 附件 1 升温曲线 27 行: `df = df[(df['T'] > Q1 - 3*IQR) & (df['T'] < Q3 + 3*IQR)]` → 升温段被全删, 边界条件腰斩
- 附件 2 收缩曲线 23 行: 同上, 快速收缩段被误删, 动力学参数估错

**对策 (4 类允许检测方法, 单调趋势段内)**:

1. **物理越界**: `T ∈ [T_min, T_max]`, `C > 0`, `R ∈ (0, R₀]`, `X ∈ [0, 1]` (题面给或物理意义)
2. **一阶差分突变**: z-score = `(ΔT/Δt - μ_rate) / σ_rate`, **|z| > 5** 才判异常 (远比 IQR 严格, 适用于平稳段)
3. **物理单调性 (带容差)**: 收缩曲线 `R(t+1) > R(t) + ε` 才异常, ε = 1e-6. 强制物理约束, 不是"剔除异常"
4. **时间间隔一致性 + 重复值**: `Δt` 偏差 > 5% 提示时间戳错乱, 重复行只保留第 1 行

**边界/驱动类数据默认保留全量**: 附件 M 的 `R(t)` / 附件 2 预报曲线 / 附件 3 滚动预测 — 是**驱动**数据不是**测量**数据, 删 1 行 = 改 1 个边界时刻 = 模型对不上. 默认保留全量, 只做物理越界.

**二阶差分"速率阶段变化"是物理现象**: 升温曲线常分阶段 (表面水 → 自由水 → 结合水), d²T/dt² 突变是阶段切换不是测量错误, **不允许剔除**. IQR 对二阶差分天然判异常, 这就是 P0-2 反例根因.

**与 v1.5.8 §红线 5 协同**: §红线 5 防御**输出侧** (边界离散式错 → 表面钉死), P0-2 §红线 6 防御**输入侧** (清洗错 → 升温段被删 → 边界条件失效). 机理题"数据-模型"双防.

**完整 4 类检测代码模板 + 边界/驱动默认保留 + 阶段变化识别** → `references/data-usage/数据清洗规范.md` (v1.5.8.1 新建, 权威源, 6.4 KB, 7 节). dryrun check 54 (L21, v1.5.8.1 新增) 启发式扫 `求解/问题N/*.py` IQR/boxplot 误用, 紧邻 `drop/删除/剔除` → red, 纯描述统计 → green, 找不到 → yellow 跳过.

**一句话总结 (v1.5.8.1 加)**:
> **数据清洗**: 趋势段禁用全局 IQR (升温/收缩/衰减全删) — 4 类允许: 物理越界 / 一阶差分 z>5 / 单调性 (含容差) / 时间间隔+重复. 边界/驱动数据默认全保留.

## 红线 7 (v1.5.8.2 新增, Step 3 必做): 论文数字三来源红线 + 数值台账

**表现**: 论文中所有非题面数字 (除小整数 0/1/2/3) 必来自 3 类可信来源之一. P0-3 反例: 凭图读数 / 一次性心算 / AI 编造 都会出 0 分. 2026A 复盘 v1.1 §0: 5.2.2 ρ/cp/k 起止值系**目视读图臆造** (实 976.4→667.3 等); 5.4.1"前 10h→1.424cm、占 78%"**同为目测错** (实 5h、71.8%); **本轮新增**: 连"手算的关键判据"也会错 — `Bi_m` 被算成 32 (实 3.24, 差 10 倍), 决定性证据: 评审找代理公式复算时全部暴露.

**3 类可信来源** (Step 3 强约束, 缺一不可):

1. **脚本 print 落盘** (求解日志) — 求解过程数字 (峰值温度/平衡水分/半干燥时间)
   - 来源标签 = `1`
   - 例: solver 输出的 `T_max=33.5279, t_dry=205906 s`
2. **从 resultX.xlsx / 表N.csv 程序读取** (gen_tables.py 做法) — 表格数字
   - 来源标签 = `2`
   - 例: `pd.read_excel('result1.xlsx').iloc[:, 1].tolist()`
3. **论文写作现场用公式当场计算 + 关键判据二次独立复算** — 推导判据 (Bi/Fo/收缩率/Re/Pr)
   - 来源标签 = `3`
   - 例: `Bi = h·L/k = 25·0.02/0.5 = 1.0` (纸上演算, 单位独立验算)

**禁止** (3 类):
- ❌ **凭图读数** (从数据图上"目测" 数值, 精度不够, 5.2.2 ρ/cp/k 错因)
- ❌ **一次性心算** (不写公式直接说"约 1.4", 关键判据会算错 10 倍, Bi_m 反例)
- ❌ **AI 写数字** (AI 可能编造, 关键判据高发)

## 红线 6 (v1.5.9.3 新增, 物理机理类必读): 移动/变形坐标方程退化反证

**表现**: 含移动边界 (Q4 干燥前沿 / 动边界 R(t)) 或变形坐标 (随体坐标 ξ) 的偏微分方程推导, 必须做**退化反证** 验证公式一致性. 2026A 复盘 v1.1 §P1-6 — Q4 随体坐标推导先误加对流项 (50.60h), 用 D=0 反证 (冻结场应 ∂C/∂t=0) 纠正为纯扩散 (49.25h). 重跑后正确值为 50.4978h, "误加对流项"的对照数值已过期, 论文改用 D=0 逻辑反证表述, 不再引用过期对照数.

**反例 (2026A 复盘 §P1-6)**:
- ❌ 推导随体坐标对流项 + 扩散项 → 跑 50.60h 与物理直觉对不上, 但**作者自洽地相信**
- ✅ 用 D=0 反证 (无扩散应冻结场 ∂C/∂t=0) → 发现对流项错加 → 删后 49.25h, 后续重跑 50.4978h

**对策 (3 步退化反证流程)**:

1. **挑退化场景** — 选物理上易验证的极端参数 (e.g. D=0 无扩散 / h=0 无对流 / v→∞ 冻结 / 周期起点)
2. **物理直觉推导** — 该场景下 PDE 应满足什么解析解 (冻结场 / 稳态 / 守恒量)
3. **离散后代码验证** — 跑求解脚本, 对比数值解 vs 物理直觉. 偏离 = 推导有误

**对照实验数值处理 (重要)**:
