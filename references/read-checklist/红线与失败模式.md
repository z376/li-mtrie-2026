## §1. Failure handling (求解/编译最常踩的 6 类)

- **数据缺失>20%**：KNN 插补或删除该特征，不静默丢
- **XGBoost/GBR 过拟合**：降低 max_depth、增加正则化参数
- **预测值异常**：检查特征是否存在数据泄露
- **交叉验证方差过大**：增加折数或采用重复 CV
- **LaTeX 编译 Error**：先 `Select-String -Path 论文.log -Pattern '! Error'` 看具体错，针对修；连续 2 次失败切换策略（改 `\caption` 转义 / 检查字体路径）
- **Overfull/Underfull warning**：调整列宽比例 / 改换行位置；2 次修不好允许 `\\newline` 或 `\\sloppy`

## §红线 8. 量级复算 + 全离散式对拍 (v1.8.0 新增, 终审复验轮 N-P0-3/N-P0-4)

> 这两条是**文稿级但会被评审连带发现**的硬项 —— 数字本身没错, 但"量级说反了""公式与代码不是一套"，
> 评审一复算就发现, 直接打"数据不可信"。

### §红线 8.1 量级/量纲陈述必须当场复算 + 同文自洽

**实证** (2026A 终审): `2.总体分析` 难点2 写 "浓度边界层厚度 $D/h_m\sim10^{-2}$ mm, 远小于 0.1 cm"
—— 实际 $D/h_m = 4.94\times10^{-9}/8\times10^{-7} = \mathbf{6.2\ mm}$, **错约 620 倍**;
且与**本文自己** `5.1.2`（$\sqrt{4Dt}\approx6$ mm, 平缓无陡降前缘）、`6.模型检验` 直接矛盾 → 终审判 FAIL。

**规则**:

1. 正文一切**量级/量纲陈述**（边界层厚度 / 扩散深度 / 穿透深度 / Bi / Fo / 收缩放大倍数）**必须当场代入数字复算**，
   与 P0-3（关键判据二次复算）**合并执行** —— 不要算一遍就信。
2. **同文自洽**: 同一物理量若在多处出现量级估计（难点 / 分析 / 检验），**交叉比对，不许打架**。
   一处量级错且与正文他处矛盾 = **自相矛盾信号**（不止是数字错），直接判 RED。
3. 判据/清单 → `references/audit/验收清单.md §H` H9 + `references/代理审计prompt.md` B3；
   **dryrun check 71** 自动抓"同名量级量多个不同值"。

**3 错 1 对对照**:

| 写法 | 判定 | 说明 |
|------|------|------|
| "边界层厚度 D/h_m ≈ 6.2 mm" + 别处 √(4Dt) ≈ 6 mm | ✅ | 两处量级一致, 且都复算过 |
| "边界层厚度 D/h_m ≈ 0.01 mm" + 别处 √(4Dt) ≈ 6 mm | ❌ RED | 同文打架 = 至少一处错 (且错 620 倍那种) |
| "边界层厚度很小" (无数值) | ⚠️ yellow | 无量级断言 → 不会被 check 71 抓, 但也证明不了 |

### §红线 8.2 论文离散公式 ↔ 代码逐符号对拍（全部离散式, 不只表面行）

**实证** (2026A 终审): 上一轮只对了**表面行** (`build_surface_row`)。终审发现**内部格式** `eq:discrete`
也写反了 —— 论文把**前向差分** $(U_{i+1}-U_i)$ 配了**后向平均** $\tfrac12(D_i+D_{i-1})$、后向配前向；
而 `solver_core.py:68-79` 的配对是**对的**。**常物性下无差别, 变物性下影响显著**。
另有几何因子：论文写 $r_{i\pm1/2}$, 代码用 `rp=(i+1)*dr` / `rm=i*dr`（差 0.035 K，在自报误差内但**不是一套**）。

**规则**: 论文里**每一个**离散方程（中心 / 内部 / 表面）都要与代码**逐符号**核对:

| 核对项 | 怎么核 | 错例 |
|--------|--------|------|
| **差分配对** | 前向差分 ↔ 前向平均 / 后向差分 ↔ 后向平均 | 前向差分配后向平均 (写反) |
| **几何加权** | 论文 $r_{i\pm1/2}$ vs 代码 `rp`/`rm` 的实际定义 | 论文用面加权, 代码用点值 |
| **中心因子** | 径向离散中心因子 = **4**, 笛卡尔 = 2 | 径向写成 2 |
| **系数名** | 论文符号 ↔ 代码变量名逐字 | 论文 $k$ / 代码 `kappa` 未定义 |

**若论文公式与代码确有差异**（如几何加权），要么改代码，要么在正文**注明加权方式** ——
**不许"论文一套、代码一套"**。审计 prompt A 板块见 `references/代理审计prompt.md` A6。
