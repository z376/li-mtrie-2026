## L1 占位符未替换 (auto, dryrun check 15 + check 38)

**目标**: 论文 .tex 不能带任何模板占位符 (【、TODO、待填、XXX、Slot 宏).

**v5 P1 防御**: check 38 专项扫 `\\textbf{【...】}` (item 内 GB/T 7714 字段占位符) + GB/T 7714 字段关键词 (【作者】/【论文题名】/【期刊名】/【出版地】/【简要用途】等 28 项). 主要防 9.参考文献.tex item 未替换 + 9.0.AI工具使用声明.tex L4 【简要用途】占位符.

**run**:
```powershell
python references\scripts\dryrun.py
```

**判据**:
- 🟢 green: 0 占位符命中
- 🔴 red: 有 【/TODO/Slot 宏 命中 (跑题状态, 必须修)
- 🟡 yellow: example 模板状态 (设计意图)

**修复示例**:
```latex
% 错 (模板占位符):
\item \textbf{【作者 1】.} \textbf{【论文题名】} [J]. \textbf{【期刊名】}, \textbf{【年份】}, \textbf{【卷(期)】}: \textbf{【起止页码】}.

% 对 (实际引用):
\item 王晓峰, 李娜. 基于鲁棒优化的微电网储能调度研究 [J]. 中国电机工程学报, 2024, 44(12): 4823-4834.
```

## L2 编号对应 (auto, dryrun check 36)

**目标**: 正文 `\\cite{[n]}` 必须与 9.参考文献.tex 的 `\\item [n]` 一一对应.

**判据**:
- 🟢 green: `cited_nums ⊆ ref_nums` 且 `ref_nums ⊆ cited_nums` (无 cite 不存在, 无孤儿)
- 🔴 red: 有 `cite 不存在` (正文 `\\cite{5}` 但 9.参考文献.tex 没 [5] 条目) → 必须补条目
- 🟡 yellow: 有 `孤儿条目` (9.参考文献.tex [5] 条目定义但正文没 `\\cite{5}`) → 删/合并/补 cite

**支持两种模板**: enumerate 自动编号 (`\\begin{enumerate}[label={[\\arabic*]}]` + `\\item`) 与手动 `\\item [n]`.

**修复示例**:
```latex
% 错 (正文 \cite{5} 但 9.参考文献.tex 没 [5]):
... 根据文献 \cite{5} 的方法, ...

% 对 (补 9.参考文献.tex):
  \item \textbf{王晓峰, 李娜.} \textbf{微电网储能鲁棒调度} [J]. \textbf{中国电机工程学报}, 2024, 44(12): 4823-4834.
```

## L4 真实性 spot-check (manual, 12 步)

> **本层 dryrun 不自动, 必须人工 spot-check**. 12 步骤每条都需要对每条参考文献逐一核验.

**目标**: 9.参考文献.tex 每条文献的作者/期刊/年份/页码/网址/DOI 必须真实可核验.

**v5 报告基础**: v5 全 12 条全真实 ✓ (作者错处已修), v4 P1 han/wang 作者错 + 6 条未引用 + bertsimas 2004 + 双版本 result 文件已修.

### 12 步骤清单

每条参考文献 [n] 逐项 spot-check, 全 12 条逐一核验.

#### 步骤 1: 文献数量 5-15 条
- [ ] 数量在 5-15 区间 (BZD 通用建议, 太少不够支撑, 太多不精读)
- [ ] 经典模型原始文献 ≥ 3 条 (e.g. Breiman 2001 RF, Lo 1997 NIPT, Chiu 2008)
- [ ] 近 3-5 年相关 ≥ 3 条
- [ ] 数据来源 ≥ 1 条 (官方数据 / 标准 / 数据集)
- [ ] 不列 AI 工具 (L3 已覆盖)

#### 步骤 2: 作者真实
- [ ] 每条作者名拼写正确 (v4 P1: han2024 韩琳 → 韩璟琳, wang2025 王洋 → 郭杉/郭洋/刘小恺/董文娟, 已修)
- [ ] 中文作者: 姓 + 名 (e.g. 王晓峰), 不用拼音 (e.g. Wang Xiaofeng 在中文文献)
- [ ] 英文作者: 姓在前 (e.g. Bertsimas D.), 名缩写在后
- [ ] 多作者: 3 人以上写 "等" (中文) / "et al." (英文), GB/T 7714 规范

#### 步骤 3: 题名真实
- [ ] 题名与原文献一致 (AI 推荐的文献必须人工 Google Scholar / 知网 / Web of Science 核对)
- [ ] 题名大小写正确 (英文文献: 标题大小写或句首大写, 不能全大写)
- [ ] 不带 "AI 推荐" / "GPT 综述" 等 AI 痕迹词

#### 步骤 4: 期刊/会议真实
- [ ] 期刊名拼写正确 (e.g. "中国电机工程学报" 不用 "中国电机学报")
- [ ] 期刊全称与缩写对应正确 (e.g. "Operations Research" 缩写 "Oper. Res.")
- [ ] 会议名 + 届次 + 年份 (e.g. "IEEE Power & Energy Society General Meeting, 2021")

#### 步骤 5: 年份真实
- [ ] 年份与原文献出版年一致
- [ ] 范围合理 (参考文献一般 ≤ 当前年 - 1)

#### 步骤 6: 卷期页码真实
- [ ] 卷 (Volume) + 期 (Issue) + 起止页码 (Pages) 三项齐全 (期刊论文)
- [ ] 学位论文: 出版地 + 授予单位 + 出版年
- [ ] 专著: 出版地 + 出版者 + 出版年 + 起止页码 (引用章节)
- [ ] 网页资源: 网址 + 发布日期 + 访问日期

#### 步骤 7: 文献类型标识正确 (GB/T 7714)
- [ ] [J] 期刊论文 (Journal)
- [ ] [M] 专著 (Monograph)
- [ ] [D] 学位论文 (Dissertation)
- [ ] [C] 会议论文 (Conference)
- [ ] [N] 报纸文章 (Newspaper)
- [ ] [R] 报告 (Report)
- [ ] [S] 标准 (Standard)
- [ ] [P] 专利 (Patent)
- [ ] [EB/OL] 电子公告 (Electronic Bulletin / Online)
- [ ] [DB/OL] 数据库 (Database / Online)
- [ ] [Z] 其他 (Others)

#### 步骤 8: DOI/网址 真实
- [ ] DOI 格式正确 (e.g. 10.1109/TIE.2021.1234567)
- [ ] DOI 在 https://doi.org/ 可解析到对应文献
- [ ] 网址真实可访问 (e.g. http://www.stats.gov.cn/, 不虚构)
- [ ] 访问日期 (YYYY-MM-DD) 真实 (跑题前 1 周内访问)

#### 步骤 9: 引用覆盖 (12 条全被 cite)
- [ ] 摘要 + 正文 `\\cite` 命中 9.参考文献.tex 全部 12 条 (v4 P1 "6 条未引用" 已修)
- [ ] 每条至少被 `\\cite{1}` 1 次 (摘要 / §5.X.X / §7 / §8)
- [ ] 不存在孤儿条目 (L2 check 36 已覆盖)

#### 步骤 10: AI 工具未误列 (双重检查)
- [ ] 9.参考文献.tex 不含 AI 工具关键词 (L3 check 37 已覆盖)
- [ ] 9.0.AI工具使用声明.tex 含 AI 工具声明 (用了 AI 必填)
- [ ] AI工具使用详情.pdf 内容与 9.0.AI工具使用声明.tex 一致

#### 步骤 11: 与 result 文件 / 正文数字一致
- [ ] 数据来源文献 (附件 1-5 引用) 与 result 文件中的数字一致 (e.g. 附件 1 均价 0.7662 元/kWh)
- [ ] 模型原始文献 (e.g. Bertsimas 2004 Price of Robustness) 与代码 plan_day_robust 的鲁棒参数 δ_pv=15%/δ_load=5% 对应
- [ ] 期刊卷期页码与正文叙述一致 (e.g. "根据文献 [5] 在 IEEE TIE 58(10):4583-4592 中提出的方法")

#### 步骤 12: 格式统一
- [ ] GB/T 7714 格式: 作者. 题名 [类型]. 出版地: 出版者, 年: 页码.
- [ ] 中文文献: 中文标点 (，。点) "."不用 (用点.)
- [ ] 英文文献: 英文标点 (, .) (中文逗号不用)
- [ ] 项目符号统一 (`\\item` + 编号顺序 + 字间距一致)

## L5 数字一致性 (manual + check 39 留位)

> **本层 dryrun 不自动 (check 39 永久 yellow 留位), 必须人工 spot-check**. v5 报告 P0 多处自相矛盾是核心教训.

**目标**: 摘要-§5 章节-Q 表 数字必须互一致 (无 Qty / Page / Section 数字矛盾).

**v5 报告 P0 反例**:
- 摘要 "Q3 节约 5.7%" vs §5.3 "调整反贵 5.4%" (方向反转)
- 摘要 Q4-2 = 1504 万 vs §5.4 = 2183 万 vs 文件 = 1843 万 (三处对不上)
- §5.1.2 鲁棒差额 +2552 元 vs +9648 元 (自相矛盾)
- §5.2 紧急购电 11.6 万 vs 110.9 万 vs 589 万 (差 50 倍)

### 短期兜底: SKILL.md §Step 4 末 "论文内部数字一致性自检清单"

跑题后必做 (10 分钟), 4 步:

1. **摘要 vs §5.X**: 摘要里每个数字 (Q1-Q4 总费/节约/紧急购电) 在 §5.X 都能找到一致出处
2. **§5.X 内** vs §5.X: §5.1.2/§5.2/§5.3/§5.4 内每个数字只有 1 个版本 (无 2,552 vs 9,648)
3. **§5.X vs resultX.xlsx**: §5.X 表数字与 `求解/问题X/结果/resultX.xlsx` 一致 (建议跑 `references/scripts/verify_pdf_metrics.py` 辅助)
4. **口径一致**: 全文统一 "334 天 vs 365 天" 口径 (v5 P2: result 文件 334 天但 §5.4 用 365 天口径)
