## 6 大题型 × 3 层模型决策

### 1. 机理题 (A 题, 物理/工程)

| 层级 | 推荐 | 备选 | 备注 |
|------|------|------|------|
| 主模型 | 物理方程 + 数值积分 (odeint) | 解析解 (sympy) | 重视"物理过程建模", 不是数据拟合 |
| 备选模型 | 简化版 (2D/3D 投影) | 离散元 (DEM) / 有限元 (FEM) | 简化保留核心物理 |
| 检验 | 量纲分析 + 边界条件 | 解析解对照 + 极限情况 | 物理一致性 > 统计指标 |

**典型题**: 烟幕干扰弹 (2024B), 火箭发射 (2023A), 卫星轨道 (2022A)。

### 2. 优化题 (B 题, 调度/规划)

| 层级 | 推荐 | 备选 | 备注 |
|------|------|------|------|
| 主模型 | 线性规划 (LP) / 整数规划 (ILP) | 动态规划 (DP) | 重视"约束建模", 不是算法炫技 |
| 备选模型 | 多目标规划 (NSGA-II) | 启发式 (GA / DE / PSO) | 多目标 Pareto 前沿 |
| 求解器 | PuLP / scipy.optimize | Gurobi / CPLEX | 看规模 < 100 变量还是 ≥ 100 |
| 检验 | 灵敏度分析 + 边界松弛 | 扰动检验 + 随机种子 | 验证最优解稳定 |

**典型题**: 物流配送 (2021B), 航班调度 (2023B), 生产计划 (2020B)。

### 3. 数据题 (C 题, 统计/ML/预测)

| 层级 | 推荐 | 备选 | 备注 |
|------|------|------|------|
| 主模型 | 多元回归 / 随机森林 | XGBoost / LightGBM | 重视"特征工程", 不是模型调参 |
| 备选模型 | 神经网络 (MLP) | 朴素贝叶斯 / SVM | 数据量大 (≥ 1000) 才考虑 NN |
| 特征 | 标准化 + 相关性 + PCA | 嵌入式特征选择 (Lasso) | 防维度灾难 |
| 检验 | 5 折 CV + 残差分析 | 留出集 + 鲁棒性 | 交叉验证 > 训练集指标 |

**典型题**: NIPT 检测 (2025C), 房价预测 (2024C), 疫情传播 (2023C)。

### 4. 评价题 (D/E 高职, 排序/打分)

| 层级 | 推荐 | 备选 | 备注 |
|------|------|------|------|
| 主模型 | 层次分析 (AHP) + 熵权法 | TOPSIS / DEA | 重视"权重确定", 不是排序算法 |
| 备选模型 | 主成分分析 (PCA) | 灰色关联 | 客观权重 vs 主观权重 |
| 一致性 | CR < 0.1 (AHP) | 专家咨询 | 防"主观随意打分" |
| 检验 | 权重扰动 + 排序稳定 | 跨方法对照 (AHP vs 熵权) | 排名变化 < 10% |

**典型题**: 城市发展评价 (2022D), 工业效益 (2023D), 教育水平 (2021D)。

### 5. 预测题 (A/B/C/D/E, 时间序列)

| 层级 | 推荐 | 备选 | 备注 |
|------|------|------|------|
| 主模型 | ARIMA / 灰色预测 (GM(1,1)) | 指数平滑 (ETS) | 数据 < 50 用灰色 |
| 备选模型 | Prophet / LSTM | 贝叶斯结构时序 | 数据 ≥ 1000 用 LSTM |
| 检验 | MAE / RMSE / MAPE | 滚动预测 + 残差白噪声 | 短期预测精度优先 |
| 季节性 | STL 分解 | 周期项 + 趋势项 | 必须识别 |

**典型题**: 人口预测, 销量预测, 交通流量预测。

### 6. 决策题 (B/D/E, 风险/优化)

| 层级 | 推荐 | 备选 | 备注 |
|------|------|------|------|
| 主模型 | 多目标优化 + 贝叶斯决策 | 蒙特卡洛模拟 | 重视"风险量化", 不是单点最优 |
| 备选模型 | 鲁棒优化 | 随机规划 | 不确定性高时优先鲁棒 |
| 决策 | 期望效用 + 风险权重 | 帕累托前沿 | 漏检 vs 过度诊断 |
| 检验 | 情景分析 (best/worst/base) | 概率分布扰动 | 极端情况稳健 |

**典型题**: 投资决策, 医疗诊断, 应急调度。

## 5 步快速选模型 (跑题前 5 分钟)

```
1. 读题面 (用 references/读题清单.md 提取 15 项)
2. 判题型: 机理 / 优化 / 数据 / 评价 / 预测 / 决策?
3. 选主模型: 上述 6 题型对应的主模型
4. 选备选: 同表 1-2 个备选 (至少 1 个线性, 1 个非线性)
5. 套公式: 5.1.2 §5.X 模型建立, 写目标函数 + 约束 + 变量
```

## 跑题实战案例 (v1.5.7 新增)

### 2025 C题 NIPT (本科组 C, 数据题)

- **题型判定**: 数据题 (C 题, 统计/ML/预测) → 用 3. 数据题 决策表
- **主模型**: 多元回归 + 随机森林 (4 个问题共用, 灵活)
- **备选模型**: 朴素贝叶斯 / SVM (二分类) / Isolation Forest (异常检测)
- **检验**: 5 折 CV + 灵敏度分析 + 鲁棒性 (±5% 误差)
- **输出**: R² 0.76 / AUC 0.62-1.0 / 异常 15%

### 2024 A 题 烟幕干扰弹 (本科组 A, 机理题)

- **题型判定**: 机理题 (A 题, 物理/工程) → 用 1. 机理题 决策表
- **主模型**: 视线-球-圆柱求交 + 差分进化
- **备选模型**: 解析解 (sympy) + 简化 2D 投影
- **检验**: 量纲分析 + 解析解对照 + 极限情况
- **输出**: 遮蔽时长 (s)
