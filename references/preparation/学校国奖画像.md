# 学校国奖画像 (School Awards Profiling)

> 借鉴 BZD 数模社 `bzd-cumcm-school-awards` v1.0 (2026-08-18) 的**核心理念**, **不复制 BZD 累积数据**.
> 学生自查 4 步法: 查数据 → 评估差距 → 选赛组 → 选题偏好.
> **真实数据查询**: 走 BZD 官网 `bzdshumo.com` 或学校教务处, 不在本文件固化.

## 何时用

- **赛前 2 周**: 评估学校整体实力, 选冲奖策略 (国一/省一/省二/优胜)
- **赛前 1 天**: 选题偏好分析 (本科组 A/B/C 哪个本校常拿奖)
- **赛后 1 周**: 复盘学校画像变化, 校准下一年备赛
- **不替代** BZD 官方数据查询, **不** 给学生具体获奖名单 (那是 BZD 资源)

## 4 步自查法

```
Step 1 查数据 (查 3-5 年)
  - 学校近 3-5 年 CUMCM 国一/国二/省一/省二 数量
  - 学校近 3-5 年 MCM/ICM 出线情况
  - 学校 2024 教指委公布的国赛名单 (官方源)
  - BZD 官网 bzdshumo.com 高校画像查询
  - 注: 不复制 BZD 数据, 学生自查

Step 2 评估差距 (个人 vs 学校平均)
  - 你的队是强校还是弱校? (Step 1 数据)
  - 强校 (近 3 年国一 ≥ 5 队) 冲国一, 弱校 (近 3 年省二/优胜多) 冲省一
  - 你的队建模手/代码手/论文手 vs 学校历史强队差距
  - 注: 强校 ≠ 你一定国一, 弱校 ≠ 你一定省二, 评委看个人

Step 3 选赛组 (本科 ABC / 高职 DE)
  - 国赛分两组:
    - 本科组: A 题 / B 题 / C 题 任选
    - 高职高专组: D 题 / E 题 任选
  - 错选题组直接判 0 分 (BZD 必查)
  - 选哪个题看学校近 3 年常拿奖的题型偏好

Step 4 选题偏好 (题型匹配)
  - A 题: 物理/工程机理题 (差分方程/连续优化)
  - B 题: 优化/调度/运筹 (线性规划/启发式)
  - C 题: 数据分析/统计/预测 (机器学习/时间序列)
  - D 题: 高职类, 偏实操
  - E 题: 高职类, 偏统计
  - 注: 不绝对, 看指导教师擅长 + 历年经验
```

## 4 类学校画像 (BZD 分类法)

| 类型 | 近 3 年表现 | 建议冲奖 | 选题建议 |
|------|------------|----------|----------|
| **A 类强校** | 国一 ≥ 5 队, 国二 ≥ 10 队 | 国一 (按 BZD 风格) | 选最难的 (A 物理或 C 大数据) |
| **B 类稳定** | 国一 1-4 队, 国二 5-9 队 | 国一/国二 | 选中等难度 (B 优化或 C 数据) |
| **C 类黑马** | 近 3 年国一 ≤ 1 队, 但近 1 年突进 | 国一 (1 个) + 省一 (保底) | 选最有把握的 (团队最强题型) |
| **D 类新人** | 近 3 年省二/优胜多, 国一 0 | 省一 (先冲) | 选最稳的 (团队训练最多题型) |

**BZD 警告**: 学校类型**不决定**你能不能拿国一. 评委看论文质量, 不看学校背景.

## 4 大常见错误

1. ❌ **复制 BZD 数据到论文/数模资料** (版权问题, BZD 资源**只用于个人查询**)
2. ❌ **只信"我们学校强"** (BZD 警告: 学校强 ≠ 你队强, 历年看个人)
3. ❌ **不查数据就选题** (凭感觉选, 不看学校历史强项)
4. ❌ **高职选 ABC** (错选赛组 = 0 分, 必查)
