# 百分制评审方法 (100-Point Rubric)

> **借鉴源**: BZD 数模社 `bzd-review-paper` v1.0 (2026-08-18) 的 **百分制评分框架** (90% 封顶 + 1/2/3 档扣分 + 格式质量系数 + 位次估计).
> 本文档搬运**评分方法**供 li-mtrie 自用, 实际评审走 LLM 自评 prompt (`references/llm-prompts/04-百分制评审.md`).

**LLM 工具版本** (本方法论 + 结构化 prompt): `references/llm-prompts/04-百分制评审.md §M3 百分制评审` — 100 分 + 90% 封顶 + 1/2/3 档扣分 + 格式系数 + 位次估计 全部进 JSON OUTPUT_FORMAT, 学生 copy-paste 自用.

## 1. 何时用

跑完题、写完论文、做完格式自查后, 自我评估**"能拿多少分 / 大概什么位次"**.

**不替代**:
- 官方评审 (评委有最终裁量权)
- 国奖预测 (用 bzd-cumcm-school-awards 查学校画像)
- 格式自查 (走 `references/格式自查清单.md`)

## 2. 评分结构 (100 分)

| 板块 | 满分 | 说明 |
|---|---|---|
| **摘要** | 10 | 独立可读, 含问题/方法/结果/结论 |
| **格式** | 10 | 走 `格式自查清单.md` 的 15 分制后, 线性映射为 0-10 |
| **模型/求解/结果** (含假设/符号/建模/求解/检验) | 70-75 | 拆到每问题三块: 模型建立 + 模型求解 + 结果与回答 |
| **补充质量** (创新/灵敏度/评价/推广) | 5-10 | 视题量和难度 |
| **合计** | 100 | 上述 4 项相加 |

## 3. 三块拆解 (每问题)

每道问题拆为**独立 3 块**, 每块独立打分:

| 块 | 含义 | 典型权重 (25 分题) |
|---|---|---|
| **模型建立** | 假设/变量/公式/约束/目标/参数 | 15 |
| **模型求解** | 算法/代码/计算/结果数值 | 5 |
| **结果与回答** | 回答题目原问/图表/灵敏度 | 5 |

权重由当前题目的需要决定, 不是固定的 15-5-5, 但**总和 = 该题满分**.

## 4. 90% 封顶制 + 1/2/3 档扣分

每块从 `0.90 × block_weight` 起评, 逐项扣分.

| 档 | 含义 | 扣分 |
|---|---|---|
| **轻微** | 局部轻微缺失/表述不清 | -1 |
| **实质** | 实质缺失/依据不足/前后不一致 | -2 |
| **核心** | 核心步骤错误/无法复现/严重影响该板块 | -3 (扣到 0 为止) |

**特殊处理**:
- 累积扣分扣完该块名义权重时, 记为 0
- 块根本答非所问/违反核心条件/无替代论证 → **直接判 0**
- **不同但有效且充分的方案不扣分** (避免"标准答案"绑架)

## 5. 格式质量系数 (deterministic)

把 `格式自查清单.md` 15 分制的结果, 映射为 `[-10, 10]` 的格式分, 然后**确定性**计算格式系数:

```
format_score_15 = 格式自查得分  (范围: -9999 ~ 15, 实际常见 -3 ~ 12)
format_score_10 = clip(format_score_15, 0, 15) / 15 * 20 - 10
                  # 0 分 → -10, 7.5 分 → 0, 15 分 → 10
quality_coefficient = (format_score_10 + 10) / 20
                  # 范围: [0, 1], 15 分 → 1.0, 7.5 分 → 0.5, 0 分 → 0
final_score = raw_score × quality_coefficient
```

**不选择定性乘子带** (no multiplier band like "excellent=1.0, good=0.9"). 系数完全由 15 分制得分决定.

## 6. 位次估计 (CUMCM vs 其他竞赛)

### CUMCM (高教社杯国赛)

用 2025 国赛分数锚点**插值估算**:

| 分数 | 估计超过约 | 等价位次 |
|---|---|---|
| 90+ | 99% | 前 1% (国特候选) |
| 80-90 | 95% | 前 5% (国一候选) |
| 70-80 | 85% | 前 15% (国二候选) |
| 60-70 | 70% | 前 30% (省一/国三) |
| 50-60 | 50% | 前 50% (省二/三) |
| < 50 | 30% | 优胜奖 |

### 其他竞赛 (MCM/ICM/MathorCup/华数杯/校赛)

用小型竞赛 10-90 分**近似均匀分布**估算:

```
percentile = clip((final_score - 10) / 80, 0, 1)
```

(没有 CUMCM 那样的大样本锚点, **不代表实际名次**)

## 7. 评审前必读 (评委视角)

1. **不要先入为主**: 评审前**先读题再读论文**, 不沿用历史思路或他人评价
2. **冻结评分细则**: 读论文**前**就把每块的扣分清单列好, 不看论文不让细则动
3. **逐项扣分**: 不"总体印象打分". 每扣 1-3 分都标页码和证据
4. **区分必报 vs 可选**: 必报项缺失扣 2-3, 可选项不扣
5. **可复现性 > 巧妙性**: 代码可跑 > 公式漂亮. 复现不了的核心步骤 = 直接扣 3
6. **创新盲区承认**: 非常规创新路径可能被低估, **不**因此拒判

```markdown

> 评分时间: __________  评分人: __________ (自评/同伴互评)

## 一、最终得分与位次

- 原始得分: X.X / 100
- 格式质量系数: 0.XX
- 最终得分: X.X / 100
- 预估位次: 前 X% (基于 2025 国赛分数锚点)

## 二、详细评分 (按问题三块)

### 问题 1 (满分 25)

| 块 | 满分 | 90% 封顶 | 原子项数 | 扣分清单 | 实得 |
|---|---|---|---|---|---|
| 模型建立 | 15 | 13.5 | 8 | -1 (符号未定义×1), -2 (无灵敏度×1) | 10.5 |
| 模型求解 | 5 | 4.5 | 4 | -1 (代码未给完整命令×1) | 3.5 |
| 结果与回答 | 5 | 4.5 | 3 | 0 | 4.5 |
| **小计** | **25** | | | | **18.5** |

(类似列问题 2 / 问题 3)

### 摘要 (满分 10)

| 检查点 | 状态 | 扣分 |

| 含问题/方法/结果/结论 | 满足 | 0 |
| 1 页内 | 满足 | 0 |

### 格式 (15 → 10 映射)

## 三、资格与格式审查

- 元数据: 全部匿名

2. ...
3. ...

## 五、优先修改建议 (按得分提升排序)

1. (操作 + 预期 +X 分 + 用时)
2. ...
3. ...
4. ...
5. ...
```

## 9. 复盘检查 (交卷后 30 分钟)

```
□ 原始得分算了吗? (含摘要 + 格式 + 3 块 + 补充)
□ 格式系数算了吗? (15 → 10 → 系数)
□ 最终得分 = 原始 × 系数
□ 位次估计了 (CUMCM 用 2025 锚点)
□ 每块扣分都有页码证据
□ 资格风险单独列出 (目录等)
□ 5 项优先修改按"提升/成本"排
□ 报告固定 5 节, 无多余/缺漏
```
