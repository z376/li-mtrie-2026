# 读题逐句翻译 (Problem Sentence-by-Sentence Translator)

> **借鉴源**: BZD 数模社 `bzd-problem-translator` v1.0 (2026-08-18) 的 **方法论** (语义翻译 + 句子单元拆分 + 覆盖台账 + 隐藏约束暴露 + Mermaid 跨题流程图 + 审计遗漏).
> **搬运策略**: v1.5.1 精简方法论 (不复制 BZD 完整子树, 详 CHANGELOG.md v1.5.8).
>
> **LLM 工具版本** (本方法论 + 结构化 prompt): `references/llm-prompts/06-读题翻译.md` — 句子单元 + 覆盖台账 + 隐藏约束 + Mermaid 流程图 全部进 JSON OUTPUT_FORMAT, 学生 copy-paste 自用.

## 1. 何时用

🟢 **对应 SKILL.md Step 0**: 读题.

跑题 **Step 0 读题** 时, 读完一遍题目后, 对**每一句**做一次"语义翻译", 把赛题 prose 翻成可执行的建模语言. **目标**: 暴露隐藏约束, 防漏题漏条件.

🟢 **完成判据**: 4 节齐 (全局故事 + 覆盖台账 + 隐藏约束 + Mermaid 流程图), 详 §2-§5.

## 2. 句子单元拆分 (auditable units)

把题目 prose 拆成**可审计单元**, 原则:
- 一个完整源句 = 一个单元
- 遇到分号或枚举子句, 仅当其含**独立可强制要求**时才拆开
- 给每个单元分配稳定 ID (如 `B01` / `D03` / `Q2-04` / `A01`)

**禁止拆**: 标题/页眉/水印/下载提示/格式规范的元信息.

🟢 **完成判据**: 总单元数 ≥ 题面句数, 标题/元信息未拆入.

## 3. 覆盖台账 (coverage ledger)

对**每个单元**做一张表:

| 单元 ID | 原文 (1:1 复制) | 翻译 (简洁中文建模语言) | 落点 (模型/数据/约束/目标/输出) | 隐藏约束? |
|---|---|---|---|---|

**核心**: 1:1 复制原文 (供评委对照), 不要"意译"丢掉信息.

🟢 **完成判据**: 表格 ≥ 10 行, 原文栏 1:1 复制 (跟 PDF 逐项对照).

## 4. 隐藏约束暴露

每个句子都可能藏**定义/机制/约束/数据线索/评价目标/交付物/依赖关系**, 不能只看字面. 4 类常见隐藏:

1. **数据约束**: "附件 1 中数据每 5 分钟一次" → 时序分辨率约束
2. **机理约束**: "假定流体不可压缩" → 连续性方程形式约束
3. **目标约束**: "评价方案鲁棒性" → 必须有灵敏度/扰动分析
4. **交付约束**: "提交 1 个 PDF" → 格式/页数/排版硬约束

🟢 **完成判据**: 4 类 (数据/机理/目标/交付) 至少各 1 条.

## 5. Mermaid 跨题流程图 (mandatory)

画 1 张 Mermaid `flowchart`, 显示:
- 题目全局故事: 对象 → 状态 → 机制 → 数据 → 决策 → 目标 → 交付物
- 跨问题共享数据/变量/参数/约束
- 验证链路 (留出/灵敏度/敏感性/基线)

**为什么必须画**: 90% 跑题事故是"问题 2 用了问题 1 没出现的变量"或"问题 3 的约束问题 1 没声明" — 流程图一眼看出.

🟢 **完成判据**: Mermaid 块 ≥ 1, 节点 ≥ 5, 含对象/状态/机制/数据/输出/验证/交付.

## 6. 4 节报告结构

```
# 赛题语义翻译报告 — [题号] [年份]
## 0. 全局故事 (1 段)
## 1. 句子单元 + 覆盖台账 (按题号分小节)
## 2. 隐藏约束清单 (按类型分组)
## 3. 跨题 Mermaid 流程图
## 4. 遗漏审计 (我先答前自查)
```

- 读题清单 15 项 (`references/读题清单.md`) — 那是 checklist, 这是翻译
- 建模方案 (`references/建模方案框架.md`) — 那是选模型, 翻译只是把题读透
