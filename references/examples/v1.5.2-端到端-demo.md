## 3. 工具 04 §M3 百分制评审模拟

把 24 页论文.pdf 喂给工具 04 §M3 百分制评审 (LLM 模拟, 学生实际跑:

```bash
# 复制 04-百分制评审.md 的 M3 prompt, 把 论文.pdf 路径换成本题, LLM 输出结构化评审
```

按 `references/百分制评审方法.md`:
- 100 分制 (摘要 10 + 格式 10 + 模型/求解/结果 70-75 + 补充 5-10)
- 90% 封顶 + 1/2/3 档扣分
- 格式系数 (format_score + 10) / 20
- CUMCM 位次 = 2025 国赛分数锚点插值

**本 example 模拟评审 (LLM 视角)**:
- 摘要 (8/10): 引言段 2 句精炼, 5 问题段量化结果清晰, 创新评价段 1 段, 减 1 (开头"针对问题"略生硬)
- 格式 (10/10): 三线表 + 单位列 + 16/60/12% 列宽, 表后注 "局部符号首次出现说明" 加分
- 模型/求解/结果 (60/70): 集中优化模型 6 段结构 BZD 范本, 5 题求解 5 段 (建立/求解/结果/检验/灵敏度) 完整
- 补充 (4/5): 灵敏度分析有 6 项 ±10% 扰动, 减 1 (创新点偏短)
- 原始得分: 82/100
- 格式系数: 0.73
- 最终得分: 82 × 0.73 = 60/100
- 位次: 约前 70% (省一/省二)

**这个分数对**真实 example 是合理的** (24 页完整论文, 没有大错), 但不是国一 (国一通常 80+). 印证了 "skill 解决'不犯低级错', 国一是'做对 + 创新 + 运气'".

## 4. 端到端步骤 (学生套用 v1.5.2 跑自己的题)

**Step 0 读取输入** (1-2 小时):
```bash
# 把赛题 PDF 放到 题目/ 目录
cp 赛题.pdf 题目/
# profile_data.py 跑 EDA
python references/scripts/profile_data.py 题目/赛题.pdf
# 写 求解/求解计划.md 顶部 4 项: 题组/题号/问题数/数据概况
```

**checkable 绿判据**: 题面文字 ≥ 200 字 + 求解/求解计划.md 顶部 4 项已填.

**Step 1 求解计划** (1-2 小时):
```bash
# 用工具 01 选题推荐 (粗筛, 拿到候选模型 Top-3)
# 用工具 04 §M1 字典预查 (细评, 4 档判定)
# 写 求解/求解计划.md (选定方案 + 参数 + 求解思路)
```

**checkable 绿判据**: 每个问题 1 个选定方案, user 用 1/2/3/OK 确认.

**Step 2 逐题求解** (12-24 小时, 主要时间):
```bash
# 创建 求解/问题X/ 目录
mkdir -p 求解/问题1/{图片,结果}
# 复制 code-template.py 改写 (或 mechanism-template.py 机理题)
cp references/code-template.py 求解/问题1/问题1_xxx.py
# 跑: python 求解/问题1/问题1_xxx.py
# 输出: 图片/*.png + 结果/result1.xlsx
```

**checkable 绿判据**: 6 脚本 py_compile 通过 + profile_data EDA 报告 + 求解/问题X/8 项自检 (走 paper-spec.md §2).

**Step 3 写论文** (8-12 小时):
```bash
# 复制 论文/0-10 章.tex 模板, 按 BZD 5 段结构 (建立/求解/结果/检验/灵敏度) 写
# 9.0.AI工具使用声明.tex 二者择一
# 10.0.附录固定说明.tex 两段必填
# AI工具使用详情.tex (用了 AI 必填)
```

**checkable 绿判据**: 11 章节 .tex 全存在 + 每个 ≥ 30 行 + AI 声明二者择一已选 + 附录固定说明两段已填.

**Step 4 编译+终态** (30 分钟):
```bash
# 编译
cd 论文
xelatex -interaction=nonstopmode 论文.tex  # × 2
xelatex -interaction=nonstopmode 电子版.tex  # × 2
xelatex -interaction=nonstopmode AI工具使用详情.tex  # × 2
cd ..
# 装包
python tools/pack.py
# 跑 dry-run 终检
python references/scripts/dryrun.py
# 期望: 6/6 全 green = sign-off 绿
```

**sign-off 绿判据** (dryrun.py 输出):
- 装包 green
- 6 脚本 green
- LaTeX 24 页 0 ! Error
- Overfull = 0 (< 5)
- pack.py 2 zip 生成
- AIGC 综合 🟢 低

**全部 green = sign-off = 可交卷**.
