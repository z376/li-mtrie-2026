# 生物医疗类典型反模式 (v1.5.7.15 新增, 生物医疗题类适配)

> **⚠️ 适用题类**: CUMCM/MCM/ICM **A 题 (生物医学/传染病/药物动力学) + 临床决策/基因/蛋白质/流行病学**. 核心特征: **生物机理 + 临床/实验数据 + 个体差异 + 伦理/隐私**, 通常**有时间序列 + 个体异质性**, 也有**风险评估/分类/预测**问题.

> **5 道防线使用**: 防线 1 + 3 + 4 **完全适用**; 防线 2 (数据隔离) **部分适用** (时序数据严格, 临床数据不能跨问题混用); 防线 5 (三口径) **部分适用** (用"敏感性/特异性/PPV/NPV" 替代).

## 1. 生物医疗类典型反模式

| # | 反模式 | 防线 | 修正做法 |
|---|--------|------|---------|
| 1 | **自创生物机理** (e.g. 自创"修正 SIR 模型") | 1/3 | **严格按已知生物机制** (教材/论文); 自创 = 评阅 0 分. 引用文献 |
| 2 | **个体差异忽略** (e.g. 全人群用同一参数) | 3 | **分层/随机效应**: 按年龄/性别/基础病分层, 或用 mixed-effects model |
| 3 | **临床指标单位错误** (e.g. 浓度 mg/mL vs μmol/L 混用) | 1 | **统一单位**: 论文 §2 公式前后声明 SI 单位 (e.g. 浓度统一 μmol/L) |
| 4 | **伦理/隐私忽略** (e.g. 用了真实患者数据但未脱敏) | 1 | §3.1 报告**数据脱敏** + 伦理审查 (IRB) + 知情同意 |
| 5 | **基线不齐** (e.g. 治疗组 vs 对照组基线不同)** | 3 | **倾向得分匹配 / 协变量调整** + 报告标准化差异 (SMD < 0.1) |
| 6 | **样本量不足没报告功效** (e.g. n=30 没算统计功效) | 3 | **功效分析**: §3.2 报告 1-β (≥ 0.8), α (e.g. 0.05) |
| 7 | **多重比较没校正** (e.g. 100 个 p-value 不 Bonferroni/FDR) | 1 | **多重校正**: Bonferroni / FDR (Benjamini-Hochberg), 报告校正后 p-value |
| 8 | **没区分相关 vs 因果** (e.g. 吸烟-肺癌只算相关没说因果) | 3 | **因果推断**: 报告 "相关 ≠ 因果", 用 DAG/Mendelian randomization 等方法 |
| 10 | **临床决策指标选错** (e.g. 类别不平衡用 accuracy) | 5 | **临床指标**: 敏感性/特异性/PPV/NPV/AUC, 不用 accuracy (类别不平衡) |
| 11 | **跨问题数据混用** (e.g. 男胎样本用到女胎预测) | 2 (变体) | **严格按题面**: 男胎 (1082 例) / 女胎 (605 例) 跨问题不混用 |

**典型例题**: 传染病模型 (SIR/SEIR) / 药物动力学 (PK/PD) / 临床决策 (诊断/治疗) / 基因表达 / 蛋白质折叠 / 流行病学.

## 2. 跑题前自检 checklist (生物医疗类)

- [ ] **生物机理引用**: §1.1 列出所有引用的已知生物机制 + 文献 (教材/同行评议论文)
- [ ] **个体差异处理**: §2.3 报告分层 / mixed-effects / 异质性分析
- [ ] **临床指标单位**: §2 公式前后统一 SI 单位 (浓度 μmol/L, 血压 mmHg 等)
- [ ] **数据脱敏**: §3.1 报告脱敏方法 + 伦理审查 (IRB) + 知情同意 (题目或泛用)
- [ ] **基线比较**: §3.3 报告治疗组 vs 对照组基线表 + SMD < 0.1
- [ ] **样本量功效**: §3.2 报告 1-β (≥ 0.8), α (e.g. 0.05)
- [ ] **多重比较**: §3.4 报告 Bonferroni / FDR 校正
- [ ] **因果推断**: §4 末尾报告 "相关 ≠ 因果", 用 DAG / 工具变量等
- [ ] **临床指标**: §3.5 报告 敏感性/特异性/PPV/NPV (类别不平衡不用 accuracy)

## 3. 跑完后期望对照 checklist (生物医疗类)

| 检查项 | 期望方向 | 量化判据 | 实际值 | 命中? |
|--------|---------|---------|--------|-------|
| 模型拟合 | 模型 vs 实验数据 吻合 | R² > 0.9 / 残差正态 | ___ | ☐ |
| 临床指标 | AUC > 0.85 / 敏感性 > 0.8 | 报告 ROC 曲线 | ___ | ☐ |
| 个体差异 | mixed-effects 显著 | 随机效应方差 > 0 | ___ | ☐ |
| 极端场景 | 极端 (e.g. 流行病高峰) 行为正确 | 模型预测 vs 实际 < 10% | ___ | ☐ |
| 灵敏度 | 关键参数 ±10% 输出影响 | 报告参数影响 + 临床意义 | ___ | ☐ |
| 多重校正 | 校正后 p-value 仍显著 | FDR < 0.05 | ___ | ☐ |

**不命中**: ✗ → 检查 (1) 生物机理是否对 (2) 个体差异是否考虑 (3) 单位是否一致 (4) 基线是否齐 (5) 临床指标是否合适.

## 4. 与物理机理类 的差异

| 维度 | 物理机理类 | 生物医疗类 |
|------|----------|----------|
| **机理来源** | 物理定律 (Navier-Stokes/Fick) | 生物机制 (SIR/PK-PD) |
| **单位** | SI (m/s/Pa) | 临床单位 (mmHg/mg/dL) |
| **个体差异** | 通常忽略 | **必须考虑** (mixed-effects / 分层) |
| **数据隐私** | 通常公开 | **必须脱敏 + IRB** |
| **多重比较** | 通常无 | **必须 Bonferroni/FDR 校正** |
| **因果 vs 相关** | 模型即因果 (物理方程) | 多半**只相关**, 需因果推断工具 |
