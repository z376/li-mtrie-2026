# 归档 (历史记录, 跑题时**不要读**)

> **这是什么**: 本 skill 开发期的历史记录 —— 开发日志、测试报告、早期的流程审计闭环文档.
> **跑题时不用读**: 这些是**怎么造出这个 skill** 的过程记录, 与"怎么用这个 skill"无关.
> 只有在你想追溯某条规则/某个 check 是什么时候、为什么加的时候才翻这里.

| 文件 | 内容 | 什么时候翻 |
|------|------|-----------|
| `开发日志.md` | 每个版本 session 的开发决策记录 (做了什么 + 为什么) | 想知道"某条规则当初为什么这么定" |
| `测试报告.md` | 早期 dryrun / 冒烟测试的输出留档 (含历史 check 数与状态) | 想看 check 的历史行为 / 回归对比 |
| `2026-08-25-流程审计-19漏点-已闭环.md` | 第一次 writing-for-agents 审计发现的 19 个漏点及其闭环 | 想知道审计体系是怎么建起来的 |

> ⚠️ **版本相关的数字已过时**: 这里的 check 数量 / 状态是当时的快照, **不代表现在**.
> 当前状态以 `references/scripts/dryrun.py` 的 `CHECKS` 表 + `CHANGELOG.md` 为准.
