# 物理机理类典型反模式 (v1.5.7.14 新增, 物理机理题类适配)

> **⚠️ 适用题类**: CUMCM **A 题 (本科物理机理类)** + 物理/力学/流体/传染病/生物医学等以**机理建模**为核心的题. 核心特征: **已知物理定律 (e.g. Navier-Stokes / Fick 定律 / SIR 模型) → 数学方程 (PDE/ODE) → 数值求解** (有限元/有限差分/有限体积).

> **5 道防线使用**: 防线 1 (流程修剪) + 防线 3 (设计意图) + 防线 4 (指针强化) **完全适用**; 防线 2 (数据隔离, 周期起点决策) **不适用**; 防线 5 (三口径铁律) **部分适用** (用"模型假设清单" + "物理量单位一致性" 替代).

---

## 1. 物理机理类典型反模式

| # | 反模式 | 防线 | 修正做法 |
|---|--------|------|---------|
| 1 | 自创物理方程 (e.g. 自创"修正 Navier-Stokes") | 1/3 | **严格按已知物理定律** (教材/论文/官方公式); 自创 = 评阅 0 分 |
| 2 | 边界条件漏写/错写 (e.g. 漏写"无滑移条件") | 1 | 边界条件**完整列出** + 物理意义注解 |
| 3 | 单位不一致 (e.g. 长度用 m, 时间用 s, 流量用 L/h 单位混用) | 1 | **SI 单位制统一** + 论文 §2 公式前后单位声明 |
| 4 | 模型假设"简化"过头 (e.g. 把非线性方程线性化后失真) | 1/3 | 假设简化**说明理由** + 简化后误差量级评估 |
| 5 | 数值方法选错 (e.g. PDE 用显式 Euler 失稳) | 1 | 选**稳定性已知**的方法 (e.g. 隐式/Crank-Nicolson) + 网格收敛性分析 |
| 6 | 网格/时间步长没做细化分析 | 3 | **网格独立性验证**: e.g. 网格 1/2/4 倍加密, 解相对误差 < 5% 才算收敛 |
| 7 | 没验证物理量守恒 (e.g. 质量守恒/能量守恒) | 3 | **守恒律验证**: e.g. 进出口流量差 < 1%, 能量误差 < 5% |
| 8 | 模型结果与解析解/实验值差距大, 找借口"数据不真实" | 3 | **改模型/改假设**, 不能用数据当借口. 物理机理题数据通常是**已知/可控**, 模型错就是错 |

**典型例题**: 传染病模型 (SIR/SEIR) / 热传导方程 / 流体力学 / 力学振动 / 光学成像.

## 2. 跑题前自检 checklist (物理机理类)

- [ ] **物理定律引用**: 论文 §1.1 列出所有引用的已知物理定律 + 文献
- [ ] **模型假设清单**: §1.2 列假设 (e.g. "忽略粘性耗散 / 一维简化"), 每条假设**说明理由** + 简化后误差量级
- [ ] **边界条件/初始条件**: §1.3 完整列出 + 物理意义
- [ ] **参数估计方法**: §2 说明每个参数的物理意义 + 取值来源 (实验/文献/拟合)
- [ ] **数值方法选择**: §3 写明方法 + 稳定性条件 + 网格收敛性分析计划
- [ ] **单位声明**: §2/§3 公式前后统一 SI 单位
- [ ] **期望结果方向**: §4 写"模型输出 vs 解析解/实验值 相对误差 < 5%" 或"网格收敛后参数稳定"

## 3. 跑完后期望对照 checklist (物理机理类)

| 检查项 | 期望方向 | 量化判据 | 实际值 | 命中? |
|--------|---------|---------|--------|-------|
| 物理量守恒 | 质量/能量/动量守恒 | 相对误差 < 1% | ___ | ☐ |
| 网格收敛 | 网格 2 倍加密解不变 | 相对误差 < 5% | ___ | ☐ |
| 与解析解对比 | 模型 vs 解析解 (简化场景) | 相对误差 < 5% | ___ | ☐ |
| 极限情况 | 极限值 (e.g. t→∞ 趋向稳态) | 行为正确 | ___ | ☐ |
| 参数灵敏度 | 关键参数 ±10% 输出影响 | 影响在物理量级内 | ___ | ☐ |

**不命中**: ✗ → 检查 (1) 物理方程引用对不对 (2) 边界条件是否漏 (3) 数值方法稳定性 (4) 网格/时间步长是否够细.
