## 1. 整题建模主线（Step 1 子步骤，先画全篇骨架再分问）

**为什么**：每年评委会加分项，"全篇思路连贯"比"每问用什么花哨算法"更重要。
在给每问列候选模型前，**先**回答 3 个全篇级问题：

### Q1：全篇的研究对象和中心矛盾是什么？

模板：本题研究 ______（研究对象），其核心矛盾是 ______
（如：效率 vs 公平、机理 vs 数据、局部最优 vs 全局最优），
最终目标是在 ______ 约束下实现 ______。

### Q2：跨问题联动链是什么？（哪问的输出是另一问的输入？）

评委会"一看就懂"的 6 种模式：

| 联动模式 | 典型用法 | 关键注意点 |
|----------|---------|------------|
| 机理→计算→精度 | 后问给前问加修正项 | 状态量/坐标系一致 |
| 描述→估计→预测→决策 | 估计/预测结果喂给决策 | 传递领域知识和不确定性 |
| 单例→多主体/阶段 | 同一仿真器多场景复用 | 加协调/分配/递归/复杂度 |
| 确定性→不确定→稳健 | 参数状态变化 | 保约束，加场景/分布/风险 |
| 单因素→多因素 | 后问个性化/扩展 | 保可运行输出，对比改进 |
| 分类→优化 | 预测控制决策 | 防数据泄露，审计决策误差 |

写明：哪问 → 输出什么 → 哪问输入 → 当作什么用（参数/初值/约束/验证集）。

### Q3：全文统一的符号表

直接写到论文第 4 章「符号说明」（详见 `paper-spec.md` 第 4 章）。
关键字段：研究对象集合 / 索引 / 决策变量 / 共享参数 / 单位 / 坐标系 / 时间约定 / 评价指标。

### Q4（可选）：Mermaid 联动流程图

```mermaid
flowchart LR

```

跨问题数据/参数/约束的传递画清楚——评委会看图秒懂全篇思路。

### 1.5 每个问题 4 段式分析（借鉴 bzd-modeling-ideas 4.x.1-4.x.4）

**为什么**：Q1-Q4 是"全篇"骨架，每道题内部还要 4 段细分。把每道题按 4 段写出来，**论文里 5.1 章节直接对应**。

对**每道问题**按以下 4 段顺序写：

| # | 段名 | 内容 | 论文对应章节 |
|---|------|------|--------------|
| 4.x.1 | **问题概述** | 任务（动作+对象） / 已知（题面条件+继承自前问的输出） / 输出（精确数值/分类/函数/图/文件）/ 本质（数学结构+为何选它） | §1 引言问题重述 + §4 符号 |
| 4.x.2 | **总体求解思路** | 从原始数据到请求结果的完整路径：处理→建模→求解→验证。标识**输入继承**（前问输出）和**输出给后问**（参数/初值/约束/验证集） | §5.X.1 分析与准备 |
| 4.x.3 | **可用模型及选型比较** | ≥2 个**真正不同**的候选模型（不是同算法的不同 solver）。给：模型本质+核心变量+实现步骤+所需数据/假设+优点+局限与失败风险+验证方法+前后问接口。表后写**推荐模型**+**选用理由**+**备选模型**+**多模型对比建议** | §5.X.2 建模与求解 |
| 4.x.4 | **创新与改进方向** | 实施项+基线+具体改动+预期改进+新增工作量+验证指标+风险+备用方案+影响问题。**简单换算法/加可视化/堆因素不算创新** | §8 模型改进与推广 |

**与 SKILL.md 现有 8 项自检的关系**：
- 4.x.1 → 自检第 4-5 条（"题面硬约束已程序化验证""每个最优/预测有独立验证"）
- 4.x.2 → 自检第 3 条（"硬约束可程序化验证吗"）
- 4.x.3 → 自检第 1-2 条（"跨问题参数复用""后问输入是前问输出"）
- 4.x.4 → 自检第 6 条（"每个最优/预测有独立验证"）

**反例**（bzd 警告）："使用遗传算法""模型融合""增加可视化""考虑更多因素" 单独使用**不算创新**——必须有具体改动 + 验证 + 对照。

## 3. 8 项整篇一致性自检回填格式

> 8 项内容见 `paper-spec.md §4.0`（权威源）。
> 本节只给"回填格式"和"踩坑教训"。

**每写完一个问题的代码，必须**在 `求解/求解计划.md` 末尾的"自检"区逐项回填。
**不回填 = 该问题未完成。**

```markdown
## 8 项整篇一致性自检（每个问题完成后回填）

### 问题 1 ✅
- [x] 符号、坐标、时间、单位系统与全篇一致？（具体说明）
- [x] 共享参数 p=0.55, L=2.20m, d=0.275m 一次估出且复用？（具体值）
- [x] 本问无继承自前问的输出（第一问）/ 本问继承自问题 N 的 X（具体值）
- [x] 硬约束 ... 可验证（程序 round(6) / min_sep ≥ ...）
- [x] 不确定性 N/A / 95% CI 传至问题 N
- [x] t=0..300 龙头位置独立验证：t=0 在 (8.8, 0) 第 16 圈 ✓
- [x] result1.xlsx N 个 sheet 完整生成（位置+速度, 448×302 + 224×302）
- [x] 各候选方案对比已记录在 `求解计划.md`

### 问题 2 ✅
...
```

**5 个必查踩坑**（每问跑）：

1. 跨问题参数复用了吗？（问题 1 估的 p, L 在问题 3 还在用吗？是否一致？）
2. 后问的输入是不是前问的输出？（问题 2 的"碰撞距离阈值"是 0.30m 吗？问题 1 估的？）
3. 硬约束能程序化验证吗？（"不碰撞" → 检查 `min_sep ≥ 板宽`）
4. 每个最优/预测结果有独立验证吗？（龙头 t=0 位置能用手算 `r=pθ/(2π)` 验证）
5. 每个输出表/文件按题目列表生成吗？（result1/2/4 全到位）

## 5. 图表规范 + 图路径（B4 踩坑专项）

### 5.1 通用规范

- 图宽 `0.8\textwidth`，表宽 `\textwidth`
- 所有表格统一 `longtable` + `>{\centering\arraybackslash}p{}`
- `caption/label` 顺序：`\caption{...}\label{tab:xxx}`，caption 在 label 前
- 图文件通过相对路径引用：`../求解/问题X/图片/xxx.png`

### 5.2 图路径规范（B4 踩坑教训，必看）

> xelatex 编译时工作目录是 `论文/`，**不是项目根目录**。所有 `\includegraphics` 路径从 `论文/` 起算。

**路径映射表**：

| 你的意图 | 错写法 | 正确写法 |
|---------|---------|---------|
| 引用问题 1 的图 | `求解/问题1/图片/龙头轨迹.png` | `../求解/问题1/图片/龙头轨迹.png` |
| 引用问题 3 的图 | `../../求解/问题3/图片/pitch.png` | `../求解/问题3/图片/pitch.png` |
| 图就在 `论文/` 下 | `图片/xxx.png` | `图片/xxx.png`（仅当图确实在 `论文/图片/`） |
| 绝对路径 | `D:\Math\求解\问题1\图片\xxx.png` | **不允许**，换电脑就坏 |

**编译报错对照**：

| 报错 | 原因 | 修复 |
|------|------|------|
| `! LaTeX Error: File 'xxx.png' not found.` | 路径错了（多半少一个 `..`）| 从 `论文/` 起算，前面加 `..` |
| `! Unable to load picture or PDF file.` | PNG 文件本身坏了 / 路径含中文编码异常 | 用英文文件名重命名 |
| 图能编但显示空框 | 用了 `draft` 模式 | 编译命令去掉 `-draftmode` |

**自检脚本**（编译前跑一次，列图存在性）：

```powershell
# 在论文/ 目录下跑
$figs = Get-ChildItem -Path ..\求解 -Recurse -Include *.png
foreach ($f in $figs) {
  $rel = $f.FullName.Replace((Get-Location).Path + '\..\', '')
  $rel = $rel -replace '\\', '/'
  Write-Host "../$rel  ← 检查 .tex 里 \includegraphics 路径是否一致"
}
```

**命名规范**：
- PNG 文件名用**英文 + 下划线**（不要中文 + 空格）
- 路径里**避开**空格、括号
- 相对路径**始终从 `../求解/...` 起步**

## 7. 常见错误（求解和写论文时主动避开）

1. 公式堆砌无串联 → 每个公式前后有中文过渡句
2. 变量无说明 → 每个公式后跟"其中，$X$表示…"
3. 表格用 `tabular`/`tabularx` → 统一 `longtable` + `p{}`
4. 图上写标题 → 标题放在 `\caption{}`
5. 图表无引用 → "如图 X 所示""如表 X 所示"
6. 正文分点符号 → 自然段落
7. 摘要超页 → 编译后验证，超了就缩减
8. 参考文献无引用 → 每条 `\bibitem` 对应正文 `\cite`
9. 优化模型只写文字 → 完整写出目标函数+约束+变量
10. 模型检验缺失 → 交叉验证+灵敏度分析缺一不可
