# 数学建模竞赛 Skill — 完整工作流

> 读题 → 计划（多模型对比 → 用户选择）→ 求解 → 论文 → 编译

**2026 规范对齐**：本工作流按 2026 年全国大学生数学建模竞赛论文格式规范
（2026 年修订稿，2026-09-01 起试行）+《人工智能工具使用规定（2026 年试行）》
更新，重点：
- 题组判断（本科 ABC / 高职 DE）
- 摘要一律中文，不要目录，正文 ≤ 30 页
- 附录两段固定说明（程序/支撑材料）
- 论文版与电子版**两套入口**（`论文.tex` 用 `withpreface`，`电子版.tex` 用 `electronic`）
- AI 工具使用声明放**参考文献之前**（不是附录）
- AI 工具使用详情 PDF 放**支撑材料**（不是附录）

用户说"开始求解""求解这个题目""生成论文"即启动。

## 执行流程

### Step 0：读取输入

- 读取 `题目/` 下 PDF/DOCX
- 读取 `数据/` 下所有 xlsx/docx/csv，**全量读取**，检查：列数一致性、数据类型、合并单元格、多级表头、隐藏 sheet
- 打印数据总览，识别问题数量 N

### Step 1：求解计划（含模型比选）

读完题后，**先不写完整计划**，而是为每个问题列出候选模型的对比分析，供用户选择。

#### 1a. 模型比选

对每个问题，列出 3-4 个候选模型/方法，逐一说明：

```
问题X：<问题简述>

| 方案 | 核心方法 | 优点 | 缺点 | 适用条件 |
|------|---------|------|------|---------|
| 方案A | （具体算法名） | （2-3条） | （1-2条） | （数据/假设要求） |
| 方案B | ... | ... | ... | ... |
| 方案C | ... | ... | ... | ... |

推荐：方案X，理由：...
```

模型选择要点：

- 问题本质定性（优化/评价/预测/分类/机理）→ 匹配对应类型的方法
- **有数据的题目**：至少包含一个机器学习/统计模型 + 一个传统机理模型
- **优化类题目**：至少包含一个精确算法 + 一个启发式算法
- **评价类题目**：至少包含主观赋权法（AHP）+ 客观赋权法（熵权/CRITIC）

候选模型池：

| 问题类型 | 候选模型池 |
|----------|-----------|
| 优化类 | 线性/整数规划、遗传算法(GA)、粒子群(PSO)、模拟退火(SA)、蚁群(ACO) |
| 评价类 | 熵权法、AHP层次分析、TOPSIS、模糊综合评价、CRITIC、灰色关联 |
| 预测类 | 时间序列(ARIMA)、随机森林、XGBoost、LSTM、灰色预测GM(1,1)、多元回归 |
| 分类/识别 | 逻辑回归、SVM、随机森林、KNN、朴素贝叶斯、CNN |
| 机理分析 | 微分方程、动力学建模、元胞自动机、Agent-Based模型 |

#### 1b. 用户选择

将对比表展示给用户，**等待用户选择每个问题的方案**。用户选择后，再写完整的 `求解/求解计划.md`，按选定方案细化求解思路和具体参数。

### Step 2：逐题求解

- 创建 `求解/问题X/图片/` 和 `求解/问题X/结果/`
- 每个问题一个 py 文件，**中文命名**
- **先算后画**：计算完成 → 打印 min/max/mean/std → 再画图
- 每题至少 **4-6 张图**，覆盖主要分析维度
- 问题 1 输出 `求解/预处理数据.csv` 供后续共用
- **灵敏度分析前置**：求解阶段就测关键参数影响
- 脚本报错 → 修复 → 重跑，通过后再下一问

### Step 3：写论文

每问拆两个子文件：

- `5.X.1.分析与准备.tex`：具体分析（三段式+9框流程图）+ 数据预处理（仅问题1）+ 算法选择对比表
- `5.X.2.建模与求解.tex`：模型建立（步骤式推导）+ 模型求解（结果表+图+分析）

**2026 规范特别检查**（与一般格式规则并列）：

- [ ] 摘要**一律中文**（无英文摘要/英文标题/英文关键词）？
- [ ] 全文**无目录**、**正文 ≤ 30 页**？
- [ ] 附录含「程序使用说明」+「支撑材料说明」两段固定句？
- [ ] **参考文献之前**有「AI 工具使用声明」（用/没用 AI，二选一）？
- [ ] **支撑材料**里有 `AI工具使用详情.pdf`（用了 AI 才需要）？
- [ ] 附录**不写** AI 段（旧 2025 模板的 AI 段已删除）？
- [ ] 论文中由 AI 生成的段落/公式/图处有内联标注？
- [ ] 已选 题组（本科 ABC / 高职 DE） 与论文一致？

**2024 通用自检**：

- [ ] 摘要 ≤900 字、恰好 1 页？
- [ ] 每问有分析流程图？
- [ ] 问题 1 有数据预处理（含公式）+ 算法对比表？
- [ ] 每问建模 ≥6 个公式，公式间有文字串联，每个公式后有变量说明？
- [ ] 所有图表被正文引用？
- [ ] 有误差分析（交叉验证）+ 灵敏度分析？
- [ ] 优点 4 条 + 缺点 2 条？
- [ ] 参考文献 8-15 条且全部被 `\cite{}` 引用？
- [ ] 全文无分点符号、正文无加粗、无多余 `\newpage`？
- [ ] 所有表格统一 `longtable` 格式？

### Step 4：编译

**2026 规范要求两份产物**（规范第九/十条）：

```powershell
# 1. 论文版（含承诺书+编号页）— 纸质提交用
Set-Location 论文
xelatex -interaction=nonstopmode 论文.tex
xelatex -interaction=nonstopmode 论文.tex
(Get-Content 论文.log) | Select-String -Pattern 'Error' | Measure-Object | Select-Object -ExpandProperty Count  # 必须为 0

# 2. 电子版（不含承诺书+编号页，第一页直接是摘要）— 电子提交用
xelatex -interaction=nonstopmode 电子版.tex
xelatex -interaction=nonstopmode 电子版.tex
(Get-Content 电子版.log) | Select-String -Pattern 'Error' | Measure-Object | Select-Object -ExpandProperty Count  # 必须为 0
```

**2026 规范第十条对电子版**：`电子版.pdf` ≤ 20MB，**不要压缩**（PDF 本身就是压缩
格式），建议输出 PDF（不用 Word）。

### Step 5：排版优化

```bash
grep 'Overfull\|Underfull\|Float too large' 论文.log
```

修复 → 重编译 ×2，直到日志干净。

## 论文核心规则

### 禁止事项（违反即扣分）

| 禁止 | 例外 |
|------|------|
| 正文分点符号（①②③、●○、1.2.3.） | 模型假设/评价的 itemize |
| 正文加粗 `\textbf{}` | 摘要"对于问题X"、问题重述"问题N："、假设/优缺点头部 |
| 全文 `\newpage` | 仅参考文献和附录前可用 |
| 图上 `set_title()` | 标题由 `\caption{}` 承担 |
| 表格换行 | 格子文字一行显示 |
| 摘要超 1 页或含公式 | — |

### 各章关键约束

**0. 摘要**：开头 ≤30 字 + 逐问（按类型选模板）+ 结尾 ≤20 字 = 总计 ≤900 字。编译后验证 `abstract:end` label 在第 1 页。

**1. 引言**：背景 2-3 段（宏观→困境→渴求），问题重述每条 `\textbf{问题N：}` ≤2 行。

**2. 总体分析**：三段纯文字，**不画流程图**。

**3. 模型假设**：itemize，`\textbf{假设N：}`，数量 ≈ 问题数。

**4. 符号说明**：`longtable`，列宽比例总和 = 1.04 − 0.04×N。

**5. 模型的建立与求解**（核心，占全文 50-60%）：

- 每问的分析流程图：9 框 TikZ 模板，只改 `{}` 中文字，每框 ≤7 字，箭头布局不动
- 建模步骤按问题类型走：优化类（目标→约束→机理→算法）、评价类（指标→权重→综合评价）、预测类（特征→模型→训练评估）
- 每问 ≥6 个公式，核心步骤公式密集，公式间用"将式(X)代入式(Y)""进一步展开得"串联
- 每个公式后跟"其中，$X$表示…"变量说明段
- **优化类必须完整写出目标函数+决策变量+约束条件**，不可用文字概括

**6. 模型检验**：误差分析（5折交叉验证，$R^2$/RMSE/MAE/MAPE）+ 灵敏度分析（参数 ±20%）

**7. 模型评价**：优点 4 + 缺点 2，**按模型写不按问题写**

**8. 模型改进与推广**：各一段自然段落

**9. 参考文献**：8-15 条，GB/T 7714-2015，优先中文。标签：中文=作者拼音+年份，英文=姓+年份+关键词。**禁止** `\emph{}` `\textbf{}`，删除 DOI。每条必须在正文有 `\cite{}`。

**10. 附录**：`longtable` 两列附件说明表。

### 图表规范

- 图宽 `0.8\textwidth`，表宽 `\textwidth`
- 所有表格统一 `longtable` + `>{\centering\arraybackslash}p{}`
- caption/label 格式：`\caption{...}\label{tab:xxx}\\`，caption 在 label 前
- 图文件通过相对路径引用：`../求解/问题X/图片/xxx.png`

## 代码规范

**绘图不限制库**，matplotlib/seaborn/plotly/Pillow 均可。

**硬性规则**：

- 图上不设标题（`set_title()`），坐标轴标签和图例全中文
- 图片保存至 `求解/问题X/图片/`
- 先算后画：所有数值结果打印后再画图
- 每题 ≥4 张图

**公共头部**（按需调整库，详见 `references/code-template.py`）：

```python
import pandas as pd
```

## 常见错误（求解和写论文时主动避开）

1. ❌ 公式堆砌无串联 → ✅ 每个公式前后有中文过渡句
2. ❌ 变量无说明 → ✅ 每个公式后跟"其中，$X$表示…"
3. ❌ 表格用 `tabular`/`tabularx` → ✅ 统一 `longtable` + `p{}`
4. ❌ 图上写标题 → ✅ 标题放在 `\caption{}`
5. ❌ 图表无引用 → ✅ "如图X所示""如表X所示"
6. ❌ 分点符号 → ✅ 自然段落
7. ❌ 摘要超页 → ✅ 编译后验证，超了就缩减
8. ❌ 参考文献无引用 → ✅ 每条 `\bibitem` 对应正文 `\cite`
9. ❌ 优化模型只写文字 → ✅ 完整写出目标函数+约束+变量
10. ❌ 模型检验缺失 → ✅ 交叉验证+灵敏度分析缺一不可
