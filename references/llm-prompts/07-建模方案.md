# 07-建模方案 (Modeling Ideas, v1.5.8.1, 借 BZD bzd-modeling-ideas)

**用途**: 跑题 Step 1 必跑, 读完题 + 走完 `references/读题翻译.md` 4 节报告后, **做整题建模方案**: 整题视角 + 逐题方案 + 跨题连续性 + 模型比选 + 创新点 + 验证闭环. **目标**: 建 1 个贯通全题的建模系统, 共享数据/变量/参数/约束.

**借鉴**: BZD 数模社 `bzd-modeling-ideas` v1.0 (2026-08-18) 的方法论 (整题视角 + 跨题连续性 + 候选模型比选 + 创新点 + 验证闭环), v1.5.1 精简风格 (不复制 BZD 完整子树).

**配套方法论**: `references/建模方案框架.md` (4.6 KB, v1.5.8 借鉴 BZD 后写的精简方法论).

**与 06-读题翻译 关系**:
- **06-读题翻译** = 输入 (赛题 → 4 节翻译报告)
- **07-建模方案** = 输出 (赛题 + 翻译报告 → 5 节建模方案)

**使用**: 复制下方 prompt, 粘贴赛题 PDF 内容 + (可选) 读题翻译报告, 拿 LLM 输出填 `求解/建模方案.md`.

## 使用流程 (5 步, 60-90 分钟)

```powershell
# 步骤 1: 准备输入 (已跑 05-读题提取 + 06-读题翻译)
# 输入 1: 题目_文本.txt (PyMuPDF 提取的完整赛题)
# 输入 2: 求解/读题翻译报告.md (可选, 但强烈建议)

# 步骤 2: 复制下方 prompt, 粘贴 题目_文本.txt 内容 + 翻译报告, 喂 LLM (15 分钟)

# 步骤 3: LLM 输出 → 填 求解/建模方案.md (30 分钟手动整理)
# 验证: 5 节齐 + 每题 4 块 + 比选表 6 维齐

# 步骤 4: 团队讨论 + 选定模型 (30 分钟)
# 关键: 不要直接用 LLM 推荐的模型, 团队对照参考论文 + 跑通代码后再确认

# 步骤 5: 选定后写 求解/求解计划.md (15 分钟)
# 把"选定模型 + 参数"从建模方案提取到求解计划
```

## Prompt (复制下面整段)

```
你是一名熟悉数学建模国赛规范的助手。请从下方完整赛题文本 (和可选的读题翻译报告),
按照 v1.5.8 借鉴自 BZD 数模社 bzd-modeling-ideas 的方法论, 出**整题建模方案**:
1 套贯通全题的建模系统, 不是给每题贴一个模型名的拼盘.

要求:
1. **整题视角先**: 3 个问题先问: 共享数据/变量/参数/约束有哪些 (→ 公共层)?
   问题 1-3 数学本质是同一类吗 (→ 统一求解器)? 问题 3 复用问题 1-2 中间结果吗
   (→ 求解顺序)?
2. **逐题 4 块**: 每道题拆 (a) 任务与本质 (b) 候选模型 (c) 选定模型 (d) 求解与验证
3. **跨题连续性**: 强制 4 维检查 (共享数据/共享变量/共享约束/上一问输出=下一问输入)
4. **候选模型比选表**: 每问题至少 2-3 个候选, 6 维 (任务对齐/数据充分/假设站得住/
   约束保留/可解释/可验证) 评估, 6 维中至少 5 维"高/中"才推荐
5. **创新点 3 类**: (a) 方法迁移 (b) 约束耦合 (c) 验证强化 — 避免假创新
6. **验证闭环**: 4 维组合 (留出验证 + 物理一致性 + 灵敏度分析 + 反事实/基线),
   最少 2 维, 4 维全做才"国奖级"
7. **不发明**: 不编造数据/系数/结果/精度, 标 unavailable + 给条件分支
8. **不复制历史**: 借鉴历史 16 题 (2020-2025) 的**期望** (覆盖/适配/连续/可信/独立
   /可实施创新), 不复制具体模型或数值结论

输出格式:

# 建模方案 — [题号] [年份]

## 0. 整题框架

### 0.1 1 段描述 (200-300 字)
[用 1 段说清: 这是个什么题, 整体数学本质, 3 个问题是否同质, 求解顺序建议]

### 0.2 系统图 (文字版)
```
[问题 1] → [中间结果 X] → [问题 2] → [中间结果 Y] → [问题 3] → [交付]
       ↑                  ↑                  ↑
       共享: 数据 / 变量 / 参数 / 约束
```

## 1. 逐题方案

### 1.1 问题 1: [题面原话摘录]

**1.1.1 任务与本质**:
- 题目问: ...
- 数学本质: 分类 / 优化 / 预测 / 仿真 / 解释 (选 1)

**1.1.2 候选模型** (≥ 2 个):

| 模型 | 任务对齐 | 数据充分 | 假设站得住 | 约束保留 | 可解释 | 可验证 | 综合判定 |
|------|---------|---------|-----------|---------|--------|--------|---------|
| M1 (e.g., 多目标规划) | 高 | 中 | 高 | 高 | 高 | 高 | ✓ 推荐 |
| M2 (e.g., 启发式) | 中 | 高 | 中 | 中 | 低 | 中 | ✗ 备选 |
| M3 (e.g., 强化学习) | 高 | 低 | 低 | 中 | 低 | 中 | ✗ 数据不够 |

**1.1.3 选定模型**: M1
- 理由 1: ...
- 理由 2: ...
- 理由 3: ...

**1.1.4 求解与验证**:
- 算法: ...
- 评价指标: ...
- 验证组合 (≥ 2 维, 推荐 4 维):
  - 留出验证: ...
  - 物理一致性: ...
  - 灵敏度分析: ...
  - 反事实/基线: ...

### 1.2 问题 2: [题面原话摘录]
[同问题 1 结构]

### 1.3 问题 3: [题面原话摘录]
[同问题 1 结构]

## 2. 跨题连续性 (强制检查)

| 维度 | 问题 1 | 问题 2 | 问题 3 | 是否一致? |
|------|--------|--------|--------|----------|
| 共享数据 (e.g., 同一附件) | ... | ... | ... | ✓ / ✗ |
| 共享变量 (e.g., 同一参数) | ... | ... | ... | ✓ / ✗ |
| 共享约束 (e.g., 同一假设) | ... | ... | ... | ✓ / ✗ |
| 上一问输出 = 下一问输入 | ... | ... | ... | ✓ / ✗ |

**不一致修正**:
- 如果某行 ✗, 列出修正动作 (统一假设 / 改参数值 / 加映射)

## 3. 创新点 + 验证闭环 (汇总)

| 创新点 | 类型 (方法迁移/约束耦合/验证强化) | 解决的问题 | 评阅可识别度 |
|--------|-----------------------------------|-----------|------------|
| [创新 1] | ... | ... | 高/中/低 |
| [创新 2] | ... | ... | 高/中/低 |

**避免假创新自检**:
- [ ] 不是拼 3 个老模型 (要新数据集/新约束/新评价指标)
- [ ] 不是简单换场景 (要方法/机理的真实迁移)
- [ ] 不是重复验证 (要 1 个强化维度, e.g. 物理一致性 + 历史回放 + 反事实)

## 4. 风险与备选

| 风险 | 概率 | 影响 | 备选方案 |
|------|------|------|---------|
| M1 在问题 2 失效 | 中 | 高 | 切 M2 (备选) |
| 数据不足 (问题 3) | 低 | 中 | 借用问题 1 估计 + 加置信区间 |
| 灵敏度爆 (问题 1) | 中 | 中 | 简化假设 (去掉某项) |

## 5. 下一步行动 (转求解)

- [ ] 写 求解/求解计划.md (提取每题选定模型 + 参数)
- [ ] 建 求解/问题{1,2,3}/ 目录
- [ ] 跑 Step 2 (代码) — 每题 1 个 .py, 4 维验证齐
- [ ] 跑 Step 3 (论文) — 把"5 节方案"摘到 §2 总体分析 + §5 建模与求解

---

赛题原文:
<赛题 PDF 文本>
[在此粘贴 PyMuPDF 提取的题目_文本.txt 内容]
</赛题 PDF 文本>

读题翻译报告 (可选, 但强烈建议):
<读题翻译报告>
[在此粘贴 求解/读题翻译报告.md 内容]
</读题翻译报告>
```

## LLM 建模方案的常见问题 + 修法

| 问题 | 表现 | 修法 |
|------|------|------|
| **LLM 给每题贴 1 个模型名** | 没比选, 没说理由 | prompt 加"≥ 2 个候选 + 6 维评估 + 显式理由" |
| **LLM 编造数据/精度** | 写"准确率 95%" 无依据 | prompt 加"不发明数据/系数/精度, 标 unavailable" |
| **LLM 不做跨题连续性** | 3 个问题孤立 | prompt 加"强制 4 维检查 (数据/变量/约束/输入输出)" |
| **LLM 假创新** | 写"创新点 1: 用 AI" | prompt 加"避免假创新自检 3 条" |
| **LLM 验证组合缺维** | 只写"留出验证" | prompt 加"4 维组合, 最少 2 维, 推荐 4 维" |
| **LLM 不给备选** | 只说"用 M1" | prompt 加"风险与备选表 3+ 行" |
| **LLM 推荐历史模型** | "用 2024C 的 CTM" | prompt 加"不复制历史, 只借鉴期望" |

## v1.5.8 真实案例 (BZD 风格)

输入: 2025 国赛 A 题 "烟幕干扰弹投放策略" PDF + 读题翻译报告

LLM 输出 (5 节示例):

```
# 建模方案 — A 2025

## 0. 整题框架
1 段: 烟幕弹遮蔽效果, 核心数学本质: 几何遮蔽 + 时序优化 + 多弹协同
系统图: 烟幕云 r(t) → 问题 1 单弹最优 (时延/高度/速度) → 问题 2 多弹协同
(时延/高度/速度/方向 4 维) → 问题 3 反导对抗 (3 弹累加遮蔽)

## 1. 逐题方案

### 1.1 问题 1
任务: 单弹最优投放, 求 T_SHIELD
候选: M1=解析几何 (球-线相交) | M2=数值优化 (网格搜索) | M3=元启发式 (GA)
选定: M1 (几何直观 + 物理清晰 + 快速)
求解: Python 几何计算, 评价 = 遮蔽时长
验证: 物理一致性 (球体半径单调递增) + 反事实 (vs 启发式)

### 1.2 问题 2
任务: 多弹协同, 4 维优化
候选: M1=NSGA-II | M2=粒子群 | M3=网格搜索
选定: M1 (4 维 Pareto 前沿清晰)
求解: jmetalpy / pymoo, 评价 = T_SHIELD
验证: 4 维组合 (留出 + 物理 + 灵敏度 ±20% + 反事实 vs PSO)

### 1.3 问题 3
任务: 反导对抗, 3 弹累加
候选: M1=几何累加 (球-线求并) | M2=概率叠加 | M3=机器学习
选定: M1 (跟问题 1-2 同方法, 跨题一致)
求解: 复用问题 1-2 几何函数, 3 弹联合遮蔽
验证: 物理 + 灵敏度 + 反事实 (vs 单弹)

## 2. 跨题连续性
数据: 附录 1+2 全共享 ✓
变量: r(t) 全共享 ✓
约束: 球体假定全共享 ✓
输入输出: 问题 1 r(t) → 问题 2 多弹 r(t) → 问题 3 累加 ✓

## 3. 创新点
1. 几何-优化联合 (方法迁移) — 几何直观 + Pareto 多目标
2. 多弹协同物理一致性 (验证强化) — 球体累加的严格验证
3. 反导对抗的反事实 (验证强化) — 单弹/双弹/3 弹对比

## 4. 风险与备选
- 风险 1: 球体假定过强 → 备选 椭球 (降低置信度)
- 风险 2: 灵敏度爆 → 备选 简化参数
- 风险 3: 多弹计算量 → 备选 减弹数到 2

## 5. 下一步
- 写求解计划
- 建 求解/问题{1,2,3}/
- Step 2 求解 (3 个 .py)
- Step 3 论文 (5 节方案摘到 §2 + §5)
```

跑题后: 干跑问题 1 T_SHIELD=0.00s, 问题 2 T_SHIELD=2.40s, 问题 3 T_SHIELD=3.93s, 全部对得上.

## 严禁清单 (本工具专用)

- ❌ 让 LLM 编造数据/系数/结果/精度 (无依据的"准确率 95%"是 hallucination)
- ❌ 让 LLM 推荐历史具体模型 (2024C 的 CTM 不能直接搬到 2025A)
- ❌ 跨题连续性 4 维缺一 (共享数据/变量/约束/输入输出)
- ❌ 假创新 (拼 3 个老模型不算)
- ❌ 验证组合 < 2 维 (留出 + 物理 + 灵敏度 + 反事实, 最少 2 维)
- ❌ 跳翻译直接做方案 (06 跑完才能跑 07, 否则 2025C 3 P0 错位那种事故)
