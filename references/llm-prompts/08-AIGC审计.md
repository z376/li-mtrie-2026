## 使用流程 (4 步, 60-90 分钟)

```powershell
# 步骤 1: 必做前置 — 跑 aigc_scan.py 第 1 层自动扫描 (5 分钟)
py -3 references\scripts\aigc_scan.py --paper-dir 跑题目录\论文\ > 跑题目录\aigc_scan_输出.json
# 拿到 9 维度分数 (模板句式/被动语态/句子长度 CV/段落对称/嵌套编号/冒号并列/标点规律/口语化/破折号)

# 步骤 2: 提取论文全文 (1 分钟)
py -3 -c "import fitz; doc = fitz.open('跑题目录\论文\论文.pdf'); print('\n'.join(p.get_text() for p in doc))" > 跑题目录\论文_文本.txt

# 步骤 3: 复制下方 prompt, 粘贴论文_文本.txt + aigc_scan_输出.json + prompt, 喂 LLM (10 分钟)
# LLM: DeepSeek / ChatGPT / Claude / Qwen 任选

# 步骤 4: LLM 输出 → 填 references/审计报告模板.html (30 分钟手动整理)
# 用浏览器打开 HTML 模板, 把 LLM 输出的 9 维分数 + 6 类 PASS/FAIL + 问题清单 + 红色警告填入
# 导出 PDF 或截图发团队群
```

## Prompt (复制下面整段)

v2.2 的两层审计 + Nature-AIGC 检测方法). 请从下方完整论文文本 + 第 1 层 9 维度自动
扫描结果, 按 v1.5.9 方法论出**两层审计报告**.

要求:
1. **两层递进 (权重 60% + 40%)**:
   - **第 1 层: 语言模板化扫描 (60%)** — 9 维度:
     1 高频连接词 (Humanizer-zh)
     2 排比/同构句式识别
     3 拔高词与修饰词 (5 级分类)
     4 被动句占比与语态分析
     5 段落结构规律性
     6 文本复杂度 (熵值/n-gram/TTR)
     7 引文验证 (L1-L3 三层检查)
     8 数值一致性追踪 (参数溯源)
     9 术语一致性检测
   - **第 2 层: 数学建模逻辑审查 (40%)** — 6 类:
     1 模型常用性判断 (对标数模竞赛常用模型库)
     2 复杂度 vs 收益评估 (识别过度工程化)
     3 华而不实识别 (五大 AI 特征)
     4 模型选择 "三问法" (逻辑论证验证)
     5 建模路径风格 (人主导的渐进建模 vs AI 式复杂化)
     6 边界自洽 (灵敏度/扰动范围有依据)

2. **严格判分 + 一票否决 + 问题标红**:
   - 每维度 0-100 分, 加权求总分
   - **总分 ≥ 80 绿, 60-80 黄, < 60 红**
   - **一票否决**: 数据编造 (L1 维度 7/8 FAIL) / 模型选择无理由 (L2 维度 4 FAIL) → 总分强制红
   - **问题标红**: 列出前 5 个最严重问题, 标注页码 + quote 1-2 句

3. **输出分层 HTML 报告** (学生用 references/审计报告模板.html 渲染):
   - 标题 + 总分 + 风险等级 (绿/黄/红)
   - 第 1 层 9 维分数表 + 综合风险
   - 第 2 层 6 类 PASS/FAIL 表 + 证据
   - 前 5 个最严重问题清单 (页码 + quote + 改写建议)
   - 红色警告区 (一票否决项)
   - HTML 模板里的占位符 {{ }} 全部填掉

4. **不发明 + 不复制**:
   - 不编造论文原文 quote (1:1 复制 PDF 文本)
   - 不复制历史具体论文 (借鉴 16 题的"期望"而非"结论")
   - 数据点对不上 result.xlsx → 标 FAIL, 跟原表逐项对比

5. **BZD 警告清单 (4 类必扣)**:
   - ❌ 用 AI 重写 AI 文本 (PaperPure 100% 判 AI)
   - ❌ 口语化 (手感崩了/撑起来/说白了) 学术规范不允许
   - ❌ 网络用语 (绝绝子/离谱/破防) 必扣
   - ❌ 破折号碎句造"人味"反模式

输出格式:

## LLM AIGC 审计的常见问题 + 修法

| 问题 | 表现 | 修法 |
|------|------|------|
| **LLM 编造 quote** | "页码 X 说..." 但原文没有 | prompt 加"1:1 复制 PDF, 标页码必对照原 PDF" |
| **LLM 漏 9 维** | 只评 3-4 维 | prompt 加"9 维全评, 缺一 FAIL" |
| **LLM 漏 6 类** | 只评 L1 | prompt 加"6 类全 PASS/FAIL, 缺一 FAIL" |
| **LLM 宽松判分** | 全给 80+ | prompt 加"严格判分, < 60 红, 60-80 黄, ≥ 80 绿" |
| **LLM 不标一票否决** | 漏数据编造 | prompt 加"数据编造/模型无理由 = 一票否决, 必列具体数据点" |
| **LLM 不出 HTML** | 输出 markdown 表格 | prompt 加"按 references/审计报告模板.html 结构填, 占位符全填掉" |
| **LLM hallucinate 模型** | 推荐历史具体论文 | prompt 加"不复制历史, 只借鉴期望" |
