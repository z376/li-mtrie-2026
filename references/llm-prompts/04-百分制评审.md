# LLM 工具 04：百分制评审 (综合自评, 终审前必用)

> 学生自用, 给 Mavis / Claude / GPT 调用的**结构化 prompt 模板**. 把你的赛题 + 数据 + 论文摘要/章节/完整 PDF 喂给 LLM, 模仿 BZD 百分制评审方法打分 + 给位次估计 + 优先修改建议.
>
> **价值**: 终审前综合自评, **早 1 天发现位次风险**, 避免交卷后才知道国二 vs 省一.

**调用链 (粗筛 → 细评 → 终评)**:
- **粗筛**: 跑 `references/llm-prompts/01-选题推荐.md` 拿到候选模型 Top-3
- **细评 (本工具 §M1)**: 对 Top-3 每个候选做 11 维评估 + 4 档判定 → 选 1 个主模型
- **格式自查 (本工具 §M2)**: 写完论文, 12 章节 + 100+ 原子检查点 (15 分制)
- **终评 (本工具 §M3)**: 终审前, 100 分 + 90% 封顶 + 格式系数 + 位次估计

**3 模式 ↔ 3 方法论 references 双向链接 (避免重复劳动)**:
- **M1 字典预查** ↔ `references/模型字典使用指南.md` (11 维评估 + 4 档判定方法论)
- **M2 格式自查** ↔ `references/格式自查清单.md` (12 章节报告 + 100+ 原子检查点)
- **M3 百分制评审** ↔ `references/百分制评审方法.md` (100 分 + 90% 封顶 + 格式系数 + 位次估计)

**本文件只给 prompt 模板 + JSON OUTPUT_FORMAT**; **方法论 + 自查清单在 references/**. 用 M1/M2/M3 前先读对应 references 1 遍 (5 分钟), 跑 prompt 时直接复用方法论术语.

---

## 何时用

- 5 步流程最后 Step 4 编译后, **提交前 2-4 小时**
- 写完 §5 建模求解后, 想自评"能拿几分 / 大概什么位次"
- 选错模型, 想确认是否**适配性合适**

**不是**:
- 让 LLM 替你想论点 / 编数据 (AI 规定违规)
- 替代官方评委 (LLM 自评**只能参考**, 实际分数以官方为准)

---

## 使用方法

1. 准备: 赛题 (1-2 段) + 数据 (结构描述) + 论文 (.tex 全文或 PDF)
2. 选择模式:
   - **M1 字典预查** — 跑题前/Step 1 选模型时, 评估候选模型适配性
   - **M2 格式自查** — 写完论文, 检查 12 章节格式 + 100+ 原子检查点
   - **M3 百分制评审** — 终审前, 综合打分 + 位次估计
3. 复制下方"📋 Prompt 模板"段
4. 替换占位符 (`{...}`)
5. LLM 输出转成 todo list + 复盘

**预期时间**:
- M1: 5-10 分钟 / 1 个候选模型
- M2: 15-25 分钟 / 1 篇论文
- M3: 20-40 分钟 / 1 篇论文

# 赛题 (题目原文)
{QUESTION_TEXT}

# 论文 (完整 .tex 全文 或 PDF 路径 + 关键章节贴文)
{PAPER_TEX_OR_PATH}

# 选题背景
{SELECTION_CONTEXT} <高教社杯国赛 A/B/C/D/E, 年份, 组别>

# 评分方法 (借鉴 li-mtrie/references/百分制评审方法.md)
- 100 分: 摘要 10 + 格式 10 + 模型/求解/结果 70-75 + 补充质量 5-10
- 每问题三块: 模型建立 + 模型求解 + 结果与回答 (各题权重由题定)
- 90% 封顶: 每块从 0.90 × weight 起评
- 1/2/3 档扣分: 轻微 -1, 实质 -2, 核心 -3 (扣到 0 为止)
- 块根本答非所问/违反核心条件 → 直接判 0
- 不同但有效且充分的方案不扣分 (避免"标准答案"绑架)
- 格式质量系数: (format_score_10 + 10) / 20
- 最终得分 = 原始得分 × 格式系数
- 位次: CUMCM 用 2025 分数锚点, 其他竞赛用 10-90 均匀近似

## 模式选择建议

| 阶段 | 模式 | 用几次 | 何时停 |
|---|---|---|---|
| Step 1 求解计划 | M1 字典预查 | 每个候选模型 1 次 | 选出主模型 |
| Step 3 写完摘要 | M2 格式自查 §3 | 摘要 1 次 | 5 项全过 |
| Step 3 写完全文 | M2 完整格式自查 | 1 次 | 12 项全过 |
| Step 4 编译前 | M3 百分制评审 | 1 次 | 终版交卷 |
| 赛后复盘 | M3 百分制评审 | 1 次 | 学习改进 |

---

## 注意事项

1. **LLM 偏严**: 百分制评审 LLM 普遍打 60-75 (实际可能 70-85), 别被吓到. **3.5 分以上就算合格** (工具 03 同款铁律)
2. **不要 100% 依赖**: LLM 不懂数学细节, **核心创新/灵敏度/可复现性** 必须人工核
3. **AIGC 风险**: 这套 prompt 输出带"评委口吻"会被 AIGC 检测, **必须改写 + 加个人风格**才能塞进 AI 工具使用详情
4. **隐私**: 喂给 LLM 前**检查**论文不含学校/姓名/指导教师 (国赛匿名)
5. **格式自查偏严格**: LLM 不懂国赛规则, **国赛特有的"无目录""无附录代码"等可能误报**, 走 `references/格式自查清单.md` 核
