# 05-读题提取 (v1.5.7)

**用途**: 从赛题 PDF 自动提取 15 项读题清单内容, 跑题前 30 分钟必跑。
**借鉴**: 2025C 跑题 3 P0 错全部源自"没读完题就跑题", LLM 自动提取防漏。
**使用**: 复制下方 prompt, 粘贴赛题 PDF 内容, 拿 LLM 输出填 `求解/读题清单.md`。

---

## 使用流程 (3 步, 30 分钟)

```powershell
# 步骤 1: 提取赛题 PDF 文本 (1 分钟)
py -3 -c "import fitz; doc = fitz.open('题目/C题.pdf'); print('\n'.join(p.get_text() for p in doc))" > 题目_文本.txt
# 完整版: 题目/C题.pdf → 题目_文本.txt

# 步骤 2: 复制下方 prompt, 粘贴 题目_文本.txt 内容 + prompt, 喂 LLM (5 分钟)
# LLM: DeepSeek / ChatGPT / Claude / Qwen 任选

# 步骤 3: LLM 输出 → 填 求解/读题清单.md (15 分钟手动 copy)
# 然后 dryrun check 19 验 15 项全覆盖
```

---

## Prompt (复制下面整段)

```
你是一名熟悉数学建模国赛规范的助手。请从下方完整赛题文本中, 严格按照 15 项
清单提取题面关键信息。

要求:
1. 必须逐项回答, 不能省略任何一项
2. 每项提取**题面原话** (quote 1-2 句) + 你的解读 (1 句)
3. 数值保留原始单位, 不擅自转换 (如 "4%" 不要改成 "0.04")
4. 分组标准保留题面给的边界, 不简化 (如 "[20,28)" 不能简化成 "20-28")
5. 异常判据保留 |Z|>3 这种题面格式
6. 隐藏约束: 题面没说但跑题必须推断的 (如缺失值处理, 异常样本分布不均等)
7. 输出 markdown 表格, 15 行 + 标题

输出格式:

## 15 项读题清单

### 1. 题组 + 题号
- 题面原话: "..."
- 你的解读: ...
- 对应代码/论文: ...

### 2. 总问题数
- 题面原话: "..."
- 你的解读: ...
- 对应代码/论文: ...

... (依此类推到 15)

### 15. 隐藏约束
- 题面原话: "(题面未明说, 需推断: ...)"
- 你的解读: ... (列 1: 缺失值处理; 列 2: 异常样本分布; 列 3: ...)
- 对应代码/论文: ...

---

赛题原文:
<赛题 PDF 文本>
[在此粘贴 PyMuPDF 提取的题目_文本.txt 内容]
</赛题 PDF 文本>
```

## 验证 (跑题前必做)

```powershell
# 检查清单 15 项全覆盖
py -3 -c "
from pathlib import Path
content = Path('求解/读题清单.md').read_text(encoding='utf-8')
items = [f'### {i}.' for i in range(1, 16)]
missing = [it for it in items if it not in content]
print(f'缺失项: {missing if missing else \"无\"}')

# 检查每项都有 3 列内容 (题面原话 + 你的解读 + 对应)
quot = content.count('题面原话')
interp = content.count('你的解读')
code = content.count('对应代码')
print(f'题面原话: {quot} 次 (应 ≥ 15)')
print(f'你的解读: {interp} 次 (应 ≥ 15)')
print(f'对应代码: {code} 次 (应 ≥ 15)')
"

# dryrun check 19 验
py -3 references\scripts\dryrun.py 2>&1 | Select-String '19\.' | Select-Object
# 预期: 🟢 GREEN
```

## LLM 提取的常见问题 + 修法

| 问题 | 表现 | 修法 |
|------|------|------|
| **LLM 跳过项目** | 12 项全覆盖, 缺 3 项 | 重跑, prompt 加 "必须逐项回答, 不能省略" |
| **LLM 转换单位** | 写 "0.04" 而非 "4%" | prompt 加 "数值保留原始单位" |
| **LLM 简化分组** | 写 "20-28" 而非 "[20,28)" | prompt 加 "分组标准保留边界" |
| **LLM 改判据** | 写 "Z 分数 > 3" 而非 "\|Z\|>3" | prompt 加 "异常判据保留题面格式" |
| **LLM 漏隐藏约束** | 15 项都填但全是字面 | 提示: "题面没说的, 但需推断" |
| **LLM hallucinate** | 编造题面原文 | 跟原 PDF 逐项对比, 改错的 |

## v1.5.7 真实案例 (2025C 跑题)

输入: PyMuPDF 提取 2025 C题 NIPT 题面 (含男胎/女胎/Y 浓度 4%/[20,28) BMI 5 组)

LLM 输出 (15 项全覆盖示例):

```
### 1. 题组 + 题号
- 题面原话: "全国大学生数学建模竞赛 本科组 C 题"
- 你的解读: 本科 C 题 (不是 D/E)
- 对应代码/论文: 论文标题

### 2. 总问题数
- 题面原话: "请回答以下 4 个问题"
- 你的解读: 4 问
- 对应代码/论文: 5.1.1-5.1.4

### 3. 数据附件结构
- 题面原话: "附件.xlsx 含 Sheet1 男胎 1082 例, Sheet2 女胎 605 例"
- 你的解读: Sheet1=男胎 1082, Sheet2=女胎 605
- 对应代码/论文: pd.read_excel

### 4. 每问用哪个 sheet
- 题面原话: "问题 1-3 用男胎数据, 问题 4 用女胎数据"
- 你的解读: 问题 1-3 sheet_name=0, 问题 4 sheet_name=1
- 对应代码/论文: 各问题 .py

... (5-15 类似)

### 15. 隐藏约束
- 题面原话: "(题面未明说, 需推断)"
- 你的解读: 列 1: 异常值剔除 3σ; 列 2: BMI 缺失填中位数; 列 3: 异常 11% 用 class_weight=balanced
- 对应代码/论文: 5.1.1 数据预处理
```

跑题后: dryrun check 19 立即抓到问题 4 sheet 错 (LLM 已说"问题 4 sheet_name=1", 实际跑时用 0) → 立刻修。
