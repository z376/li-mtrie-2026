# LLM 工具 01：选题推荐

> 学生自用，给 Mavis / Claude / GPT 调用的**结构化 prompt 模板**。把题面 + 数据喂给 LLM，让它给你推荐问题类型 + 候选模型 Top-3 + 数据洞察。

---

## 何时用

- 读完题但**不确定问题类型**（优化/评价/预测/分类/机理）
- 想**对比 3-4 个候选模型**但手头没时间列 9 列表格
- 想**快速判断数据能不能用**（缺失率/分布/异常值）

不替代手动 `references/模型决策树.md`，而是用 LLM 加速你的初判。

---

## 使用方法

1. 打开 Mavis / Claude / GPT 会话
2. 复制下方"📋 Prompt 模板"段
3. 替换 `{PROBLEM}` `{DATA_SUMMARY}` `{CONSTRAINTS}` `{OUTPUT_FORMAT}` 4 个占位符
4. 把 LLM 输出贴回 `求解/求解计划.md` 作为初稿

**预期时间**：5 分钟（含 1 轮 LLM 调用 + 1 轮手动修订）

---

## 📋 Prompt 模板

```
你是数学建模国赛助手。下面给你题目和附件数据。请按 OUTPUT_FORMAT 严格输出。

# 题目（国赛 20XX 年 A/B/C/D/E 题，题组 X，X 道问题）
{PROBLEM}

# 数据概览
- 附件 1：{文件名}，{shape}，{列名}，{缺失率}
- 附件 2：{文件名}，{shape}，{列名}，{缺失率}
- （按需追加）

# 约束
- 96 小时限制
- 单机 16GB 内存
- 优先选有 scikit-learn / scipy / numpy 现成包的方案
- {额外约束}

# OUTPUT_FORMAT（严格 JSON，不要解释）

{
  "problem_summary": "一句话概括全篇（研究对象 + 核心矛盾 + 最终目标）",
  "problem_type": [
    {"q": "问题 1", "type": "优化/评价/预测/分类/机理/混合", "confidence": 0.0-1.0, "reason": "为什么"}
  ],
  "model_candidates": [
    {
      "rank": 1,
      "name": "算法/模型名",
      "essence": "数学本质（一句话）",
      "why_fit": "为什么匹配这道题",
      "data_needs": "需要什么数据/假设",
      "failure_risk": "最可能失败的方式",
      "compute_cost": "O(n log n) / O(n^2) / O(n^3) ..."
    }
  ],
  "data_insights": [
    "数据列 X 的分布异常（具体）",
    "数据列 Y 与 Z 强相关（r=0.92），可降维"
  ],
  "recommended_4x_analysis": {
    "q1_overview": "任务/已知/输出/本质",
    "q1_approach": "从数据到结果的完整逻辑",
    "q1_model_choice": "推荐 + 理由 + 备选",
    "q1_innovation": "可创新方向（不是简单换算法）"
  }
}

# 严禁
- 不要编造不存在的方法/包
- 不要给没在你的 model_candidates 里写过的备选
- 不要给不在你推荐范围内的"也许更好"的方案
```
