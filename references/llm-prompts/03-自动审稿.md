# LLM 工具 03：自动审稿（终审前自审）

> 学生自用，给 Mavis / Claude / GPT 调用的**结构化 prompt 模板**。把你的论文 PDF / .tex 喂给 LLM，模仿 5 类审稿人维度打 5 档分 + 给改进建议。
>
> **价值**：终审前提前自审，省去 1-2 轮改稿时间。

---

## 何时用

- 5 步流程最后 Step 4 编译前
- 写完 1 个 .tex 后想自评质量
- 自评分数 ≤ 3 时，参考改进建议再改稿

**不是**：让 LLM 替你想论点 / 编数据 / 调格式（那是 AI 规定违规）。

---

## 使用方法

1. 写完至少 1 章（如 §5 模型建立与求解）
2. 复制下方"📋 Prompt 模板"段
3. 替换 `{CHAPTER_TEX}` 占位符（1-3 章一起喂也行）
4. 把 LLM 输出转成 todo list
5. **注意**：LLM 评分偏严，**3.5 分以上就算合格**

**预期时间**：10-20 分钟 / 1 章

---

## 📋 Prompt 模板

```
你是数模国赛匿名审稿人。下面给你论文 1 个章节（或多章）。请按 5 个维度 5 档打分，并给具体改进建议。

# 章节
```
{CHAPTER_TEX}
```

# 整体背景（让 LLM 知道上下文，可选）
- 国赛 20XX 年 {A/B/C/D/E} 题
- 章节编号: §{N}
- 我们用 {DE / GA / XGBoost} 等模型
```

## 5 维评分细则（给 LLM 看）

| 维度 | 5 分标准 | 3 分标准 | 1 分标准 |
|------|---------|---------|---------|
| **mechanism** | 数学结构清晰，假设有依据，公式正确 | 结构对但有 1-2 处推导跳步 | 公式错或假设矛盾 |
| **data_validation** | 有误差+灵敏度+稳健性 3 类检验 | 只有 1-2 类 | 无检验或数字不一致 |
| **writing** | 自然、具体、补数字补理由 | 模板化但能读 | 满篇"研究表明""具有重要意义" |
| **innovation** | ≥1 个具体改动 + 验证 + 对照 | "模型融合""加可视化" | 简单换算法 |
| **format** | 0 Error / 0 Overfull / 图表对齐 | 1-2 处小毛病 | 公式截图 / 红绿对比 |

## 反例 / 警示

**LLM 评分偏严**——3.5 分以上算合格。1-2 分也常见，不代表论文差，代表"还有改进空间"。

**别让 LLM 替你写**。LLM 给的"fix"是方向，不是终稿。改 1 段回到 §2.AIGC 降重流程再让 LLM 自审 1 次。

---

## 自检

跑完 1 轮 LLM 自动审稿后，对照以下 5 条：

- [ ] 5 维评分都有具体 issue + fix（不是空泛"加强 X"）
- [ ] must_fix 项 ≤ 3 条（多了说明 LLM 没真审）
- [ ] issue 是**具体现象**（如"式 3 缺推导"）不是**泛化批评**（如"写作一般"）
- [ ] fix 是**具体操作**（如"加 1 句过渡"）不是**方向**（如"优化表述"）
- [ ] example_phrases_to_replace 至少 1 条（说明 LLM 真在审 AI 痕迹）

---

## 批量用法

96 小时建议跑 3 次：
- **T+24h**（§5 写完）—— 第 1 轮自审，定位结构问题
- **T+72h**（§6-7 写完）—— 第 2 轮自审，定位数据/写作问题
- **T+90h**（终稿前 6 小时）—— 第 3 轮自审，最终清单

每轮 focus 不同维度：
- 第 1 轮：mechanism + innovation
- 第 2 轮：data_validation + writing
- 第 3 轮：writing + format
