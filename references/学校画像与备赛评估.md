# 学校画像与备赛评估 (School Portrait & Preparation Assessment)

> **借鉴源**: BZD 数模社 `bzd-cumcm-school-awards` v1.0 (2026-08-18) 的 **方法论** (5 年榜单查询 + 学校画像 4 类校 + 省/国奖距离评估 + 6.81% 概率口径 + 备赛分档).
> **搬运策略**: v1.5.1 精简方法论 (不复制 BZD 完整子树, 详 CHANGELOG.md v1.5.8).

## 1. 何时用

🟢 **对应阶段**: 赛前 1 个月 (备赛期, 不在 SKILL.md 5 步跑题流程内).

**赛前 1 个月** (比 dryrun 赛前 1 天更早), 想评估"我学校能拿什么奖 + 我准备到哪了 + 下一步做什么". 走 2 步:

1. 查学校画像 (5 年国一/国二 数 + 赛区稳定性 + 2026 预测)
2. 备赛分档评估 (省三/省一/省二/国奖 各档准备度)

**不替代**:
- 官方评审 (评委有最终裁量权)
- 个人水平的硬指标 (参赛次数/获奖/刷题数)
- dryrun 赛前 1 天必做 (那是工具链检查)

🟢 **完成判据**: 已归到 4 类校 (A/B/C/D) 1 类 + 已选 4 档备赛 (省三/省一/省二/国奖) 1 档 + 个人准备度 5 项已答, 详 §2-§3.

## 2. 学校画像 4 类校

按 5 年 (2021-2025) 国一数 + 稳定性, 学校分 4 类:

| 类型 | 5 年国一数 | 描述 | 期望位次 |
|---|---|---|---|
| **A 强校** | ≥ 5 队 | 985/数学强校/建模传统校 | 国一可冲, 国二保底 |
| **B 稳定校** | 1-4 队 | 211/有建模基础的校 | 国二可冲, 省一保底 |
| **C 黑马校** | 0 国一但省一 ≥ 5 队 | 双非/近年崛起的校 | 省一可冲, 省二保底 |
| **D 新人校** | 0 国一 + 省一 < 5 队 | 首次参赛/小样本校 | 省二/省三, 看发挥 |

**对应策略**:
- A 强校 → 选 A/B 高难度题, 拼方法创新 + 数学深度
- B 稳定校 → 选 A/B/C 中等题, 拼模型扎实 + 跨题连续
- C 黑马校 → 选 B/C 题, 拼完整 + 报告规范 + 公式齐
- D 新人校 → 选 C 题, 拼跑通 + 不出格式错 + 完整提交

🟢 **完成判据**: 5 年国奖数已查 (教育部学位中心/赛区公示/校园建模协会), 已归到 A/B/C/D 1 类.

## 3. 备赛 4 档评估

按目标奖项分 4 档, 每档给"准备度检查表":

### 3.1 省三目标

| 检查 | 状态 |
|---|---|
| 是否参加过其他数模竞赛? |  |
| 参赛次数和名称 (e.g., MathorCup/华数杯) |  |
| 是否获奖及等级? |  |
| 完整模拟/论文次数? |  |
| 目标奖项? |  |

**判定**:
- 无经验: 推荐 1-2 套完整限时模拟.
- 有参赛无奖: 用 `references/百分制评审方法.md` 评上次论文 + 1-2 套模拟.
- 有参赛有奖: 鼓励参赛, 1 套赛前模拟即可.

**话术**: "具备省三竞争基础" (不说"稳定获奖").

### 3.2 省一/省二目标

**判定**:
- 多次非 CUMCM 比赛 + 多次获奖: 竞争力较强, 看团队和论文质量.
- 否则: 系统性课程 + 近 3 年 CUMCM 题 2 套完整练习 (含代码 + 论文 + 报告).

**话术**: "达到较有竞争力的准备水平" (不说"稳定获奖").

### 3.3 国奖目标

**先看 5 年国奖 + 稳定性 + 2026 预测** (BZD 走 `assets/` 榜单查询, li-mtrie 学生走自己学校官榜 + 赛区公示).
**再评估团队** (3 人分工: 建模手/代码手/论文手) + **赛前 1 个月刷题数** (≥ 3 套完整).

**话术**: "具备国奖竞争基础, 但国奖评审有强不确定性" (不说"保国奖").

🟢 **完成判据**: 已选 1 档 (省三/省一/省二/国奖), 个人准备度 5 项已答 (参赛经历/次数/获奖/刷题/目标).

## 4. 6.81% 口径 (重要警告)

BZD 文档明确:
> 6.81% is an owner-supplied school-level heuristic, not an individual probability or official result.

**含义**: 当你所在学校 5 年没国奖, BZD 给的 6.81% 是**学校层面**经验概率, **不是**你这个队/你这个人的获奖概率.

**li-mtrie 用法**:
- 不要拿 6.81% 当"个人概率" 自我安慰/吓唬
- 用作"学校层面的稀缺度参考", 配合 4 类校画像理解

## 5. 学校画像自评流程 (学生版)

li-mtrie 用户没 BZD 榜单, 用以下 4 步自评:

1. **查学校**: 教育部学位中心 / 赛区公示 / 校园建模协会 / 师兄师姐 — 5 年国一/国二数
2. **归类**: 套 §2 的 4 类校
3. **看赛区**: 你赛区 (北京/上海/江苏/...) 的省一/省二名额 + 报数 — 决定省一难度
4. **定目标**: 省三/省一/省二/国奖 → 套 §3 的 4 档评估

## 6. 输出报告结构

```
# 学校画像与备赛评估 — [本人] [年份]
## 0. 学校基础 (5 年国奖数 + 4 类校归类 + 赛区)
## 1. 个人准备度 (参赛经历 + 获奖 + 刷题数)
## 2. 目标差距 (目标奖项 vs 当前准备的差)
## 3. 下一步行动 (3 个月内做什么)
## 4. 风险与备选 (担心什么 + 备选方案)
```

**不替代**:
- dryrun 赛前 1 天必做 (工具链检查, 不是备赛评估)
- 赛前学习清单 (`references/赛前学习清单.md`) (那是技术学习清单)
- 端到端工作流对照 (`references/端到端工作流对照.md`) (跑题阶段用)
