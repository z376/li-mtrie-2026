## A 类：环境/前置环节（5 个）

> 这 5 个是**流程图里压根没提到**的事前环节，user 第一次跑就可能直接卡在装包阶段。

### A1: 没指定 Python 解释器来源，pip 装错解释器的库
- **现象**：user 在 Windows 上有"微软商店版 Python"（路径含空格、不能 pip 升级）+ Anaconda Python + 系统 Python + VS Code 选择的 Python 共存。跑 `pip install pulp` 后在 Jupyter 里 `import pulp` 仍然 `ModuleNotFoundError`，因为 Jupyter 用的是另一个解释器。
- **位置**：SKILL.md 「必装依赖」一节（line 35-46）。
- **影响**：装了半天包跑不动代码；进一步怀疑 skill 是不是有问题；浪费时间排错。
- **修复**：在「必装依赖」前加一节「Python 环境就位」明确 3 件事：① 推荐 Python 3.10-3.12；② `python -c "import sys; print(sys.executable)"` 先确认是哪个解释器；③ 装包后用同一个解释器跑验证 `python -c "import pulp; print(pulp.__version__)"`。

### A2: 没要求用虚拟环境，96 小时跑题包污染 / 版本冲突
- **现象**：赛前一周装的是 `pandas 2.0`，赛题发下来想用 `pandas 2.2` 的新 feature，全局升级会破坏以前的脚本；或者两支队伍在同一个项目目录下抢包。
- **位置**：SKILL.md 完全没有 venv / conda env 的任何字样。
- **影响**：赛前准备的算法模板（60 天备赛清单 §四）跑不动；新题装新包把旧题搞崩。
- **修复**：SKILL.md 顶部加一节「环境隔离（强烈建议）」，给出 PowerShell 2 行命令：`python -m venv .venv` + `.\.venv\Scripts\Activate.ps1`，并把所有 `pip install` 改为「先激活 venv 再装」。

### A3: 没预估磁盘空间和清理时机
- **现象**：96 小时跑完，发现 `论文/` 下有 50+ 个 `.aux` `.log` `.synctex.gz` 临时文件（每次 xelatex 编译生成 6-10 个）；`求解/` 下每个问题 5-10 张 PNG + 几个 xlsx 中间文件；3 次重打包后 `支撑材料.rar` 副本堆了 100MB；C 盘红了。
- **位置**：SKILL.md 全文无磁盘空间/清理提示。
- **影响**：提交前才发现 C 盘不够，无法再编译 / 打包；慌忙删东西把源码也删了。
- **修复**：Step 4.1 编译前加一行「清理 .aux/.log」（给 PowerShell 脚本 `Remove-Item 论文/*.aux, 论文/*.log, 论文/*.synctex.gz -ErrorAction SilentlyContinue`）；Step 4.4 打包前加「保留 1 份最终 .rar」提醒；附录「赛前 1 天自检」加一条「预留 ≥ 5 GB 工作空间」。

### A4: PDF/DOCX 题面读不到时没给回退方案
- **现象**：测试报告 §1 提到「`fitz` API 弃用，建议改 `import pymupdf`」；实际比赛更常见的是 ① 扫描件 PDF（PyMuPDF 读出来是图片）② 加密 PDF ③ 老 .doc 不是 .docx。
- **位置**：SKILL.md Step 0 只说「读 `题目/` 下所有 PDF/DOCX，提取问题描述」。
- **影响**：扫描件 PDF 读出来是空文本，要 OCR（额外装 tesseract）；加密 PDF 报密码错，不知道该不该重置；老 .doc 报格式不兼容。流程直接断。
- **修复**：Step 0 加「读题失败回退表」：① 扫描件 → 提示「需 OCR，请 `pip install pytesseract` + 安装 tesseract-ocr」；② 加密/损坏 → 提示「先打开看，确认能否解密」；③ `.doc` → 提示「手动转 .docx 再放回」。

### A5: 没考虑封闭网络环境，离线怎么装依赖
