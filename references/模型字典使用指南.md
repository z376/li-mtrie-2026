# 模型字典使用指南 (Model Dictionary)

> **借鉴源**: BZD 数模社 `bzd-model-dictionary` v1.0 (2026-08-18) 的 **方法论**(11 维评估 + 4 档判定 + 6 类指标 routing).
> 本文档**不复制** 5713 条具体模型记录(那是 BZD 团队持续维护的版权资源),只搬运**评估框架**供 li-mtrie 自用.

**LLM 工具版本** (本方法论 + 结构化 prompt): `references/llm-prompts/04-百分制评审.md §M1 字典预查` — 11 维 + 4 档 + 6 类指标 routing 全部进 JSON OUTPUT_FORMAT, 学生 copy-paste 自用.

## 1. 何时用

跑题进入 **Step 1 求解计划 / 候选模型比选** 时,对每个候选模型问:

> "这个模型适合这道题的数据和目标吗?"

不是查"哪个模型流行",而是**逐项检查适配性**并给出明确判定.

## 2. 11 维评估表

对**每个候选模型**逐项评估. 每维独立,不合并不平均.

| # | 维度 | 关键问题 |
|---|---|---|
| 1 | **任务对齐** | 模型解决的是不是题目实际任务: 描述/推断/预测/分类/排序/优化/仿真/控制/解释? |
| 2 | **观测单元** | 建模单元是否与数据一致? 重复观测(同人/同地/同设备/同时间)是否独立? |
| 3 | **目标与输出** | 模型输出是否就是题目要求的量(可含不确定性/可行决策/操作阈值)? |
| 4 | **数据充分性** | 样本量/事件数/特征数/类别平衡/覆盖范围/测量分辨率够不够? |
| 5 | **假设合理性** | 分布/独立性/平稳性/线性/比例风险/凸性/光滑性 等要求是否站得住脚且可检验? |
| 6 | **泄露与因果** | 是否误用未来信息/重复主体/目标导出的变量/结果后的特征? 因果声明是否超出设计允许? |
| 7 | **约束与机理** | 公式是否保留单位/守恒律/几何/容量/时序/整数性 等硬约束? |
| 8 | **可验证性** | 结果能否用残差/留出/分组/滚动验证 + 稳定性/收敛性/灵敏度/基线/仿真 来检验? |
| 9 | **可解释性** | 对竞赛题和领域来说, 解释是否充分(评委能不能复述你的"为什么")? |
| 10 | **计算可行性** | 在有限时间内能否可复现地求解? 收敛与随机性是否可控? |
| 11 | **论文完整性** | 团队能否在论文里讲清假设/公式/求解/参数选取/结果/检验/局限/复现? |

**判定铁律**: 不要机械平均 — 单个致命不匹配可决定整体判定. 避免"从相关性声称因果"、"从样本内拟合声称泛化"、"从启发式结果声称最优(无上界/对照)".

## 3. 4 档适配性结论

| 结论 | 含义 | 后续动作 |
|---|---|---|
| **合适** | 任务/输出对齐, 核心假设有数据支持, 数据充分, 验证可行, 无重大结构性缺陷 | 直接采用, 走 Step 2 求解 |
| **有条件合适** | 模型方向对, 但需要**特定预处理 / 依赖处理 / 约束补充 / 阈值设计 / 验证方法 / 与其他模型组合** 才能用 | 列条件清单, 满足后再走求解 |
| **不合适** | 解的不是同一类任务, 违反核心数据结构或硬约束, 或合理调整后仍不能产生所需结果 | **换模型**, 跳到 §5 替代模型 |
| **证据不足, 待人工复核** | 关键数据事实或模型身份不明 | 暂停, 列缺失证据清单, 回去读题读数据 |

## 4. 6 类问题的指标 routing

每个题目类型选对应指标, 不要套用错位指标.

| 题型 | 必查指标 | 备注 |
|---|---|---|
| **分类** | Accuracy (附**类别平衡**上下文) + Precision/Recall/F1 + ROC-AUC + PR-AUC + 混淆矩阵 + 校准 + 分组感知验证 | Accuracy 在不平衡时**几乎无用**, 必须看 F1 和 PR-AUC |
| **回归** | R² + RMSE + MAE + MAPE (分母有效时) + 残差诊断 + 分组/留出验证 | 警惕 R² 在非线性/异方差下虚高 |
| **时间序列** | 平稳性 + 残差白噪声 + 滚动起点验证 + horizon-specific error + 结构断点检验 | 样本外必须用**滚动预测**而非随机切分 |
| **聚类** | silhouette + DBI + CH + 稳定性 + 可解释性 + 簇是否形成**可用区间/分段** | 数字漂亮不代表业务可解释 |
| **优化** | 约束可行性 + 目标重算 + 收敛性 + 运行时 + **多次运行** + 基线 + 最优性 gap / 已知最优对照 | ILP/启发式必须报告**目标下界**或与已知最优的差 |
| **评价/排序** | 权重灵敏度 + 排序稳定性 + 指标一致性 + 指标冗余度 | 熵权法/TOPSIS 等必须有灵敏度分析, 单点结果不可信 |
| **机理/数值仿真** | 稳定性 + 误差阶 + 收敛性 + 守恒律/不变量 + 实测 vs 仿真对比 | 物理常数/单位必须 SI 制一致 |

## 5. 替代 / 配套模型清单

判定**不合适**或**有条件合适**时, 列 2-4 个替代或配套模型.

**配套** (complement, 跑在同一数据上):
- 主模型 X + 灵敏度分析 Y (e.g., 主优化 + 蒙特卡洛扰动)
- 主回归 + 残差诊断 + 异方差检验

**替代** (replace, 换思路):
- LP → ILP / 启发式 (整数性重要时)
- 多元回归 → 树模型 / 神经网络 (非线性强时)
- 时间序列 → 状态空间 / 贝叶斯 (不确定性重要时)

**预处理** (preprocess, 喂给主模型):
- 标准化 / 归一化 / 类别编码
- 缺失值填补 (均值/中位数/KNN/多重插补)
- 异常值处理 (3σ / IQR / 领域知识)
- 类别不平衡 (SMOTE / 类别权重 / focal loss)

每列一个替代/配套模型, 简短说明它**解决 §2 哪一维**, 走流程 §3 重新判定.

## 6. 落地清单 (给论文用)

走完 §2-§5 后, 把以下写进论文 §5 建模求解 + §6 模型检验:

1. **预处理** — §2 第 4/5/6 维触发的所有数据/特征工程
2. **训练/估计设计** — 留出/分组/滚动验证的具体切分方式
3. **参数/约束选择** — 主要超参的取值范围和选择依据(不要直接"调参调出 0.92")
4. **验证指标** — §4 routing 里**至少 3 个**指标, 全部有数值
5. **灵敏度分析** — 关键参数 ±10% / ±20% 的指标变化表或图
6. **论文必报** — 假设清单 / 公式 / 求解器版本 / 运行时间 / 复现命令

## 7. 一页自检 (赛前/赛中都可用)

针对当前候选模型, 把答案写出来:

```
模型名:                ____________________
1. 任务类型:           □分类 □回归 □时序 □聚类 □优化 □评价 □机理 □其他
2. 题目实际任务:       ____________________ (引自题目原话)
3. 模型输出:           ____________________
4. 数据 N / 维度 p:    _____ / _____ (够不够? p/N > 0.1 危险)
5. 核心假设:           ____________________ (可检验吗?)
6. 致命不匹配:         □无 □有 (____)
7. 验证方案:           ____________________ (留出/分组/滚动?)
8. 替代/配套模型:      ____________________
9. 适配性结论:         □合适 □有条件合适 □不合适 □证据不足
10. 落地条件 (有条件合适时): ____________________
```

第 6 行打 "有" 时, 整个评估**不算通过**, 必须换或加约束.
