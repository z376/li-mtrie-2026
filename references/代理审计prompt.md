## 2. 审计 checklist (按板块)

### A 板块: 模型层 (重点 P0)

**A1 边界/初值离散式逐项对拍题面** (P0-1 防御):
- 读 `求解/问题N/solve_*.py` 提**所有**边界条件 / 初始条件行
- 与题面 PDF 原文逐项对照 (`读题清单.md §3-4 题面 quote`)
- 重点抓: 边界条件类型 (Robin/Dirichlet/Neumann) 与题面是否一致
- 重点抓: 半控制体 FVM Robin 离散式 γ=2·h·Δt/Δr 是否含 Δt (无 Δt = h→∞ 极限, 表面钉死)
- **决定性证据**: 跑 dE/dt ÷ [h(T∞−Ts)·A] 守恒校验, |比值−1| 应 < 0.05
  - **用工具跑, 别手推**: `py -3 <brief『审计目标』段的 skill 根目录>/references/scripts/bc_check.py --project .` (v1.6.3 新增; v1.7.2 补: brief 现在直接给出该绝对路径, 不要再猜 `<SKILL_ROOT>`)
  - 求解时没埋点 (无 `求解/问题N/结果/守恒记录.csv`) → **直接判 FAIL**, 报告里写"未提供守恒记录, 无法排除 P0-1 型离散式错误"
  - P0-1 签名: 比值 ≈ **223** (表面被钉死成 h→∞ 极限); 正确实现 ≈ **0.995**

**A2 能量守恒 + 独立换实现重算** (P0-1 防御):
- 写自写求解器 (scipy banded 或另一套 FVM) 复现关键值
- 跟作者实现对比同一参数/同一网格/同一时间步的特征量 (峰值/平衡/半干燥时间)
- 相对误差 < 1% 绿 / 1-5% 黄 / > 5% 红
- **不信任自己的代码**, 自己的"自洽"可能是错的
- **复算过程必须落盘**: 写进 `求解/审计报告*.md` 的 A 板块结论 (验收标准第 2 条要求"有独立换实现的复算记录"),
  光有结论没有过程 = 不算复算

**A3 数据清洗** (P0-2 防御):
- 扫求解脚本找 iqr/boxplot/quantile + 紧邻 drop
- 趋势段 (升温/收缩/衰减) 禁用全局 IQR
- 改 4 类允许: 物理越界 / 一阶差分 z>5 / 单调性含容差 / 时间间隔+重复

**A4 关键判据二次复算** (P0-3 防御):
- 论文所有非题面数字 (Bi/Fo/收缩率/Re/Pr 等关键判据) 必来自 3 类可信来源之一
- 找一次心算反例 (e.g. Bi_m=32 实 3.24 差 10 倍)
- 凭图读数 / AI 写数字 必报 red

**A5 resultX 结构 vs 附件3 模板** (P0-4 防御):
- 用 openpyxl 比对 resultX 列名/dtype/sheet 名
- A 列必须按模板写 (e.g. `时间\到药材中心的距离`, 不能简写 `时间`)
- result4 末列 = "药材表面"
- 论文表步长 ≠ result 完整序列步长

**A6 全部离散式逐符号对拍** (终审复验轮, 延伸 P0-1 —— 从"表面行"扩到**全部**离散式):
- 论文里**每一个**离散方程 (中心 / 内部 / 表面) 都要与代码**逐符号**核对, 不只表面行
- 4 个必核项: **差分配对** (前向差分 ↔ 前向平均, 后向差分 ↔ 后向平均, 写反 = 常物性下无差别、变物性下显著错) · **几何加权** ($r_{i\pm1/2}$ vs 代码 `rp=(i+1)*dr` / `rm=i*dr`, 权重不同) · **中心因子** (径向离散中心因子 = 4, 笛 = 2) · **系数名** (论文符号 vs 代码变量名逐字)
- 终审反例: 论文 `eq:discrete` 把前向差分 $(U_{i+1}-U_i)$ 配了后向平均 $\tfrac12(D_i+D_{i-1})$, 而 `solver_core.py:68-79` 配对是**对的** → 论文错
- 若论文公式与代码确有差异 (如几何加权), 要么改代码, 要么在正文**注明加权方式**, 不许"论文一套、代码一套"

**A7 叙述性前提核查** (终审复验轮, 延伸 P1-4 —— **终审 GREEN 也会漏的盲区**):
- 凡陈述"某方案为何必要 / 某困难为何存在"的句子, 核对其**前提在当前方案下是否仍成立**
- 扫描词: 难点 / 动机 / 创新点 / 假设的理由 / 为什么这么处理 / 若按…直接… / 由于…
- 终审反例: 水分已从 Dirichlet 改回 Robin, 但 `2.总体分析` 难点1 仍写 "若按 Robin 直接离散, 第一步即产生负浓度…" —— 该前提**已被推翻**, 整句要重写; 同类: 难点2 的"边界层不可分辨"整条前提随 Bi_m≈3.2 失效
- 交叉自查: **审计 PASS ≠ 该板块无遗漏**; 叙事类结论必须人工再过一遍

### K 板块 (v1.8.0 新增, 格式轮 F-P1-1/F-P1-2): 表格

**K1 宽度量测**:
- 用 PyMuPDF 逐页量**横线跨度**, 全部表格应恒等于版心宽 (容差 < 2 pt)
- 满宽写法 = `\begin{tabularx}{\textwidth}{...}`; **tabularx 的剩余空间在所有 X 列间均分**, 不是"最后一个 X 补满"

**K2 同风格 + 一个元素一格**:
- 风格二选一 —— 三线 (booktabs) 或网格 (竖线 + 逐行 `\hline` + `\arrayrulewidth 0.5pt`), **同一篇不混风格** (除非用户指定个别表)
- 组表头/空角格**各自成格**: `\multicolumn` 只跨数值列, **数据格严禁合并** (题面组表头如 "到药材中心的距离/cm" 是**一个独立标签格**)

**K3 高表与 vbox**:
- 规格模板: 数值列表 = 行表头 + n 数据列 (`{l|C…C}` 等宽); 文本表 = **一表只放一个弹性列 `L`**, 其余用 `c`/`l`/`p{0.x\textwidth}`
- `[H]` 高表 (>20 行): 固定列宽 + `\scriptsize`, 或改 longtable 允许跨页
- 编译后**必查 Overfull \vbox** —— 终审反例: `l` 列自然宽度 299 pt 吃掉大半版心, 28 行表高逾版心一倍 → **Overfull vbox 602 pt**

### H 板块 (v1.6.1 新增, P2-7): 读图串档防御 (Read 工具)

**H1 读图前必做 PIL 尺寸校验** (不是可选, 是硬性前置):
```python
from PIL import Image
import hashlib
from pathlib import Path

figs = sorted(Path('论文/figures').glob('*.png'))
info = {}
for f in figs:
    with Image.open(f) as im:
        info[f.name] = im.size
    with open(f,'rb') as fp:
        info[f.name] = (info[f.name], hashlib.md5(fp.read()).hexdigest()[:8])
for k, v in info.items():
    print(k, v)
```

**H2 同尺寸图串档检测**: 上面输出的**尺寸完全相同**的图 → Read 工具读它们时会串档 (读 A 返回 B 内容). 处理 3 选 1:
- **montage 拼图**: 把多张图拼成 1 张大图再读 (推荐, 一次看清全部)
- **文件名水印**: 在图上叠文件名文字再读 (最可靠, 杜绝张冠李戴)
- **单张读取**: 一次只读 1 张, 读完立刻核对内容与文件名是否对应
