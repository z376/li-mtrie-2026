## 2. 审计 checklist (按板块)

### A 板块: 模型层 (重点 P0)

**A1 边界/初值离散式逐项对拍题面** (P0-1 防御):
- 读 `求解/问题N/solve_*.py` 提**所有**边界条件 / 初始条件行
- 与题面 PDF 原文逐项对照 (`读题清单.md §3-4 题面 quote`)
- 重点抓: 边界条件类型 (Robin/Dirichlet/Neumann) 与题面是否一致
- 重点抓: 半控制体 FVM Robin 离散式 γ=2·h·Δt/Δr 是否含 Δt (无 Δt = h→∞ 极限, 表面钉死)
- **决定性证据**: 跑 dE/dt ÷ [h(T∞−Ts)·A] 守恒校验, |比值−1| 应 < 0.05
  - **用工具跑, 别手推**: `py -3 <SKILL_ROOT>/references/scripts/bc_check.py --project .` (v1.6.3 新增)
  - 求解时没埋点 (无 `求解/问题N/结果/守恒记录.csv`) → **直接判 FAIL**, 报告里写"未提供守恒记录, 无法排除 P0-1 型离散式错误"
  - P0-1 签名: 比值 ≈ **223** (表面被钉死成 h→∞ 极限); 正确实现 ≈ **0.995**

**A2 能量守恒 + 独立换实现重算** (P0-1 防御):
- 写自写求解器 (scipy banded 或另一套 FVM) 复现关键值
- 跟作者实现对比同一参数/同一网格/同一时间步的特征量 (峰值/平衡/半干燥时间)
- 相对误差 < 1% 绿 / 1-5% 黄 / > 5% 红
- **不信任自己的代码**, 自己的"自洽"可能是错的
- **复算过程必须落盘**: 写进 `求解/审计报告*.md` 的 A 板块结论 (验收标准第 2 条要求"有独立换实现的复算记录"),
  光有结论没有过程 = 不算复算

**A3 数据清洗** (P0-2 防御):
- 扫求解脚本找 iqr/boxplot/quantile + 紧邻 drop
- 趋势段 (升温/收缩/衰减) 禁用全局 IQR
- 改 4 类允许: 物理越界 / 一阶差分 z>5 / 单调性含容差 / 时间间隔+重复

**A4 关键判据二次复算** (P0-3 防御):
- 论文所有非题面数字 (Bi/Fo/收缩率/Re/Pr 等关键判据) 必来自 3 类可信来源之一
- 找一次心算反例 (e.g. Bi_m=32 实 3.24 差 10 倍)
- 凭图读数 / AI 写数字 必报 red

**A5 resultX 结构 vs 附件3 模板** (P0-4 防御):
- 用 openpyxl 比对 resultX 列名/dtype/sheet 名
- A 列必须按模板写 (e.g. `时间\到药材中心的距离`, 不能简写 `时间`)
- result4 末列 = "药材表面"
- 论文表步长 ≠ result 完整序列步长

### H 板块 (v1.6.1 新增, P2-7): 读图串档防御 (Read 工具)

**H1 读图前必做 PIL 尺寸校验** (不是可选, 是硬性前置):
```python
from PIL import Image
import hashlib
from pathlib import Path

figs = sorted(Path('论文/figures').glob('*.png'))
info = {}
for f in figs:
    with Image.open(f) as im:
        info[f.name] = im.size
    with open(f,'rb') as fp:
        info[f.name] = (info[f.name], hashlib.md5(fp.read()).hexdigest()[:8])
for k, v in info.items():
    print(k, v)
```

**H2 同尺寸图串档检测**: 上面输出的**尺寸完全相同**的图 → Read 工具读它们时会串档 (读 A 返回 B 内容). 处理 3 选 1:
- **montage 拼图**: 把多张图拼成 1 张大图再读 (推荐, 一次看清全部)
- **文件名水印**: 在图上叠文件名文字再读 (最可靠, 杜绝张冠李戴)
- **单张读取**: 一次只读 1 张, 读完立刻核对内容与文件名是否对应

**H3 图内容 ↔ caption 对应核对**: 每张图读完后, 核对图里的曲线/坐标轴/图例是否与论文 `\caption` 描述一致 (串档最典型的表现: 图 3 的 caption 说的是 Q2, 图里画的是 Q1 的曲线).
