## 1. 论文硬规则（违反即扣分/取消评奖）

按"格式 / 内容 / AI / 纪律"分 4 类，每类 1 张表。**写完论文后逐项打勾**。

### 1.1 格式类（规范第一~十一条）

| 检查项 | 规范条目 | 状态 |
|--------|----------|------|
| 摘要 ≤ 1 页 | 第三条 | ☐ |
| 摘要中文，不附英文翻译 | 第三条 | ☐ |
| 论文无目录 | 第四条 | ☐ |
| 正文 ≤ 30 页 | 第四条 | ☐ |
| 上下左右页边距 ≥ 2.5 cm | 第一条 | ☐ |
| 附录 1：程序使用说明（"用了"或"没用"二选一） | 第五条 | ☐ |
| 附录 2：支撑材料说明（"提供了"或"没有"二选一） | 第五条 | ☐ |
| 附录 3：核心源代码（贴关键函数 + AI 标注） | 推荐 | ☐ |
| 支撑材料 ≤ 20 MB，.rar/.zip | 第十一条 | ☐ |
| 承诺书+编号页（纸质版第一/二页） | 第六条 | ☐ |
| 电子版第一页 = 摘要页（不放承诺书/编号页） | 第十条 | ☐ |
| 公式必须用公式编辑器（不要截图） | 第八条 | ☐ |

### 1.2 内容类（不在正文分点/加粗）

| 检查项 | 例外 | 状态 |
|--------|------|------|
| 正文无分点符号（①②③、●○、1.2.3.） | 模型假设/评价的 itemize | ☐ |
| 正文无 `\textbf{}` 加粗 | 摘要"对于问题X"、问题重述"问题N："、假设/优缺点头部 | ☐ |
| 全文不加 `\newpage` | 参考文献和附录前可用 | ☐ |
| 图不设 `set_title()` | 标题由 `\caption{}` 承担 | ☐ |
| 表格不换行 | 格子文字一行显示 | ☐ |
| 图表全中文 | 含 caption/坐标轴/图例 | ☐ |
| 所有图表在正文被引用 | "如图X所示""如表X所示" | ☐ |
| 不显示参赛队/学校/赛区信息 | 承诺书/编号页/支撑材料除外 | ☐ |
| 参考文献全 GB/T 7714 格式 | 8-15 条，全被引用 | ☐ |
| 引用 AI 工具的格式：`[编号]工具名, 版本/型号, 开发机构, 使用日期` | AI 规定 | ☐ |

### 1.3 AI 工具类（违反即取消评奖，AI 规定第 5 条）

| 检查项 | 位置 | 状态 |
|--------|------|------|
| 「AI 工具使用声明」放参考文献之前（不是附录） | 论文正文 | ☐ |
| 「AI 工具使用详情.pdf」放支撑材料（不是附录） | 支撑材料 | ☐ |
| 论文里 AI 生成的段落/公式/图在**该处**用脚注或括注标明 | 论文正文 | ☐ |
| 核心判断环节（赛题理解/问题重述/模型假设/最终结论）**没**完全交给 AI | 创作过程 | ☐ |
| 没隐瞒 AI 使用情况 | 论文+支撑材料 | ☐ |
| AI 工具列在参考文献 | 参考文献 | ☐ |

**AI 工具使用详情生成流程**（2026 AI 规定第 4 条）：
1. 填写 LaTeX 模板 `论文/AI工具使用详情.tex`（5 节：工具信息/使用目的/prompt/核验/禁用场景）
2. 编译：`xelatex -interaction=nonstopmode AI工具使用详情.tex` (×2 次)
3. 输出位置 `论文/AI工具使用详情.pdf` → 复制到 `支撑材料/AI工具使用详情.pdf`（不是附录）
4. 优势：跟主论文共用 format.cls + 思源宋体，排版自动一致

### 1.4 纪律类（违反即取消评奖，参赛规则第 3/5 条）

## 2. 一键验证命令

跑完论文后，按下面命令逐项自检。命令基于 PowerShell 5.0+（Windows 自带）。

```powershell
# 1) 摘要长度（≤ 1 页，约 ≤ 900 字）
$abstract = Get-Content 论文/0.摘要.tex -Raw
$zh = [regex]::Matches($abstract, '[\u4e00-\u9fff]').Count
Write-Host "摘要中文字数: $zh（应 ≤ 900）"
if ($zh -gt 900) { Write-Warning "摘要可能超 1 页" }

# 2) 正文长度（≤ 30 页）
$pages = (Get-Content 论文.log | Select-String -Pattern 'Output written on 论文.pdf \((\d+) pages\)').Matches.Groups[1].Value
Write-Host "论文.pdf: $pages 页（应 ≤ 30）"

# 3) 目录检查（应为空，2026 规范第四条）
if (Select-String -Path 论文/*.tex -Pattern '\\tableofcontents' -Quiet) {
    Write-Warning "存在 \\tableofcontents，违反 2026 规范"
}

# 4) 编译 warning（应尽量为 0）
$warnings = @(Get-Content 论文.log, 电子版.log | Select-String -Pattern 'Overfull|Underfull|Float too large')
Write-Host "Overfull/Underfull warning 数: $($warnings.Count)"

# 5) 支撑材料大小（≤ 20 MB）
if (Test-Path 支撑材料.rar) {
    $size = [math]::Round((Get-Item 支撑材料.rar).Length / 1MB, 2)
    Write-Host "支撑材料.rar: $size MB（应 ≤ 20）"
}

# 6) AI 工具使用声明位置（应在 9.0.AI工具使用声明.tex，紧邻参考文献之前）
if (Test-Path 论文/9.0.AI工具使用声明.tex) {
    if (Select-String -Path 论文/9.0.AI工具使用声明.tex -Pattern 'AI 工具使用声明' -Quiet) {
        Write-Host "✓ AI 工具使用声明在 9.0 文件里（位置正确）"
    } else {
        Write-Warning "9.0.AI工具使用声明.tex 存在但内容异常"
    }
} else {
    Write-Warning "缺少 论文/9.0.AI工具使用声明.tex（违反 2026 规范）"
}

# 7) 附录两段固定说明（应在 10.0.附录固定说明.tex，二选一占位）
if (Test-Path 论文/10.0.附录固定说明.tex) {
    if ((Select-String -Path 论文/10.0.附录固定说明.tex -Pattern '附录 1.*程序使用说明' -Quiet) -and `
        (Select-String -Path 论文/10.0.附录固定说明.tex -Pattern '附录 2.*支撑材料说明' -Quiet)) {
        Write-Host "✓ 附录 1+2 固定说明齐全（10.0 文件）"
    } else {
        Write-Warning "10.0.附录固定说明.tex 内容异常"
    }
} else {
    Write-Warning "缺少 论文/10.0.附录固定说明.tex（违反 2026 规范第五条）"
}
```

**期望输出**：
- 摘要中文字数 ≤ 900
- 论文.pdf 页数 ≤ 30
- Overfull/Underfull warning 接近 0（容许少量）
- 支撑材料.rar ≤ 20 MB
- AI 声明位置 ✓
- 附录 1+2 ✓

## 3. 禁用场景（AI 规定第 4 条）

以下环节**不得**完全交给 AI：

- 赛题理解
- 问题重述
- 模型假设选择
- 最终结论判断

**可以**用 AI 的环节（但要核验 + 标注）：
- 代码编写/调试
- 数据可视化
- 文档润色/格式检查
- 参考文献格式整理
- 公式编辑器排版

## 5. 最终提交物清单

正式提交时**必须**有 3 个文件：

1. `论文/论文.pdf` — 纸质版（含承诺书+编号页）
2. `论文/电子版.pdf` — 电子版（≤ 20 MB，不放承诺书/编号页）
3. `支撑材料.rar` — 全部源码、数据集、中间图（≤ 20 MB）

**支撑材料.rar 内容**（规范第十一条）：
- 建模所用到的所有可运行源程序
- 自主查阅的数据资料（赛题原始数据除外）
- 较大篇幅中间结果图表
- 用了 AI 的话：`AI工具使用详情.pdf`

**不放**（规范第十一条）：
- 承诺书
- 编号专用页
- 参赛队/学校/赛区信息
