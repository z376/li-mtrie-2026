\section{模型改进与推广}
\subsection{模型改进方向}

\begin{enumerate}
  \item \textbf{更精细的烟幕云团模型}：考虑云团扩散（半径随时间增大）、浓度衰减（有效时长缩短）、风场漂移
  \item \textbf{混合整数规划}：将弹数决策建模为 0-1 变量，问题 5 可建模为混合整数非线性规划（MINLP）
  \item \textbf{鲁棒优化}：考虑导弹速度、风场等不确定性，使用鲁棒优化或随机规划
  \item \textbf{多目标优化}：同时最大化遮蔽时长、最小化弹药消耗等多个目标，使用 NSGA-II 等多目标进化算法
  \item \textbf{机器学习加速}：用神经网络拟合"决策→遮蔽时长"的函数关系，加速优化过程
  \item \textbf{博弈论建模}：将对抗建模为攻防双方的 Stackelberg 博弈
\end{enumerate}

\subsection{模型推广}

\begin{enumerate}
  \item \textbf{舰艇编队防空}：将模型推广到多艘舰艇的编队防空场景，烟幕干扰弹可由舰载发射装置投放
  \item \textbf{多波段对抗}：考虑红外、雷达、激光等多波段制导武器，针对不同波段的烟幕配方不同
  \item \textbf{动态目标}：真目标可能是移动目标（如坦克、车辆），需要动态追踪
  \item \textbf{多约束工程实现}：考虑投放装置的限制（如同时投放的弹数、投放间隔的工程下限）
  \item \textbf{气象因素}：考虑风速、风向、温度、湿度对烟幕云团的影响
  \item \textbf{实战评估}：将模型用于实战训练，生成投放策略推荐
\end{enumerate}

\subsection{应用前景}

本文建立的烟幕干扰弹投放策略优化模型，可直接应用于：
\begin{itemize}
  \item 陆军野战防空：要地防空时的烟幕布设
  \item 海军舰艇自防御：对抗反舰导弹
  \item 空军机场防护：保护机场设施
  \item 民用工程：核电站、水坝等关键设施的反恐防护
\end{itemize}
