\section{模型假设}
\subsection{基本假设}

为简化建模并突出核心物理过程，本文作如下假设：

\begin{enumerate}
  \item \textbf{导弹匀速直线飞行}：来袭导弹 M1/M2/M3 一旦被发现，飞行方向直指假目标 $(0, 0, 0)$，速度 300 m/s 不变。
  \item \textbf{无人机等高度飞行}：FY1--FY5 受领任务后以固定高度 $z_{init}$ 等高度匀速直线飞行，飞行方向和速度瞬时可调。
  \item \textbf{烟幕弹无动力飞行}：烟幕弹脱离无人机后只受重力，无空气阻力。
  \item \textbf{烟幕云团瞬时形成}：烟幕弹起爆后瞬时形成球状云团，半径 10 m，浓度分布均匀。
  \item \textbf{烟幕云团匀速下沉}：起爆后云团以 3 m/s 匀速下沉，20 s 内有效。
  \item \textbf{有效遮蔽的几何判定}：当且仅当烟幕云团球与"导弹→真目标"视线段相交，且真目标圆柱与该视线段相交时，遮蔽有效。
  \item \textbf{忽略空气动力学与风场影响}：不考虑风对烟幕云团扩散、漂移的影响。
  \item \textbf{起爆时间精确控制}：通过时间引信可精确控制起爆时刻，忽略起爆误差。
\end{enumerate}

\subsection{假设的合理性}

\begin{itemize}
  \item 假设 1 与题目"直指假目标方向，速度 300 m/s"一致，是合理的简化。
  \item 假设 2--3 与题目"等高度匀速直线飞行"和"在重力作用下运动"一致。
  \item 假设 4 与题目"起爆后瞬时形成球状烟幕云团"一致。
  \item 假设 5 与题目"以 3 m/s 的速度匀速下沉"一致。
  \item 假设 6 是几何遮蔽的严格定义：当烟幕球和真目标同时位于视线上时，视线被阻断。
  \item 假设 7--8 是工程近似，简化问题便于建立可解模型。
\end{itemize}

\subsection{模型局限性}

\begin{itemize}
  \item 未考虑烟幕云团扩散（半径变化）和浓度衰减的非理想过程
  \item 假设真目标被"完全遮蔽"才有效，实际可能有部分遮蔽效应
  \item 未考虑多枚烟幕弹同时遮蔽时的累积增强效应
  \item 未考虑来袭导弹的机动规避（实际导弹可能做末端机动）
\end{itemize}
